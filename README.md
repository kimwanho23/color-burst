# 컬러 버스트

현재 버전: **v1.0.0-beta.13** (베타) · [변경 기록](CHANGELOG.md) · [작업 규칙·커밋 컨벤션](CONTRIBUTING.md)

최대 4인이 각자 컴퓨터에서 접속해, 중앙에서 터져 나오는 색상 원을 동시에 노리는 웹 클릭 게임.

## 실행 방법

필요한 것: [Node.js](https://nodejs.org) 20 이상 (LTS 권장)

```bash
npm install     # 처음 한 번
npm run dev     # 서버(3001) + 화면(5173) 동시 실행
npm test        # shared 규칙 테스트 (node:test)
```

브라우저에서 http://localhost:5173 접속 → 방 만들기 → 방 코드를 친구에게 공유.

- **같은 와이파이의 친구**: `npm run dev` 실행 시 터미널에 뜨는 `Network: http://192.168.x.x:5173` 주소로 접속 (Windows 방화벽 허용 창이 뜨면 허용)
- 혼자 테스트: 대기실에서 "빈 자리는 봇으로 채우기"를 켜고 시작
- 주소 뒤에 `#방코드`를 붙여 보내면 코드가 미리 입력돼요 (예: `http://.../#43CB`)

배포용 실행 (내 컴퓨터에서 확인할 때):

```bash
npm run build   # client/dist 생성
npm start       # 3001 포트 하나로 화면과 서버를 같이 제공
```

## 배포 (Render)

`render.yaml`에 설정이 들어 있어서 Render가 그대로 읽어 간다. 서버 지역은 한국에서 가장 가까운 **싱가포르**(Render에는 한국 지역이 없다). 지역은 서비스를 만든 뒤에는 바꿀 수 없어서, 바꾸려면 서비스를 지우고 Blueprint로 다시 만들어야 한다.

1. https://dashboard.render.com 에서 GitHub로 로그인
2. **New → Blueprint** → `color-burst` 저장소 선택 → **Apply**
3. 빌드가 끝나면 `https://color-burst-xxxx.onrender.com` 같은 주소가 생긴다. 이 주소를 친구에게 공유

- `main`에 푸시하면 자동으로 다시 배포된다
- 무료 플랜은 15분 동안 접속이 없으면 서버가 잠들고, 다음 접속 때 깨어나는 데 1분 정도 걸린다. 게임 중(WebSocket 통신 중)에는 잠들지 않는다
- 서버가 잠들거나 다시 배포되면 진행 중이던 방은 사라진다
- 상태 확인: `주소/healthz` → `{"ok":true,"version":"1.0.0-beta.13",...}`

## 버전과 릴리즈

| 단계 | 버전 | 의미 |
|---|---|---|
| 베타 (현재) | `1.0.0-beta.1`, `beta.2`… | 테스트하며 규칙·밸런스 조정. 바뀔 때마다 숫자 올림 |
| 출시 후보 | `1.0.0-rc.1`… | 기능 고정, 버그만 수정 |
| 정식 | `1.0.0` | 정식 출시 |
| 이후 | `1.0.1` / `1.1.0` / `2.0.0` | 버그 수정 / 새 기능 / 큰 변경 |

새 버전을 낼 때:

1. 모든 `package.json`(루트, shared, server, client)의 `version`을 올리고 `npm install --package-lock-only`
2. `CHANGELOG.md`에 변경 내용 추가
3. 커밋 후 태그: `git tag -a v1.0.0-beta.2 -m "설명"` → `git push origin main` → `git push origin v1.0.0-beta.2`
4. GitHub에서 그 태그로 Release 작성. 베타·rc는 **Set as a pre-release** 체크

버전에 `-`가 들어 있으면(베타, rc) 게임 화면에 BETA / RC 표시가 자동으로 붙는다.

### 설계 원칙

- **판정은 서버가 한다.** 화면은 "이 원을 클릭했다"만 보내고, 누가 먼저 잡았는지·점수·피버·표적은 서버가 계산해 모두에게 알린다. 네트워크 지연은 최대 250ms까지 보정.
- **원은 생성 정보만 보낸다.** 위치는 `발사 각도 + 속도 + 생성 시각`으로 계산되므로(`circlePos`) 통신량이 적고 모든 화면이 같은 위치를 본다. 접속 시 서버 시각을 맞춘다.
- **재접속은 탭마다 만드는 비밀 키로 처리한다.** 키는 `sessionStorage`에 있어서 새로고침해도 유지되고, 다시 연결되면 같은 키로 자동 입장해 원래 자리·점수로 돌아온다. 게임 중이면 남은 시간과 떠 있는 원까지 받아 이어서 한다. 대기실에서 끊긴 자리는 15초간 비워 두고, 방장이 끊기면 다른 사람에게 넘어간다. '방 나가기'를 누르면 자리가 바로 정리된다.
- **필드는 1600×900 논리 좌표.** 화면 크기와 상관없이 모두 같은 판을 본다.
- **규칙은 `shared/src/rules.ts` 한 곳.** 밸런스는 `RULES` 숫자만 고치면 서버와 화면에 같이 반영된다.
- **프레임워크 교체 지점**: 통신은 `server/src/index.ts`·`client/src/main.ts`, 그리기는 `client/src/render.ts`만 바꾸면 된다 (예: Socket.IO → Colyseus, Canvas → PixiJS/Phaser, 로비 UI → React).

## 현재 규칙 (기본 프리셋)

| 클릭 대상 | 평상시 | 피버 중 (점수 3배, 7초) |
|---|---|---|
| 내 색 | +3, 피버 게이지 ▲▲ | +9 |
| 노란색 (공통) | +2, 피버 게이지 ▲ | 내 색 취급, +9 |
| 무지개 (3%) | +5, 피버 게이지 ▲▲▲ | +15 |
| 남의 색 (견제) | +1, 내 콤보 끊김, 피버 ▼▼, 4초간 표적 | +3, 페널티 없음 |
| 표적인 사람의 색 (반격) | +6 | +18 |
| 보스 원 | 때릴 때 +1, 막타 +20, 최다 타격 +5 | 배율 최대 ×2 |
| 방어형 보스 보호막 중 / 붉은 공격형 보스 | 막힘(0점) / −2, −4, −6 … (라운드 안에서 때린 횟수만큼) | 같음 |
| 빈 공간 (방 규칙에서 끌 수 있음) | 콤보 끊김, 피버 ▼ | 콤보 끊김 |
| `?` 아이템 원 (방 규칙에서 끌 수 있음) | 점수 없음, 무작위 아이템 바로 발동 | 같음 |

- 원은 가운데에서 태어나지만, 가운데 점선 원(발사 보호 구역) 안에 있는 동안은 잡을 수 없다 (반투명으로 보임)
- 견제당한 사람은 콤보가 끊김, 콤보 10마다 +5 보너스
- 60초 한 판, 마지막 10초 속도 상승, 보스는 한 판에 3번(마지막 10초 포함), 한 번에 1~3마리(화면에 최대 3마리)
- 보스 종류: 일반, 방어형(주기적으로 보호막), 공격형(주기적으로 붉어짐, 그때 때리면 감점), 이동형(작고 빠르며 벽에서 튕김)
- 방장이 대기실에서 **방 규칙**을 바꿀 수 있음: 프리셋(기본/파티/하드코어/느긋하게/카오스/장애물 코스/정밀 사격/커스텀)과 고급 설정(게임 속도, 원 개수, 한 판 시간, 피버 배율·시간·충전, 무지개 확률, 표적 시간, 맵 패턴 확률, 레이저 두께, 원 크기, 견제 페널티, 꼴찌 보정, 보스 원, 빈 곳 클릭 페널티, 아이템 원, 발사 패턴, 레이저, 방해 아이템, 아케이드의 라운드 테마·랜덤 이벤트 확률). 고급 설정을 바꾸면 '커스텀'이 켜지고 방장 브라우저에 기억된다
- 색마다 도형(▲■◆+)을 넣어 색약도 구분 가능

## 기능

- **아이템 원**: 일반 원 대신 2.5% 확률로 `?` 원이 나오고, 잡으면 무작위 아이템 16종(방해 아이템을 켜면 20종) 중 하나가 바로 발동(흔함 / 희귀 / 전설). 넓은 손, 자석, 콤보 고정, 점수 2배, 장판, 폭죽, 시간 정지, 필드 클리어 등. 자세한 내용은 [로드맵](docs/ROADMAP.md#아이템-목록)
- **게임 커서**: 게임 중에는 진짜 마우스 커서 대신 게임이 그린 커서를 쓴다(클릭 위치는 같음). 커서 위치를 서버에 보내 레이저·자석을 판정한다
- **레이저**: 10~15초마다 1.2초 경고 띠 뒤에 화면을 가로지르는 레이저(빔 폭은 방 규칙 '레이저 두께': 화면 높이의 얇게 15% / 보통 22% / 굵게 30%, 하드코어·카오스는 굵게). 한 줄 / 평행 두 줄(사이에 피할 틈) / X자 / 세 방향으로 쏜다. 커서가 닿으면 1.5초 스턴(클릭 불가), 스턴이 끝나고 1초는 다시 맞지 않는다. 피버 중에 맞으면 남은 피버 시간이 절반
- **맵 패턴** (방 규칙 '맵 패턴' 확률, 기본 35%): 라운드마다 최대 1번, 3초 경고(자리 미리보기)와 현수막 뒤 8~10초 나타난다. 가로막기(커서가 지나갈 수 없는 벽), 가시 공(닿으면 그 공은 사라지고 1초 스턴), 회전 막대(커서를 밀어냄), 소용돌이(4초 간격으로 두 개, 근처면 쏠리고 눈에 들어가면 끝날 때까지 갇힘, 안에서는 클릭 가능), 빙판(커서가 미끄러짐), 좁아지는 링(가장자리에 있으면 1초 스턴 반복), 안개(원을 가림). 벽·막대 안은 누를 수 없다(감점 없음). 봇은 영향을 받지 않는다
- **자석(능력·아이템)**: 커서 둘레 범위 안에 들어온 내 원을 끌어당겨 잡는다(1초에 2개)
- **방해 아이템** (방 규칙에서 끌 수 있음, 느긋하게 프리셋은 꺼짐): 잡은 사람을 뺀 모두에게 걸린다(감도 감소·마우스 반대 3초, 시야 방해 5초). 감도 감소(커서가 진짜 마우스를 늦게 따라옴), 마우스 반대(커서가 화면 가운데 기준 거울 위치), 시야 방해(잉크 얼룩 / 화면 반쪽 가림 / 낙서 / 볼록·오목 렌즈), 1등 저격(1등이 3초 스턴 + 콤보 끊김, 1등이 잡으면 2등). 효과가 걸리거나 끝나면 커서가 미끄러져 옮겨 간다. 커서 위치는 진짜 마우스 위치에서 정해서 효과 중에도 화면 밖으로 빠지지 않고, 마우스가 게임 영역 밖으로 나가도 커서는 가장자리에 남는다
- **이동형 보스 오오라**: 이동형 보스 둘레의 보랏빛 고리. 안에 들어간 커서는 보스 쪽으로 끌려가고 1초마다 피버 게이지 −15, 콤보 30% 감소(피버 중이면 들어갈 때 남은 피버 시간 절반). 고리를 눌러도 감점은 없다
- **카오스 프리셋**: 아이템 3배, 발사 패턴 2배 자주, 레이저 2초마다(가끔 겹쳐서), 보스가 한 번에 2~3마리, 맵 패턴 80%, 라운드 테마·랜덤 이벤트 30%. 속도·원 개수·피버 배율도 올라간 난장판
- **발사 패턴**: 12~18초마다 웨이브가 섞여 나온다(부채꼴, 동시 다발, 나선, 이중 링, 쌍나선, 연속 사출, 쓸기). 직전에 중앙 원이 번쩍이며 예고
- **랜덤 이벤트 (아케이드)**: 라운드 사이마다 방 규칙 확률(기본 10%)로 깜짝 룰렛이 돌아 로빈 후드, 세금, 복권, 능력 교환, 대평등(3라운드 뒤부터, 모두의 점수가 평균 쪽으로 절반) 등의 이벤트 중 하나가 일어난다(한 게임 최대 2번)
- **라운드 테마 (아케이드)**: 랜덤 이벤트와 따로, 2라운드부터 라운드마다 방 규칙 확률(기본 15%)로 다음 라운드 테마(골드 러시, 보스 러시, 역발사 등)가 정해진다(한 게임 최대 2번)
- **아케이드 모드**: 5라운드 누적 점수. 라운드가 끝날 때마다 능력 3개 중 1개를 고른다(다시 뽑기 1번, 30초, 라운드가 끝나면 "라운드 종료!" 뒤에 열림). 능력 34개(잭팟, 찰나의 순간, 속사, 리바운드, 점화, 보조 능력 넓은 손·자석·헛손질 보정 등) × 등급 4개(노말 흰색 / 레어 파랑 / 에픽 보라 / 레전드 프리즘, 레전드는 수치가 에픽의 2배 + 증강마다 레전드 전용 효과), 같은 능력은 중첩. 2라운드 뒤부터는 노말이 안 나오고, 3·4라운드 뒤에는 **2장**을 고른다(첫 장을 고르면 같은 규칙으로 새 카드 3장이 다시 깔림, 다시 뽑기는 라운드에 1번). 꼴찌는 높은 등급 확률 상승과 등급 보장(레어 → 에픽 → 레전드 이상 1장). 가끔 큰 보상과 대가가 붙은 **저주 카드** 8장이 섞여 나온다(한 게임 1장). 자세한 수치는 [로드맵](docs/ROADMAP.md#아케이드-모드-100-beta3-)
  - **역전 기회**: 2라운드 끝부터 꼴찌 점수가 1등의 60% 미만이면 켜진다. 꼴찌인 동안 점수 ×1.1 / ×1.2 / ×1.3(2·3·4인), 3라운드 뒤 선택에 **특별 카드**(대역전, 판 뒤집기, 추격자, 철벽 등 12장, 게임 끝까지) 1장, 4라운드 뒤 선택은 전부 레전드
  - **증강 조합**: 정해진 증강을 모두 모으면 보너스(피버 마스터, 콤보 머신, 보스 헌터, 견제왕, 행운아, 변두리, 미식가, 철옹성). 가진 증강과 같은 분류·조합 조각이 선택지에 더 자주 나온다. 증강 선택 화면의 조합 패널(완성은 밝게, 진행은 ●●○, 시작 안 한 조합은 흐리게)과 카드마다 붙는 조합 배지(고르면 오르는 진행은 "2→3/3")로 본다
  - **넓은 손 순위 보정** (꼴찌 보정 방): 꼴찌 넓은 손 +20, 4인 방 3등 +10 (순위가 바뀌면 바로 다시 계산)
- **점수 구역**: 화면을 타원으로 중앙(×1) / 사이(×2) / 가장자리(×3)로 나눈다. 일반 원은 잡는 순간 있던 자리의 배율을 받는다(피버·잭팟 등과 곱함). 바닥의 옅은 점선이 경계, 점수 글자 옆에 ×2 / ×3. 증강 '찰나의 순간'은 가장자리 배율을 더 올린다
- **황금 원**: 한 판에 1~3번 나오는 작고 아주 빠른 금빛 원. 벽에서 튕기고 5초 뒤 사라진다. 직접 클릭으로만 잡히고 +20 고정(배율 없음)
- **도감**: 위쪽 바·처음 화면·대기실의 '도감' 버튼으로 증강(등급별 수치·중첩 상한), 조합(게임 중이면 내 진행도), 저주, 특별, 아이템, 보스, 규칙(점수표)을 볼 수 있다. 게임이 진행 중일 때만 위쪽 버튼이 숨는다
- **상대 빌드**: 증강 선택 화면 아래 '상대 빌드'(점수 순, 완성 조합·레전드 ★), 점수판 칩을 누르거나 마우스를 올리면 그 사람 빌드 카드, 결과 화면에도 빌드 타일. 점수판 칩에는 특별 카드·완성 조합 수 배지
- **설명 카드**: 증강·조합 아이콘에 마우스를 올리면 바로 설명 카드(합친 수치, 레전드 효과, 들어가는 조합과 진행도 / 조합 효과와 필요한 증강 ✓). 터치는 누르면 뜬다
- **활성 조합**: 게임 중 아이템 효과 칩 위에 내 완성 조합 칩(철옹성은 남은 횟수), 효과가 발동하면 반짝인다
- **연출**: 보스를 처치하면 순간 멈춤·강한 흔들림·처치한 사람 배너, 남이 아이템을 잡으면 화면 위쪽 알림과 점수판 아이콘, 피버 중에는 테두리가 맥동하고 파편이 커진다 (설정 '화면 효과 줄이기'면 멈춤·흔들림·맥동 없음)
- **혼자 하기**: 처음 화면에서 바로 봇 3명과 대결. 횟수·시간 제한 없이 일시정지, 다른 탭으로 가면 자동 정지
- **일시정지** (`Esc` / `P` / 상단 버튼): 멀티는 누구나 한 게임에 3번, 한 번에 최대 30초(지나면 저절로 풀림), 푸는 건 누구나. 풀리면 3초 카운트다운 뒤 다시 시작
- **한 판 더**: 결과 화면에서 바로 재시작
- **설정**: 배경음악·효과음 음량, `M` 음소거, 화면 효과 줄이기, 전체 화면, 핑 표시
- **결과 화면**: 칭호(막타 장인, 견제왕, 피버 머신, 콤보 마스터, 정밀 사격, 평화주의자), 점수 그래프, 방 누적 승수
- **매크로 방지**: 1인 초당 15회 클릭 제한
