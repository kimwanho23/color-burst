# 컬러 버스트

현재 버전: **v1.0.0-beta.3** (베타) · [변경 기록](CHANGELOG.md) · [작업 규칙·커밋 컨벤션](CONTRIBUTING.md)

최대 4인이 각자 컴퓨터에서 접속해, 중앙에서 터져 나오는 색상 원을 동시에 노리는 웹 클릭 게임.

## 실행 방법

필요한 것: [Node.js](https://nodejs.org) 20 이상 (LTS 권장)

```bash
npm install     # 처음 한 번
npm run dev     # 서버(3001) + 화면(5173) 동시 실행
```

브라우저에서 http://localhost:5173 접속 → 방 만들기 → 방 코드를 친구에게 공유.

- **같은 와이파이의 친구**: `npm run dev` 실행 시 터미널에 뜨는 `Network: http://192.168.x.x:5173` 주소로 접속 (Windows 방화벽 허용 창이 뜨면 허용)
- 혼자 테스트: 대기실에서 "빈 자리는 봇으로 채우기"를 켜고 시작
- 주소 뒤에 `#방코드`를 붙여 보내면 코드가 미리 입력돼요 (예: `http://.../#43CB`)

배포용 실행 (내 컴퓨터에서 확인할 때):

```bash
npm run build   # client/dist 생성
npm start       # 3001 포트 하나로 화면과 서버를 같이 제공
```

## 배포 (Render)

`render.yaml`에 설정이 들어 있어서 Render가 그대로 읽어 간다.

1. https://dashboard.render.com 에서 GitHub로 로그인
2. **New → Blueprint** → `color-burst` 저장소 선택 → **Apply**
3. 빌드가 끝나면 `https://color-burst-xxxx.onrender.com` 같은 주소가 생긴다. 이 주소를 친구에게 공유

- `main`에 푸시하면 자동으로 다시 배포된다
- 무료 플랜은 15분 동안 접속이 없으면 서버가 잠들고, 다음 접속 때 깨어나는 데 1분 정도 걸린다. 게임 중(WebSocket 통신 중)에는 잠들지 않는다
- 서버가 잠들거나 다시 배포되면 진행 중이던 방은 사라진다
- 상태 확인: `주소/healthz` → `{"ok":true,"version":"1.0.0-beta.3",...}`

## 버전과 릴리즈

| 단계 | 버전 | 의미 |
|---|---|---|
| 베타 (현재) | `1.0.0-beta.1`, `beta.2`… | 테스트하며 규칙·밸런스 조정. 바뀔 때마다 숫자 올림 |
| 출시 후보 | `1.0.0-rc.1`… | 기능 고정, 버그만 수정 |
| 정식 | `1.0.0` | 정식 출시 |
| 이후 | `1.0.1` / `1.1.0` / `2.0.0` | 버그 수정 / 새 기능 / 큰 변경 |

새 버전을 낼 때:

1. 모든 `package.json`(루트, shared, server, client)의 `version`을 올리고 `npm install --package-lock-only`
2. `CHANGELOG.md`에 변경 내용 추가
3. 커밋 후 태그: `git tag -a v1.0.0-beta.2 -m "설명"` → `git push origin main` → `git push origin v1.0.0-beta.2`
4. GitHub에서 그 태그로 Release 작성. 베타·rc는 **Set as a pre-release** 체크

버전에 `-`가 들어 있으면(베타, rc) 게임 화면에 BETA / RC 표시가 자동으로 붙는다.

## 구조

```
color-burst/
├─ shared/      규칙과 메시지 형식 (서버·화면 공용, 프레임워크 무관)
│  └─ src/rules.ts      점수·피버·견제 판정, 원 생성, 밸런스 수치(RULES)
│  └─ src/protocol.ts   주고받는 메시지 정의
│  └─ src/arcade.ts     아케이드 능력 20개, 등급 확률, 중첩 계산
├─ server/      Node.js + Socket.IO
│  └─ src/index.ts      접속, 방 만들기/입장
│  └─ src/room.ts       방 하나의 게임 진행 (원 생성, 클릭 판정, 타이머)
│  └─ src/bot.ts        봇 AI (쉬움/보통/어려움)
├─ client/      Vite + TypeScript + Canvas
│  └─ src/main.ts       화면 전환, 서버 통신, 입력
│  └─ src/render.ts     Canvas 그리기와 연출
│  └─ src/audio.ts      합성 배경음악·효과음 (음악/효과음 음량 분리)
│  └─ src/rulesUI.ts    대기실 방 규칙 화면
│  └─ src/settings.ts   개인 설정 (음량, 효과, 핑)
│  └─ src/results.ts    결과 화면 (칭호, 그래프)
│  └─ src/arcadeUI.ts   능력 선택 카드, 빌드 표시
└─ prototype/   처음 만든 1인 프로토타입 (참고용, 그냥 열면 실행됨)
```

### 설계 원칙

- **판정은 서버가 한다.** 화면은 "이 원을 클릭했다"만 보내고, 누가 먼저 잡았는지·점수·피버·표적은 서버가 계산해 모두에게 알린다. 네트워크 지연은 최대 250ms까지 보정.
- **원은 생성 정보만 보낸다.** 위치는 `발사 각도 + 속도 + 생성 시각`으로 계산되므로(`circlePos`) 통신량이 적고 모든 화면이 같은 위치를 본다. 접속 시 서버 시각을 맞춘다.
- **재접속은 탭마다 만드는 비밀 키로 처리한다.** 키는 `sessionStorage`에 있어서 새로고침해도 유지되고, 다시 연결되면 같은 키로 자동 입장해 원래 자리·점수로 돌아온다. 게임 중이면 남은 시간과 떠 있는 원까지 받아 이어서 한다. 대기실에서 끊긴 자리는 15초간 비워 두고, 방장이 끊기면 다른 사람에게 넘어간다. '방 나가기'를 누르면 자리가 바로 정리된다.
- **필드는 1600×900 논리 좌표.** 화면 크기와 상관없이 모두 같은 판을 본다.
- **규칙은 `shared/src/rules.ts` 한 곳.** 밸런스는 `RULES` 숫자만 고치면 서버와 화면에 같이 반영된다.
- **프레임워크 교체 지점**: 통신은 `server/src/index.ts`·`client/src/main.ts`, 그리기는 `client/src/render.ts`만 바꾸면 된다 (예: Socket.IO → Colyseus, Canvas → PixiJS/Phaser, 로비 UI → React).

## 현재 규칙 (기본 프리셋)

| 클릭 대상 | 평상시 | 피버 중 (점수 3배, 7초) |
|---|---|---|
| 내 색 | +3, 피버 게이지 ▲▲ | +9 |
| 노란색 (공통) | +2, 피버 게이지 ▲ | 내 색 취급, +9 |
| 무지개 (3%) | +5, 피버 게이지 ▲▲▲ | +15 |
| 남의 색 (견제) | +1, 내 콤보 끊김, 피버 ▼▼, 4초간 표적 | +3, 페널티 없음 |
| 표적인 사람의 색 (반격) | +4 | +12 |
| 보스 원 | 때릴 때 +1, 막타 +20, 최다 타격 +5 | 배율 최대 ×2 |
| 빈 공간 | 콤보 끊김, 피버 ▼ | 콤보 끊김 |

- 견제당한 사람은 콤보가 끊김, 콤보 10마다 +5 보너스
- 60초 한 판, 마지막 10초 속도 상승, 보스는 한 판에 3번(마지막 10초 포함)
- 방장이 대기실에서 **방 규칙**을 바꿀 수 있음: 프리셋(기본/파티/하드코어/느긋하게)과 고급 설정(게임 속도, 원 개수, 한 판 시간, 피버 배율·시간·충전, 무지개 확률, 견제 페널티, 표적 시간, 꼴찌 보정, 보스 원)
- 색마다 도형(▲■◆+)을 넣어 색약도 구분 가능

## 기능

- **아케이드 모드**: 5라운드 누적 점수. 라운드가 끝날 때마다 능력 3개 중 1개를 고른다(다시 뽑기 1번, 15초). 능력 20개 × 등급 4개(노말 흰색 / 레어 파랑 / 에픽 보라 / 레전드 프리즘), 같은 능력은 중첩. 꼴찌는 높은 등급 확률 상승. 자세한 수치는 [로드맵](docs/ROADMAP.md#아케이드-모드-100-beta3-)
- **혼자 하기**: 처음 화면에서 바로 봇 3명과 대결. 자유롭게 일시정지, 다른 탭으로 가면 자동 정지
- **일시정지**: 멀티는 방장만 (`Esc` / `P` / 상단 버튼)
- **한 판 더**: 결과 화면에서 바로 재시작
- **설정**: 배경음악·효과음 음량, `M` 음소거, 화면 효과 줄이기, 전체 화면, 핑 표시
- **결과 화면**: 칭호(막타 장인, 견제왕, 피버 머신, 콤보 마스터, 정밀 사격, 평화주의자), 점수 그래프, 방 누적 승수
- **매크로 방지**: 1인 초당 15회 클릭 제한
