# 다른 PC에서 이어서 작업하기

2026-11-18 협력전 작업 인수인계. 기준 브랜치는 `main`이다.

## 시작

기존 저장소의 작업 상태를 확인한 뒤 최신 커밋을 받는다.

```powershell
git status
git switch main
git pull --ff-only origin main
npm.cmd install
npm.cmd run dev
```

Node.js 20 이상이 필요하다. 화면은 기본 `http://localhost:5173`, 서버는 3001이다. 화면 포트가 사용 중이면 Vite가 출력한 `Local` 주소로 접속한다. PowerShell에서 `npm.ps1` 실행이 차단되면 위처럼 `npm.cmd`를 쓴다. 종료는 Ctrl+C다.

`CLAUDE.md`, `CONTRIBUTING.md`, 이 문서와 `docs/ROADMAP.md`를 먼저 읽는다. `main` 푸시는 Render 자동 배포를 시작한다. 원격 푸시는 사용자가 명시적으로 요청했을 때만 수행한다.

## 이번에 반영한 동작

- 협력전 패배 시 어두운 배경 위에 붉은 `FAIL`이 900ms 동안 나타나고, 종료 후 총 1700ms에 결과창을 연다. 글자 크기는 40~88px이다. 효과 줄이기를 켜면 정적인 글자를 600ms 표시한다. 새 게임이나 화면 전환은 지연된 결과창 표시를 취소한다.
- 보스 처치 시 약 4초간 처치 연출을 재생한 뒤 결과창을 연다. 보스가 마지막 위치에서 멈추고 점점 하얗게 빛나며 2.2초에 완전히 하얘진다. 2.5초에 폭발·충격파, 3초부터 CLEAR 페이드 인이 이어진다. 효과 줄이기는 하얘진 몸체가 잔잔하게 사라지는 방식이며 폭발·파편·흔들림을 생략한다. 재시작·화면 전환 시 연출과 예약된 결과창을 취소한다.
- 클릭해서 제거하는 큰 구체는 청록색 발광 구체다. 가시와 중앙의 ‘클릭’ 글자는 제거했다. 표적 플레이어 색 고리는 남아 있다.
- 큰 구체는 좌우 벽에서 반사하고 위아래로 이탈하면 기존 표적 피해를 준다. 일반 원은 이 반사를 적용하지 않는다. 위치와 클릭 판정은 공유 함수 `circlePos`를 사용한다.
- 발사 2초 전 경고 문구는 ‘보스가 큰 원을 발사합니다! 클릭해서 제거하세요!’다. 위아래로 이탈하기 전 최소 3초를 확보하도록 속도를 제한한다.
- 보스 원 안의 체력 숫자도 `coop:state` 수신 시 상단 체력 바와 함께 갱신한다.
- 내려오는 벽은 2초 경고 후 2단계 속도 900, 3단계 속도 1100으로 빠르게 내려온다. 벽 속도는 모든 난이도가 공유한다. 프레임 사이에 벽이 커서를 통과하는 경우도 이동 경로로 피격을 검사한다.
- 벽은 작은 위험 탄을 가로로 배치한 패턴이지만 피격 종류는 별도 `wall`이다. 벽 피해는 이지 15, 노말 25, 하드 35, 엑스퍼트 45로 일반 탄막보다 높다.
- 보스 체력은 `round(300 × (사람 수 + 봇 수 × 0.5) × 난이도 배율)`이다. 솔로 체력은 이지 240, 노말 300, 하드 360, 엑스퍼트 540이다.
- 수정 파훼 후 살아 있는 사람의 회복량은 이지 40, 노말 20, 하드 10, 엑스퍼트 0이다. 최대 체력은 100이다.

## 스페셜 어택

대기실에서 각자 선택한다. 선택 변경은 준비 완료를 해제한다. 게임 중에는 선택을 변경할 수 없다. 선택값이 없는 이전 데이터는 레이저로 처리한다.

| 공격 | 필요 게이지 | 기본 총피해 | 지속 시간 |
|---|---|---|---|
| 레이저 | 30 | 18 | 2.4초 |
| 유성 폭격 | 50 | 34 | 2초 |
| 회전 칼날 | 75 | 55 | 4초 |

원 획득 +1, 수정 타격 +1, 큰 구체 제거 +4로 충전한다. 가득 차면 Space 한 번으로 자동 공격한다. 큰 피해 구간에는 피해가 2배다. 보호막 구간·일시정지·시작 카운트다운·기절·탈락 중에는 발동할 수 없다. 공격 중 보스가 보호막 단계로 넘어가면 남은 공격은 종료된다. 공격의 피해와 게이지 소모는 서버에서 결정한다.

대기실에 공격별 아이콘, 충전량·위력 비교 막대와 선택 표시가 있다. 전투 중 게이지에도 선택 아이콘과 Space 안내가 표시된다. 공격 연출은 위험 탄막 아래에 그린다.

## 엑스퍼트 단계별 난이도

사용자 피드백에 따라 첫 단계부터 과도하게 어렵던 수치를 조정했다. 목표는 하드보다 조금 어려운 초반에서 적응하고 후반으로 갈수록 강해지는 흐름이다.

| 항목 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 실제 평상시 탄막 간격 | 850ms | 약 577ms | 약 344ms |
| 탄막 기준 속도 | 320 | 380 | 440 |
| 큰 구체 수 | 5 | 7 | 9 |
| 큰 구체 기준 속도 | 280 | 340 | 400 |

큰 구체 속도에는 최소 대응 시간 제한이 적용된다. 탄막 개별 속도는 무늬 설정에 따라 기준 속도와 차이가 있다. 수정 구간은 더 촘촘한 별도 발사 간격을 사용한다. 첫 수정 12회, 두 번째 수정 24회이며 제한 시간은 각각 8초다. 수정 파훼 실패 시 즉시 패배한다.

### 엑스퍼트 전용 압살

2·3단계의 고유 패턴 후보에 `crush`를 추가했다. 세로 세 줄 중 한 줄을 밝은 안전 구역으로 남기고 나머지 두 줄은 즉사 구역으로 표시한다. 3초 경고 뒤 120ms 동안 위아래 턱이 닫히며 닫힌 순간 위험 구역에 있는 사람에게 피해 100을 준다. 일반 피격 무적과 아이템 방어막을 관통한다. 안전 구역에 있던 사람은 닫힌 뒤 위험 구역으로 이동해도 다시 판정하지 않는다.

구현은 `Seal.lethal`과 `coop:seal` 상태를 재사용한다. `CoopHitBy`의 `crush`로 피격을 기록한다. 일시정지 시 예고·발동 시각이 함께 밀리고, 재접속 상태에도 실린다. 보호막 단계가 시작되면 예고를 취소한다. 화면은 `drawCrush`에서 표시한다.

### 엑스퍼트 전용 유도탄

2·3단계 고유 패턴 후보에 `homing`을 추가했다. 맨 아래에 자리 잡고 가만히 탄막을 피하는 플레이를 견제하는 패턴이다. 1.5초 예고(보스 둘레 대상 색 점선 고리, 내가 대상이면 내 커서에 차오르는 고리) 뒤 살아 있는 사람마다 1발을 쏜다. 봇은 대상이 아니다. 탄은 서버가 틱마다 대상 커서 쪽으로 선회 상한 안에서 꺾으며 움직이고, 한 틱 동안 지나간 선분이 커서에 닿으면 맞는다. 클릭으로 제거할 수 없다.

| 항목 | 2단계 | 3단계 |
|---|---|---|
| 속력(필드/초) | 300 | 340 |
| 초당 최대 선회 | 140도 | 160도 |

수명 5초 뒤 0.4초 동안 흐려지며 판정이 없다. 피해는 이지 15, 노말 20, 하드 25, 엑스퍼트 30이다. 맞히거나 방어막에 막히면 탄이 사라지고, 무적 중이면 계속 쫓는다. 대상 탈락·판 밖 이탈·보호막 단계 시작·탄막 지우기 아이템·판 종료 때 지운다. 일시정지하면 시각을 밀고 위치는 멈춘다. 서버가 `coop:homing`으로 50ms마다 위치를 보내고, 화면은 최대 120ms 외삽해 그린다.

구현은 `shared/src/coop.ts`의 `steerHoming`·`homingHits`·`homingAlpha`, `server/src/coop.ts`의 `tickHoming`, `client/src/render.ts`의 `drawHoming`이다. 수치는 `RULES.coop.homing`에 있다.

## 주요 코드

- `shared/src/rules.ts`의 `RULES.coop`에 모든 게임 수치가 있다. `levels.expert`는 첫 단계 기준이고 `expertRamp`는 2·3단계 공격 기준이다.
- `shared/src/coop.ts`의 `coopAttackRules`, `coopThreatCount`, `threatSpeed`가 단계별 기준을 선택한다. `makeThreat`는 큰 구체의 속도를 제한한다.
- `shared/src/rules.ts`의 `circlePos`는 큰 구체의 좌우 반사를 계산한다.
- `shared/src/coopSpecial.ts`에 공격 종류와 화면 메타데이터가 있다.
- `server/src/coop.ts`가 충전·발동·공격 진행과 일시정지 시간 보정을 담당한다. `server/src/room.ts`, `server/src/index.ts`가 선택·발동 이벤트를 연결한다.
- `client/src/coopUI.ts`, `client/src/icons.ts`, `client/src/style.css`가 선택 화면과 게이지를, `client/src/render.ts`가 공격 연출을 담당한다.
- `client/src/main.ts`에 Space 입력, 큰 구체 경고, 보스 체력 동기화, 패배 후 결과창 전환이 있다.
- 처치 연출은 `client/src/render.ts`의 `COOP_DEFEAT`, `startCoopDefeat`, `drawCoopDefeat`와 `client/src/main.ts`의 `boss:killed`, `game:over`에 연결되어 있다.

## 검증과 다음 확인

급강하 벽·압살·백색 발광 처치 연출까지 전체 테스트 595개, 타입 검사, 프로덕션 빌드가 통과했다. 처치 연출에는 타이밍·단발 폭발·효과 줄이기·취소를 확인하는 회귀 테스트가 포함되어 있다. 실제 화면에서 연출 확인은 남아 있다.

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
```

브라우저 도구는 로컬 연결 시간 초과와 Windows 브라우저 URL 판별 실패로 화면 검증을 완료하지 못했다. 집에서 실제 플레이로 다음을 확인한다.

- 세 스페셜 어택의 선택·충전·Space 발동, 아이콘과 공격 연출, 멀티플레이에서 동시에 사용하기.
- 일시정지·재접속 뒤 공격과 게이지 상태 이어짐, 보호막 단계 전환 시 남은 공격 종료의 체감.
- 큰 구체 좌우 반사 뒤 클릭 제거와 아래쪽 이탈 피해, 발사 경고 가독성.
- 급강하 벽의 속도·피격 체감과 압살의 안전 구역·카운트다운·닫힘 연출, 멀티플레이 탈락 판정.
- 패배 시 FAIL 크기·페이드 인·결과창 순서, 효과 줄이기, 연출 중 다른 사람이 재시작했을 때 화면 전환.
- 처치 시 4초 연출의 백색 발광·폭발·CLEAR·결과창 순서, 소리와 효과 줄이기, 재시작으로 취소한 뒤 남은 파편이 없는지 확인.
- 하드 솔로와 엑스퍼트 단계별 압박, 체력·제한 시간 밸런스. 수치는 초기 조정값이므로 플레이 기록과 후기로 조정한다.

유도탄은 실제 플레이로 속도·선회 체감, 멀티플레이 동시 추격, 일시정지·재접속 뒤 이어짐을 확인한다. 우클릭 보호막은 구상 단계다. 사용 횟수 제안은 이지 3회, 노말 2회, 하드 1회, 엑스퍼트 0회다.

콤보 상한 1.8배와 단시간 폭딜에 반응하는 보스 반격도 논의 단계다. 제안은 10콤보마다 +0.2배, 최근 3초간 보스 최대 체력 8% 피해에 반격 예고, 맞으면 콤보 초기화, 재사용 대기 20초, 파훼 후 딜 타임에는 반격 억제다. 현재 실제 콤보 설정은 `RULES.coop.comboStep`, `comboPer`, `comboCap`을 확인한다.
