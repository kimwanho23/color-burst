# 다른 PC에서 이어서 작업하기

2026-11-19 작업 인수인계. 기준 브랜치는 `main`이다. 아케이드 2차 묶음과 폭탄 원은 모두 main에 합쳐졌다.

## 폭탄 원 (2026-11-19)

[설계](superpowers/specs/2026-11-19-bomb-circle-design.md) 기준. 클래식·아케이드에서 나오는 특수 원이다. 협력전·튜토리얼에는 나오지 않는다.

| 항목 | 현재 규칙 |
|---|---|
| 방 규칙 | '특수 원'(`specialCircles`). 기본 켜짐, 하드코어 프리셋은 꺼짐 |
| 등장 | 일반 원이 생길 때 아이템 원 판정 다음에 2.5% 확률. 웨이브 원·라운드 테마에는 섞이지 않는다 |
| 폭발 | 폭탄 중심을 지나는 가로·세로 줄이 판 끝까지 간다(줄 반폭 30). 걸린 원은 남의 색도 견제 페널티 없이 `via: 'cross'`로 잡고, 원마다 점수·콤보·피버·잭팟을 받는다. 보물 상자를 충전하고 점화도 발동한다. 황금 원·아이템 원과 발사 보호 구역 안의 원은 걸리지 않는다 |
| 보스 | 직접 클릭 1회와 같은 타격. 독식 기여와 막타로 인정한다. 보호막·붉은 상태면 지나간다 |
| 터지는 경우 | 직접 클릭, 넓은 손, 장판, 폭죽, 다른 폭탄. 자석으로는 터지지 않는다. 봇도 십자로 터뜨린다 |
| 연쇄 | 걸린 폭탄은 150ms 뒤 그때 위치에서 터진다. 점수는 처음 터뜨린 사람이 받는다. 일시정지·시간 정지 중에는 예약이 밀린다 |
| 점수 출처 | 결과 화면에 '폭탄' 줄(`SrcKey` `bomb`)이 생긴다. 십자의 보스 타격은 '보스'에 들어간다 |

- 보호 구역에 막 들어간 폭탄을 누르면 서버가 거절해 다시 누를 수 있다. 넓은 손 범위에 터지지 않은 폭탄만 있으면 빈 곳 클릭으로 판정한다.
- 함께 바꾼 밸런스: 폭죽·필드 클리어로 잡은 원도 잭팟을 굴린다(`balance` 커밋). 점화·사냥꾼·연쇄 폭발의 자동 획득은 예전처럼 잭팟이 없다.
- 수치는 `RULES.specialCircles.bomb`(`chance`·`halfWidth`·`chainDelayMs`·`r`)에 있다. 테스트는 `shared/test/bomb.test.ts`다.
- 실제 플레이로 확인할 것: 십자·연쇄 연출의 가독성, 보스 근처 폭탄 쟁탈이 생기는지, 효과 줄이기 화면, 폭죽 잭팟과 십자 보물 상자 충전 때문에 아이템 빌드 고점이 지나치게 오르는지.

## 얼음 원 · 분열 원 (2026-11-19)

[설계](superpowers/specs/2026-11-19-ice-split-circle-design.md) 기준. 방 규칙 '특수 원' 하나로 폭탄·얼음·분열을 함께 켜고 끈다. 특수 원 전체 확률 2.5%를 셋이 1:1:1로 나눠서 폭탄은 예전의 1/3로 나온다.

| 원 | 현재 규칙 |
|---|---|
| 얼음 원 | 터뜨린 사람 빼고 모두(봇 포함, 팀전이면 상대 팀). 1초 동안 커서가 아주 느려진 뒤(`frost` 디버프, 지연 1,200ms) 1초 기절. 철벽·위험 스턴 무적 시간이면 안 걸림. 일시정지·시간 정지가 얼어붙는 시각(`frostAt`)을 밀고, 라운드·판이 끝나면 지운다 |
| 분열 원 | 터뜨린 사람 색 파편 4개(반지름 22, 속력 ×1.5, `splitBy`). 주인·팀원은 평소처럼 잡고 점수 출처는 '분열'. 남의 커서에 닿거나 남이 클릭하면 1초 기절, 파편은 사라짐. 봇은 커서가 없어 닿지 않고 남의 파편을 노리지 않는다 |
| 공통 | 원 자체는 점수·콤보 없음. 클릭·넓은 손·장판·폭죽·필드 클리어·폭탄 십자로 터지고 자석으로는 안 터진다. 십자에 걸리면 바로, 폭죽·필드 클리어면 연쇄 지연 뒤. 기절은 `hazardStun`의 `soft` 옵션이라 콤보·피버를 건드리지 않는다 |

- 함께 바꾼 기존 동작: 웨이브 원에는 특수 원이 섞이지 않는다(폭탄 원 설계대로). 기절한 봇은 클릭하지 않는다(1등 저격도 이제 봇에게 먹힘).
- 원 안에 한글·영어 글자를 넣지 않는다. 얼음은 눈송이 무늬, 분열은 금 무늬, 파편은 톱니 테두리와 잔상으로 구분한다.
- 수치는 `RULES.specialCircles`(`chance`·`weights`·`ice`·`split`). 서버는 `server/src/room.ts`의 `popSpecial`·`burstIce`·`burstSplit`·`tickFrost`·`tickPieces`·`hitPiece`, 테스트는 `shared/test/ice-split.test.ts`.
- 실제 플레이로 확인할 것: 얼어 가는 1초의 커서 체감, 얼음 결정·서리 고리 가독성, 파편 피하기가 억울하지 않은지, 폭탄이 줄어든 체감.

## 아케이드 2차 묶음 (2026-11-19)

[설계](superpowers/specs/2026-11-19-arcade-bundle2-design.md)와 [구현 계획](superpowers/plans/2026-11-19-arcade-bundle2.md)을 기준으로 유니크 8장, 정밀 사격, 아이템 증강 2장과 잡화점, 레전드 천장, 방패·도발 개편을 반영했다. 역전 기회의 특별 카드는 천장이 적용되면 3라운드 뒤 두 번째 묶음에 나온다.

로컬 브라우저에서 유니크 도감, 혼자 하기 아케이드 한 판, 3라운드 뒤 레전드 천장과 다시 뽑기를 확인했다. 무의 시간 띠·회색 타일, 거울 복사 타일, 정밀 사격 과녁 링, 보물 상자 룰렛은 실제 플레이 중 발동 화면을 따로 확인해야 한다.

### 이번 아케이드 변경

| 기능 | 현재 규칙 |
|---|---|
| 독주와 연결 | 독주 카드 한 종류로 직접 잡은 내 색·노란색·무지개 점수 +15%. 다른 독주 카드, 연결, 일반 시너지 또는 지정 조합이 있으면 독주가 꺼진다. 연결은 일반 분류 6개의 증강 종류 수에 각각 +1을 준다. 선택 화면에서 독주 변경을 미리 표시한다. [독주 카드별 효과](ROADMAP.md#독주-시너지-설계) |
| 잡화점과 보물 상자 | 잡화점은 아이템 효과 시간 ×1.5와 아이템 발동 묶음당 피버 +25를 준다. 폭죽·필드 클리어·장판 및 아이템이 늘린 넓은 손 범위로 잡은 원은 상자를 충전하지 않는다. 보물 상자 레전드는 단독 보유 시 8콤보마다 열린다. 흔함 50%, 희귀 45%, 전설 5%다. |
| 보호막 발생기 | 시작 시 및 등급별 10 / 8 / 6 / 4초마다 견제 보호막과 득점 보너스가 각각 1회 채워진다. 다음 내 색 직접 클릭에 50%, 최대 100점을 더한다. 반격 태세는 견제를 막을 때 반격권을 주고, 보호막 강타는 반격 성공 시 보호막을 써서 기본 +40점에 피버 배율을 적용한다. |
| 자기장과 충전기 | 자기장은 내 색 원 직접 획득 5개로 충전한다. 다음 내 색 클릭 위치의 반경 140 안에 있는 같은 색 원을 등급별 1 / 2 / 3 / 4개까지 끌어온다. 충전기는 10 / 8 / 6 / 4초마다 피버 +20, 레전드 +30이다. 충전기로 피버가 시작되면 초과분의 절반을 이월한다. |
| 성장과 밸런스 | 수확은 원 20개당 1칸, 무의 시간은 3초다. 왕의 증표는 보스 체력 25% 이상 기여 또는 막타에 1칸, 레전드가 50% 이상 기여하면 2칸을 얻는다. 기본 피버 ×3은 증표 3칸에서 ×5.8, 5칸에서 ×9가 된다. 콤보 머신은 콤보 보너스 ×1.5다. |

### 기본 아케이드 시뮬레이션

테스트 자동사냥 1명과 기본 봇 3명으로 30초씩 5라운드를 진행했다. 첫 10판은 방어와 득점 조합을 각각 5판 노렸다. 콤보 머신 배율을 ×2에서 ×1.5로 낮추고 같은 시드로 10판을 재실행했다. 콤보 머신이 활성화된 5개 라운드의 콤보 점수 합계는 4,685점에서 3,528점으로 줄었고 최고점은 11,420점에서 10,088점으로 내려갔다.

조정 후 새 시드로 보스·영역·콤보·아이템을 각각 5판씩 더 돌렸다. 실제로 나온 카드 중 목표 빌드에 맞는 카드를 우선 골랐다.

| 목표 | 평균 최종 점수 | 최고점 | 완성 조합 |
|---|---:|---:|---|
| 보스 | 7,214 | 9,590 | 보스 헌터 2/5 |
| 영역 | 7,510 | 8,657 | 가장자리 빌드 3판 중 변두리 2판 |
| 콤보 | 7,726 | 10,246 | 콤보 머신 1/5 |
| 아이템 | 6,656 | 9,064 | 잡화점 3/5 |

판정과 드래프트, 봇은 실제 서버 로직을 사용했다. 가상 시계를 50ms씩 진행하고 종료 결과를 `server/src/gameLog.ts`의 `gameRecord`로 저장했다. 첫 10판의 시드는 `93149 + 판 번호 × 1109`, 추가 판 11~30의 시드는 `289811 + 판 번호 × 3943`이었다. 운영 Render 로그 접근에는 로그인이 필요해 로컬 실행 결과로 비교했다. 자동사냥이 모든 판에서 이겼으므로 이 점수는 빌드의 득점 경로를 보는 자료다.

실전 확인 우선순위는 사람끼리 보스를 경쟁할 때 보스 헌터의 점수, 잡화점의 피버 지속 비율, 독주에서 완성 조합으로 갈아타는 타이밍이다. 잡화점 최고점 판은 보물 상자 26회, 아이템 발동 92회를 기록했다. 운영 서버는 판 완료 시 `[game]` 줄에 증강·최종 점수·점수 출처를 남긴다.

### 개발 테스트 자동사냥

`npm.cmd run dev`로 실행한 뒤 **혼자 하기 → 대기실 → 테스트 자동사냥**을 켠다. 증강은 선택 화면에서 직접 고른다. 협력전에서는 피해와 피격 기절에 면역이고, 아케이드에서 보호막 강타를 완성하면 일반 반격과 반격권을 우선 사용한다. 테스트 판은 일반 승수와 운영 게임 로그 집계에서 제외된다. 기능은 개발 서버와 개발 클라이언트에서 켤 수 있다.

## 시작

기존 저장소의 작업 상태를 확인한 뒤 최신 커밋을 받는다.

```powershell
git status
git fetch origin
git switch main
git pull --ff-only origin main
npm.cmd install
npm.cmd run dev
```

Node.js 20 이상이 필요하다. 화면은 기본 `http://localhost:5173`, 서버는 3001이다. 화면 포트가 사용 중이면 Vite가 출력한 `Local` 주소로 접속한다. PowerShell에서 `npm.ps1` 실행이 차단되면 위처럼 `npm.cmd`를 쓴다. 종료는 Ctrl+C다.

`CLAUDE.md`, `CONTRIBUTING.md`, 이 문서와 `docs/ROADMAP.md`를 먼저 읽는다. `main` 푸시는 Render 자동 배포를 시작한다. 원격 푸시는 사용자가 명시적으로 요청했을 때만 수행한다.

## 이번에 반영한 동작

- 협력전 패배 시 어두운 배경 위에 붉은 `FAIL`이 900ms 동안 나타나고, 종료 후 총 1700ms에 결과창을 연다. 글자 크기는 40~88px이다. 효과 줄이기를 켜면 정적인 글자를 600ms 표시한다. 새 게임이나 화면 전환은 지연된 결과창 표시를 취소한다.
- 보스 처치 시 약 4초간 처치 연출을 재생한 뒤 결과창을 연다. 보스가 마지막 위치에서 멈추고 점점 하얗게 빛나며 2.2초에 완전히 하얘진다. 2.5초에 폭발·충격파, 3초부터 CLEAR 페이드 인이 이어진다. 효과 줄이기는 하얘진 몸체가 잔잔하게 사라지는 방식이며 폭발·파편·흔들림을 생략한다. 재시작·화면 전환 시 연출과 예약된 결과창을 취소한다.
- 클릭해서 제거하는 큰 구체는 청록색 발광 구체다. 가시와 중앙의 ‘클릭’ 글자는 제거했다. 표적 플레이어 색 고리는 남아 있다.
- 큰 구체는 좌우 벽에서 반사하고 위아래로 이탈하면 기존 표적 피해를 준다. 일반 원은 이 반사를 적용하지 않는다. 위치와 클릭 판정은 공유 함수 `circlePos`를 사용한다.
- 발사 2초 전 경고 문구는 ‘보스가 큰 원을 발사합니다! 클릭해서 제거하세요!’다. 위아래로 이탈하기 전 최소 3초를 확보하도록 속도를 제한한다.
- 보스 원 안의 체력 숫자도 `coop:state` 수신 시 상단 체력 바와 함께 갱신한다.
- 내려오는 벽은 2초 경고 후 2단계 속도 900, 3단계 속도 1100으로 빠르게 내려온다. 벽 속도는 모든 난이도가 공유한다. 프레임 사이에 벽이 커서를 통과하는 경우도 이동 경로로 피격을 검사한다.
- 벽은 작은 위험 탄을 가로로 배치한 패턴이지만 피격 종류는 별도 `wall`이다. 벽 피해는 이지 15, 노말 25, 하드 35, 엑스퍼트 45로 일반 탄막보다 높다.
- 보스 체력은 `round(300 × (사람 수 + 봇 수 × 0.5) × 난이도 배율)`이다. 솔로 체력은 이지 240, 노말 300, 하드 360, 엑스퍼트 540이다.
- 수정 파훼 후 살아 있는 사람의 회복량은 이지 40, 노말 20, 하드 10, 엑스퍼트 0이다. 최대 체력은 100이다.

## 스페셜 어택

대기실에서 각자 선택한다. 선택 변경은 준비 완료를 해제한다. 게임 중에는 선택을 변경할 수 없다. 선택값이 없는 이전 데이터는 레이저로 처리한다.

| 공격 | 필요 게이지 | 기본 총피해 | 지속 시간 |
|---|---|---|---|
| 레이저 | 30 | 18 | 2.4초 |
| 유성 폭격 | 50 | 34 | 2초 |
| 회전 칼날 | 75 | 55 | 4초 |

원 획득 +1, 수정 타격 +1, 큰 구체 제거 +4로 충전한다. 가득 차면 Space 한 번으로 자동 공격한다. 스페셜 어택은 큰 피해 구간에도 표의 고정 피해를 준다. 큰 피해 구간에는 원 획득 피해가 2배다. 보호막 구간·일시정지·시작 카운트다운·기절·탈락 중에는 발동할 수 없다. 공격 중 보스가 보호막 단계로 넘어가면 남은 공격은 종료된다. 공격의 피해와 게이지 소모는 서버에서 결정한다.

보조 스페셜도 같은 방식으로 고른다.

| 보조기 | 필요 게이지 | 효과 |
|---|---:|---|
| 수호 결계 | 50 | 커서 위치에 반경 175 마법진 5초. 안의 팀원이 받는 모든 체력 피해 40% 감소, 겹쳐도 40%. 수정 파훼 중 사용 가능 |
| 중력 족쇄 | 55 | 보스 이동과 새 공격 발사를 3초간 멈추고 팀 색 원만 생성. 이미 발사된 탄은 진행. 해제 뒤 10초간 팀 공통 속박 내성 |
| 연계 신호 | 40 | 6초 동안 팀의 자기 색·노란 원 획득 콤보 +1 추가 |

대기실은 설정 카드, 게임 규칙 카드, 스페셜 어택 선택 순서다. 스페셜별 아이콘과 충전량·공격 위력이 선택 카드에 표시된다. 전투 중 게이지에도 선택 아이콘과 Space 안내가 표시된다. 공격 연출은 위험 탄막 아래에 그린다.

약점 노출 아이템은 보스에게 5초 동안 받는 원 피해 +20%를 건다. 팀 전체에 적용되며 다시 획득하면 지속 시간이 갱신된다. 스페셜 어택과 미사일은 고정 피해를 준다.

## 엑스퍼트 단계별 난이도

사용자 피드백에 따라 첫 단계부터 과도하게 어렵던 수치를 조정했다. 목표는 하드보다 조금 어려운 초반에서 적응하고 후반으로 갈수록 강해지는 흐름이다.

| 항목 | 1단계 | 2단계 | 3단계 |
|---|---|---|---|
| 실제 평상시 탄막 간격 | 850ms | 약 577ms | 약 344ms |
| 탄막 기준 속도 | 320 | 380 | 440 |
| 큰 구체 수 | 5 | 7 | 9 |
| 큰 구체 기준 속도 | 280 | 340 | 400 |

큰 구체 속도에는 최소 대응 시간 제한이 적용된다. 탄막 개별 속도는 무늬 설정에 따라 기준 속도와 차이가 있다. 수정 구간은 더 촘촘한 별도 발사 간격을 사용한다. 색 수정은 첫 보호막에서 체력 24, 두 번째에서 48이다. 같은 색 타격은 피해 2, 다른 색 타격은 피해 1을 준다. 색 수정을 모두 깨면 체력 5인 중앙 프리즘 수정이 나온다. 플레이어 색과 관계없이 한 번 누를 때마다 피해 1을 준다. 보호막별 8초 제한 시간은 프리즘까지 공유한다. 수정 파훼는 보호막마다 한 번 진행한다. 실패하면 2초 예고 뒤 수정이 폭발해 팀에 피해를 주고 다음 단계로 넘어간다. 보스는 폭주 중 5초간 무적이다. 폭발 피해는 이지 30, 노말 50, 하드 70, 엑스퍼트 90이다.

### 엑스퍼트 전용 압살

2·3단계의 고유 패턴 후보에 `crush`를 추가했다. 세로 세 줄 중 한 줄을 밝은 안전 구역으로 남기고 나머지 두 줄은 즉사 구역으로 표시한다. 3초 경고 뒤 120ms 동안 위아래 턱이 닫히며 닫힌 순간 위험 구역에 있는 사람에게 피해 100을 준다. 일반 피격 무적과 아이템 방어막을 관통한다. 안전 구역에 있던 사람은 닫힌 뒤 위험 구역으로 이동해도 다시 판정하지 않는다.

구현은 `Seal.lethal`과 `coop:seal` 상태를 재사용한다. `CoopHitBy`의 `crush`로 피격을 기록한다. 일시정지 시 예고·발동 시각이 함께 밀리고, 재접속 상태에도 실린다. 보호막 단계가 시작되면 예고를 취소한다. 화면은 `drawCrush`에서 표시한다.

### 엑스퍼트 전용 유도탄

2·3단계 고유 패턴 후보에 `homing`을 추가했다. 맨 아래에 자리 잡고 가만히 탄막을 피하는 플레이를 견제하는 패턴이다. 1.5초 예고(보스 둘레 대상 색 점선 고리, 내가 대상이면 내 커서에 차오르는 고리) 뒤 살아 있는 사람마다 1발을 쏜다. 봇은 대상이 아니다. 탄은 서버가 틱마다 대상 커서 쪽으로 선회 상한 안에서 꺾으며 움직이고, 한 틱 동안 지나간 선분이 커서에 닿으면 맞는다. 클릭으로 제거할 수 없다.

| 항목 | 2단계 | 3단계 |
|---|---|---|
| 속력(필드/초) | 300 | 340 |
| 초당 최대 선회 | 140도 | 160도 |

수명 5초 뒤 0.4초 동안 흐려지며 판정이 없다. 피해는 이지 15, 노말 20, 하드 25, 엑스퍼트 30이다. 맞히거나 방어막에 막히면 탄이 사라지고, 무적 중이면 계속 쫓는다. 대상 탈락·판 밖 이탈·보호막 단계 시작·탄막 지우기 아이템·판 종료 때 지운다. 일시정지하면 시각을 밀고 위치는 멈춘다. 서버가 `coop:homing`으로 50ms마다 위치를 보내고, 화면은 최대 120ms 외삽해 그린다.

구현은 `shared/src/coop.ts`의 `steerHoming`·`homingHits`·`homingAlpha`, `server/src/coop.ts`의 `tickHoming`, `client/src/render.ts`의 `drawHoming`이다. 수치는 `RULES.coop.homing`에 있다.

## 우클릭 보호막

협력전에서 우클릭(터치 기기는 화면 아래 보호막 버튼)으로 1.5초 동안 피하는 공격의 피해를 모두 막는다. 판당 횟수는 이지 3, 노말 2, 하드 1, 엑스퍼트 0회이며 엑스퍼트에서는 표시하지 않는다. 막으면 피해·기절·무적 없이 '막음!'과 막는 소리가 나고, 동료 피드에는 '보호막으로 막음'이 뜬다. 켜져 있는 동안 아이템 방어막은 소모되지 않는다. 압살·분노·큰 구체 놓침(`crush`·`rage`·`threat`)은 관통한다. 켜진 동안과 끝난 뒤 쿨타임 2초(`cooldownMs`) 동안 다시 누르면 무시하고(일시정지 중에는 쿨타임도 멈춘다), 기절·탈락·일시정지·시작 카운트다운 중에는 쓸 수 없다. 수정 구간에는 쓸 수 있다. 서버는 화면의 피격 신고를 받은 시각으로 판정하므로 끝을 `lagMs`(150ms) 늘려 본다. 화면은 보호막을 요청한 뒤 응답을 기다리는 500ms 동안 맞은 연출을 미리 내지 않는다. 대기실 게임 규칙 카드에 보호막 안내가 있다. 막음 글자·소리는 0.15초 간격으로 묶고, 왼쪽 버튼을 누른 채 우클릭해도 보호막이 켜진다.

켜는 소리가 나고 내 커서를 연한 파란 구체가 감싼다. 구체는 자기 화면에만 보인다(동료 커서 위치는 받지 않는다). 남은 25% 구간에서 줄며 흐려진다. 일시정지하면 종료 시각을 밀고, 재접속하면 플레이어 상태(`CoopFx.barrierUntil`·`barrierLeft`)로 이어진다.

우클릭은 이제 모든 모드에서 클릭 판정이 아니다. 게임 화면에서 브라우저 메뉴도 뜨지 않는다.

구현은 `server/src/coop.ts`의 `activateBarrier`·`damage`, `server/src/room.ts`의 `coopBarrier`, `client/src/pointer.ts`의 `pointerAction`, `client/src/coopUI.ts`의 `renderBarrierHud`, `client/src/render.ts`의 `drawBarrier`다. 수치는 `RULES.coop.barrier`에 있다.

## 콤보 상한과 폭딜 반격

협력전 원 획득 피해의 콤보 보너스는 10콤보마다 +0.2배, 상한 1.8배(40콤보)다. 예전 값은 +0.1배·1.5배였다. 보스 체력은 그대로 두었다.

팀 피해가 몰리면 보스가 반격한다. 분노 게이지는 보스 최대 체력 대비 %로 원 획득 피해(봇 포함)만큼 차고 매초 일정량 빠진다(새는 양동이). 스페셜 어택·미사일·큰 피해 구간·수정 보호막 단계의 피해는 넣지 않는다. 가득 차면 2초 예고(`보스 반격!`) 뒤 탈락하지 않은 모두(봇 포함)의 콤보를 0으로 만든다. 체력 피해·기절은 없다. 그 순간 우클릭 보호막이 켜져 있으면 콤보를 지킨다(판당 보호막 횟수를 탄 막기와 함께 쓴다). 서버는 발동 + `lagMs`(150ms)에 판정해 늦게 도착한 켜기 요청도 인정한다. 아이템 방어막은 반격을 막지 않는다. 예고 중 수정 보호막 단계가 시작되면 취소하고 게이지를 비운다(재사용 대기 없음).

| 난이도 | 빠지는 속도(%/초) | 용량(%) | 재사용 대기 |
|---|---|---|---|
| 이지 | 2.3 | 5 | 30초 |
| 노말 | 1.3 | 2.5 | 25초 |
| 하드 | 0.8 | 1.5 | 20초 |
| 엑스퍼트 | 0.5 | 1.0 | 15초 |

화면은 보스 체력 바 아래 붉은 분노 게이지(재사용 대기 중에는 흐리게 남은 초), 예고 문구, 발동 순간 화면 번쩍임(효과 줄이기는 테두리만), 동료 피드를 보여 준다. 대기실 설명에 반격 안내 한 줄이 있다. 결과 통계에 사람마다 `counterLost`·`counterSaved`가 쌓인다.

구현은 `shared/src/coopCounter.ts`(`counterValue`·`fillCounter`·`barrierCovers`), `server/src/coop.ts`의 `hurtBoss`(combo 인자)·`tickCounter`, `client/src/coopUI.ts`의 `counterGauge`, `client/src/render.ts`의 `drawCounterFlash`다. 수치는 `RULES.coop.counter`와 `comboPer`·`comboCap`에 있다. 설계 `docs/superpowers/specs/2026-11-18-coop-combo-counter-design.md`.

```powershell
npm.cmd test
npm.cmd run typecheck
npm.cmd run build
```

브라우저 도구는 로컬 연결 시간 초과와 Windows 브라우저 URL 판별 실패로 화면 검증을 완료하지 못했다. 집에서 실제 플레이로 다음을 확인한다.

- 공격·보조 스페셜의 선택·충전·Space 발동, 아이콘과 공격 연출, 멀티플레이에서 동시에 사용하기.
- 일시정지·재접속 뒤 공격과 게이지 상태 이어짐, 보호막 단계 전환 시 남은 공격 종료의 체감.
- 큰 구체 좌우 반사 뒤 클릭 제거와 아래쪽 이탈 피해, 발사 경고 가독성.
- 급강하 벽의 속도·피격 체감과 압살의 안전 구역·카운트다운·닫힘 연출, 멀티플레이 탈락 판정.
- 패배 시 FAIL 크기·페이드 인·결과창 순서, 효과 줄이기, 연출 중 다른 사람이 재시작했을 때 화면 전환.
- 처치 시 4초 연출의 백색 발광·폭발·CLEAR·결과창 순서, 소리와 효과 줄이기, 재시작으로 취소한 뒤 남은 파편이 없는지 확인.
- 하드 솔로와 엑스퍼트 단계별 압박, 체력·제한 시간 밸런스. 수치는 초기 조정값이므로 플레이 기록과 후기로 조정한다.

유도탄은 실제 플레이로 속도·선회 체감, 멀티플레이 동시 추격, 일시정지·재접속 뒤 이어짐을 확인한다. 우클릭 보호막은 우클릭 체감과 연타, 휴대폰에서 버튼 위치·크기, 구체 가독성, 일시정지·재접속 뒤 이어짐, 다른 모드에서 우클릭이 아무 일도 하지 않는지 확인한다.

콤보 상한과 폭딜 반격은 실제 플레이로 난이도별 감각(이지는 강화 둘이 겹쳐야, 노말은 최대 콤보 + 강화 하나, 하드는 최대 콤보로 거의 다 잡으면, 엑스퍼트는 최대 콤보면 금방 반격), 게이지·예고 가독성, 보스 처치 시간이 얼마나 빨라졌는지 확인한다.
