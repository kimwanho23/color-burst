# 협력전 개편 (패턴을 파훼하는 보스전) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 협력전을 "보스가 뿜는 내 색 원을 잡아 피해 → 체력 구간마다 보호막·내 색 수정 파훼 → 큰 피해 구간 → 단계별 보스·맵 패턴" 보스전으로 바꾸고, 결과 화면에서 사람마다 가한 대미지를 보여 준다.

**Architecture:** 판정·수치는 `shared/src/coop.ts`(순수 함수)와 `RULES.coop`, 한 판 상태는 `server/src/coop.ts`의 `CoopRun`이 가진다(지금 구조 유지). 보스가 뿜는 원은 `from`을 가진 일반 색 원(`makeCircle`과 같은 모양)이라 기존 잡기 판정을 그대로 타고, `room.ts`는 협력전일 때 잡은 결과를 `CoopRun.catchOrb`로 넘긴다. 수정은 새 원 종류 `'crystal'`. 투표·카드는 지운다.

**Tech Stack:** TypeScript, Socket.IO, Vite, `node:test` (`npm test`)

**Spec:** `docs/superpowers/specs/2026-11-17-coop-raid-design.md`

## Global Constraints

- 수치는 `RULES.coop`에서만. 처음 값은 아래 Task 1 표 그대로, 판 기록을 보고 나중에 조정.
- 협력전에서 보스를 눌러도 피해·콤보·헛클릭 모두 없음. 판 가운데 원(색·노랑·무지개·아이템·황금)은 협력전에서 나오지 않음.
- 개인 피버 없음(협력전에서 게이지가 차지 않고 화면에서 숨김).
- 생명 3, 맞은 뒤 무적 2초, 제한 시간 180초는 그대로.
- 게임 방법·도감 문구에 배율 숫자를 쓰지 않는다.
- 커밋: Conventional Commits 한국어, 작성자 `Kim Wan ho`, 커밋 전 `npm run typecheck`·`npm run build` 통과. 작업 브랜치 `feat/coop-raid`(main에서), `main` 푸시 금지.

## Review Focus

1. **보호막 중 탈락·나감으로 수정 주인이 사라짐** — 남은 수정만 깨면 보호막이 풀려야 하고, 깰 사람이 없으면 바로 풀림(판이 멈추지 않음) → Task 2 테스트 `보호막 중 주인이 탈락하면 그 수정은 깬 것으로`.
2. **보호막·큰 피해 구간 중 일시정지/다시 시작** — 제한 시간·큰 피해 구간 끝 시각이 멈춘 만큼 밀림 → Task 2 테스트 `일시정지하면 보호막 제한 시간과 큰 피해 끝이 밀림`.
3. **큰 피해 구간 피해가 단계 경계를 넘음** — 2단계 시작 직후 큰 피해로 33% 아래로 내려가지 않고 다음 보호막이 바로 올라옴 → Task 2 테스트 `큰 피해 구간에도 단계 경계에서 멈추고 보호막`.
4. **봇만 남거나 사람 1명** — 사람 1명 + 봇 0명으로도 원이 충분히 나오고 보호막이 풀릴 수 있음 → Task 2 테스트 `사람 1명이면 수정 1개, 깨면 큰 피해`.
5. **보스 몸 클릭** — 보스를 눌러도 콤보가 끊기지 않고 피해도 없음 → Task 3 테스트 `보스를 눌러도 피해·콤보 변화 없음`.

- Produces (`CoopHost`에서 `pauseForVote`·`resumeAfterVote`·`feverOn` 제거, 추가):

  cursorOf(id: string): Point | null;           // 사람 커서 (없으면 null = 판정 안 함)

- Produces (`CoopRun`):
  ```ts
  catchOrb(p: PlayerState, c: Circle, now: number): { dmg: number; killed: boolean };  // 잡은 원(내 색·노랑) → 피해·기록
  hitCrystal(p: PlayerState, c: Circle, now: number): boolean;                         // 주인만, hp−1, 0이면 깨짐
  isShielded(): boolean; inBurst(now: number): boolean;
  busy(): boolean;   // 지금은 항상 false (투표가 없어짐)
  ```
  `popThreat`·`damage`·`threatEscaped`·`shift`·`state`·`result`·`dispose`·`recheck`는 유지(카드 인자 제거, 기록 추가).
- 동작
  - **원 뿜기**(`tick`): 보호막이 아니면 사람·봇 한 명당 `orb.gapMs × levels[level].orbMult` 간격(큰 피해 구간이면 `burst.orbGapMs`)으로 그 사람 색 원을, `yellowPct`% 확률로 노란 원을 보스 자리(`circlePos(boss)`)에서 사방(0~2π 무작위) `orb.speed`로 낸다. 탈락한 사람 색은 내지 않는다.
  - **`catchOrb`**: 보호막이면 피해 0. 아니면 `applyRaidDamage(boss, orbDamage(p, c.kind, inBurst), phase)`. 기록 `dmg`(+큰 피해면 `burstDmg`), 점수는 `Math.round(dealt) × RULES.boss.hit`(점수 출처 `boss`), `coop:orb` 전송. 경계에 닿으면(`crossed`, 3단계 0 아님) `beginShield(now)`. 체력 0이면 `killed`.
  - **`beginShield(now)`**: `shield = { until: now + crystalSec*1000, no: (phase-1) }`, 원 뿜기·보스 패턴 일정 정지, 날아가는 추적 원·내려찍기·안전지대 지움(맵 패턴은 남김). 살아 있고 연결된 사람 + 봇마다 `placeCrystals` 자리에 `makeCrystal`(횟수 `crystalHits(level, no)`). 깰 사람이 아무도 없으면 바로 `breakShield`. `coop:state`.
  - **`hitCrystal`**: 주인이고 보호막 중일 때만 hp−1, 0이면 원 지우고 기록 `crystals++`, 남은 수정이 없으면 `breakShield(now)`.
  - **`breakShield(now)`**: `breaks.push(now - 시작)`, `shield = null`, `burstUntil = now + burst.ms`, 그동안 보스 패턴·맵 패턴 멈춤(`setPattern(null)`), 끝나면 `phase++`, 패턴 일정 다시.
  - **시간 초과**: `now ≥ shield.until`이면 `rageAt = now + rageWarnMs`(경고), 그때 살아 있는 사람 모두 `damage(p, 'rage')`, `breaks.push('rage')`, 남은 수정 hp를 처음 횟수로, `shield.until` 다시.
  - **보호막 중 주인 탈락·끊김**(`recheck`·`damage`에서 탈락 시): 그 사람 수정을 지우고 남은 게 없으면 `breakShield`.
  - **보스 패턴 일정**(보호막·큰 피해 구간이 아닐 때): 레이저(지금 그대로), 추적 원 2단계부터가 아니라 **1단계부터**(스펙 표), 내려찍기 2단계부터 `slamEvery`(3단계 × `phase3Mult`), 안전지대 3단계 `safeEvery`, 맵 패턴 2·3단계 `mapEvery`로 `phasePatterns[phase]`에서 하나.
  - **내려찍기**: 살아 있는 사람마다 `cursorOf` 자리에 `Slam`(`at = now + slam.warnMs`) 만들어 `coop:slam`. `at`에 커서가 원 안이면 `damage(p,'slam')`+`stun`.
  - **안전지대**: `rollSafe(levels.safeCount, now + safe.warnMs, rand)`를 `coop:safe`. `at`에 커서가 `inSafe` 밖이면 `damage(p,'safe')`+`stun`. 끝나면 `coop:safe(null)`.
  - **`shift(delta)`**: 패턴 시각, `shield.until`, `burstUntil`, `rageAt`, 대기 중 `Slam.at`·`SafeZones.at`을 민다.
  - **`result`**: `players`(사람·봇 모두, `dmg`·`burstDmg`는 소수 그대로), `breaks`, `maxHp`.

- [ ] **Step 1: 실패하는 테스트 작성** (방 단위. `coopRoom(humans, bots)`·시계는 기존 방식)
