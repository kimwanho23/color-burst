# 협력전 구현 계획

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 방 규칙 옵션 `coop`으로, 모두가 개인 생명 3개를 갖고 180초 안에 3단계 레이드 보스를 잡는 협력전을 넣는다.

**Architecture:** 판정·계산은 `shared/src/coop.ts`(순수 함수), 한 판의 생명·단계·카드·투표·공격 일정은 `server/src/coop.ts`의 `CoopRun`이 맡는다. `room.ts`는 `CoopHost` 인터페이스를 구현해 넘기고 tick·클릭·원 이탈·레이저/장판 맞음·일시정지 시각 밀기·판 끝에서만 `CoopRun`을 호출한다. 레이저(`rollVolley`)·장판(`makePattern`)·탈락(`eliminate`, `outAt`)·일시정지 재개(`beginResume`/`finishResume`)는 기존 코드를 다시 쓴다.

**Tech Stack:** TypeScript, Node(socket.io) 서버, Vite 화면, `node --test` + `tsx`.

**Spec:** `docs/superpowers/specs/2026-11-09-coop-design.md`

- 커밋 메시지: `<타입>(<범위>): <한국어 요약>` (`CONTRIBUTING.md`). 한 커밋에 한 목적. 커밋 끝에 `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

- 테스트는 기능을 모두 구현한 뒤 Task 9에서 한꺼번에 쓴다(사용자 방침). 기능 Task는 typecheck·build·기존 `npm test` 통과로 확인한다.

## Review Focus

1. 투표 중에 사람이 나가거나 끊김 → 남은(연결된) 사람이 모두 투표하면 바로 마감, 연결된 사람이 0명이면 시간이 다 될 때 무작위로 마감. (Task 9 `coop 투표: 나간 사람은 기다리지 않음`)
2. 투표 중 일시정지·해제 요청 → 무시(투표가 끝나야 재개 카운트다운). (Task 9 `coop 투표: 일시정지 요청 무시`)
3. 큰 피해 한 방이 두 단계 경계를 넘음(예: 70% → 20%) → 체력은 다음 경계(33%가 아니라 67%)에서 멈추고 단계는 하나만 오른다. (Task 9 `applyRaidDamage: 경계에서 멈춤`)
4. 같은 순간 레이저와 공격 원 이탈이 겹침 → 무적 때문에 생명은 한 번만 준다. (Task 9 `coop 생명: 겹친 피격은 한 번`)
5. 협력전을 켠 채 아케이드·팀전·서바이벌을 새로 고름 → 협력전이 꺼지고 고른 것이 켜짐. 프리셋을 골라도 협력전·난이도는 유지. (Task 9 `sanitizeRules: 협력전 배타`)

### Task 4: 서버 `CoopRun` (server/coop.ts)

**Files:**
- Create: `server/src/coop.ts`

**Interfaces:**
- Consumes: Task 2 함수, Task 3 타입, `makePattern(id, at, rand)`(`patterns.ts`).
- Produces:

```ts
export interface CoopHost {
  players(): PlayerState[];
  emit<E extends keyof ServerToClient>(ev: E, ...args: Parameters<ServerToClient[E]>): void;
  nextId(): number;
  addCircle(c: Circle): void;                    // circles에 넣고 circle:spawn
  removeCircles(pred: (c: Circle) => boolean): void;
  fireLaser(lines: LaserLine[], at: number): void; // room.lasers에 넣고 laser:warn
  clearLasers(): void;
  setPattern(p: MapPattern | null): void;        // pendingPattern 또는 지우기
  pauseForVote(now: number): void;               // pausedAt = now, pausedBy = null
  resumeAfterVote(): void;                       // 기존 beginResume (3초 카운트다운)
  eliminate(p: PlayerState, now: number): void;
  finish(win: boolean): void;                    // room.end()
  emitPlayers(): void;
  feverOn(p: PlayerState, now: number): boolean;
}

export class CoopRun {
  constructor(host: CoopHost, level: CoopLevel, rand?: () => number);
  start(now: number): void;            // 생명 = lives, immuneUntil = 0, 레이드 보스 생성, 첫 공격 시각, coop:state
  tick(now: number): void;             // 공격 시각이 되면 레이저/공격 원/장판, 투표 마감 시각 확인
  hitRaid(p: PlayerState, c: Circle, now: number): { dealt: number; gained: number };
  popThreat(p: PlayerState, c: Circle, now: number): number;   // 점수 threatPoints (src.threat)
  damage(p: PlayerState, by: 'laser' | 'hazard' | 'threat', now: number, circleId?: number): boolean; // 생명이 줄었으면 true (호출 쪽은 true일 때만 스턴)
  threatEscaped(c: Circle, now: number): void;
  pick(playerId: string, card: CoopCardId): void;
  voting(): boolean;
  shift(delta: number): void;          // finishResume에서: 다음 공격 시각·무적 끝 시각을 민다
  state(): CoopState;
  result(now: number, startAt: number, win: boolean): CoopResult;
  feverGainMult(): number;             // 1 + chargePct × 빠른충전수 (room이 G.feverGain에 곱함)
}
```

동작 (설계 4~6절)
- `tick`: 투표 중에는 room의 tick이 멈춰 있어 불리지 않는다. 단계별로 레이저(1단계부터), 공격 원(2단계부터, 표적은 살아 있는 사람 중 돌아가며; 각도는 보스에서 아래쪽 반원 안에서 고르게 퍼뜨림), 장판(3단계, `hazards` 중 무작위, `makePattern(id, now + laserWarnMs)`)을 `attackGap`대로 낸다. 레이저는 `rollVolley(rand, G.laserHalf, levels[level].volleyOdds)`.
- `hitRaid`: 보스 무적(`phaseInvulnMs`) 중이면 피해 0. `raidDamage` → `applyRaidDamage`. 점수 `gained = Math.round(dealt) × RULES.boss.hit`, `src.boss`, `stats.bossHits++`. `crossed`면: 2단계 이상으로 넘어갈 때 `clearLasers`, 공격 원 제거, `setPattern(null)`, `phaseInvulnMs` 뒤 투표 시작(`drawCards`, `pauseForVote`, `coop:vote`). 3단계에서 체력 0이면 `finish(true)`.
- `damage`: 봇·탈락·`now < immuneUntil`이면 false. 아니면 `lives--`, `immuneUntil = now + immuneMs(cards)`, `coop:hit`. `lives === 0`이면 `eliminate`, 살아 있는 사람이 0이면 `finish(false)`.
- `threatEscaped`: 표적이 살아 있는 사람이면 `damage(target, 'threat', now, c.id)`.
- `pick`: 투표 중이고 사람이고 options 안의 카드면 표 기록(다시 고르면 바뀜), `coop:votes`. 연결된 사람 모두 투표했으면 바로 마감.
- 마감: `tallyVotes` → 카드 추가, `heal`이면 살아 있는 사람 `lives = min(maxLives, lives + 1)`, `coop:card`, `coop:state`, `voteResultMs` 뒤 `resumeAfterVote()`.
