# 정사각형 판 · 황금 원 배율 · 조합 보너스 조정 설계

상태: 구현 완료 (2026-11-08)

## 목적

1. 게임 상자(div)와 거의 같은 크기의 **정사각형 판**으로 바꿔 화면을 꽉 채우고, 판 경계를 분명히 한다.
2. 후반에 가치가 사라지는 **황금 원**이 다른 원처럼 배율을 받게 한다.
3. 약한 **조합 보너스**(콤보 머신·보스 헌터·견제왕·철옹성·미식가)를 세게 바꾼다.
4. 너무 센 **무지개 사냥 레전드**(즉시 피버)를 낮춘다.

## 1. 정사각형 판

### 크기
- 판(`FIELD`)을 1600×900 → **1100×1100**으로 바꾼다.
- 보통 데스크톱(브라우저 안쪽 1920×960)에서 판이 게임 상자 높이(약 784px)를 채우면 화면 배율이 약 0.71이다. 지금(약 0.73)과 거의 같아서 원·커서·범위가 화면에서 지금과 같은 크기로 보인다.
- 그래서 **판 단위로 적힌 크기·속도 수치(원 반지름, 발사 속도, 넓은 손·자석 범위, 오오라, 맵 패턴 크기 등)는 그대로 둔다.**
- 중앙에서 끝까지 거리는 사방 550이 된다(지금은 위아래 450, 좌우 800). 원이 화면에 머무는 평균 거리는 지금과 비슷하다(직사각형 평균 약 560, 정사각형 평균 약 610). 그래서 원 개수·발사 간격도 그대로 둔다.

### 게임 상자와 테두리
- 게임 상자(`#stage`)를 정사각형으로 만들고, 위쪽 바·점수판·아래 피버 바를 뺀 남는 높이와 화면 폭 중 작은 쪽에 맞춘다(가운데 정렬).
- 판에 밝은 테두리(두께 3, 둥근 모서리, 바깥쪽 옅은 빛)를 그린다. 상자와 판 비율이 어긋나 남는 여백이 생기면 한 단계 어둡게 칠한다.
- 피버 표시: 지금 상자 전체 가장자리가 주황으로 빛나는 효과를 **판 테두리가 주황으로 빛나는 것**으로 옮긴다.
- 위쪽 바·점수판은 상자와 같은 폭으로 맞춘다(지금 `#app` 최대 폭 1200px 제한은 상자 크기 기준으로 바꾼다).

### 판 모양에 묶인 것 정리
- 점수 구역: 화면 비율 타원 → **원**이 된다(계산식은 같고 `FIELD`만 바뀜). 경계선은 지금보다 조금 진하게 그린다.
- 코드에 직접 적힌 판 좌표를 `FIELD` 기준으로 바꾼다.
  - 레이저 통과점 범위 (`cursor.ts`의 200~1400, 150~750)
  - 화면 문구 위치·폭죽 중심 (`main.ts`의 (800, y), (800, 450))
  - 시야 방해 낙서 범위 (`render.ts`의 200~1400, 120~780)
  - 주석의 800/450
- 레이저 두께는 판 높이의 비율(15/22/30%)이라 그대로 비율을 유지한다. 레이저·회전 막대 길이는 새 판 대각선(약 1556)을 덮는지 확인한다.
- 맵 패턴 생성 범위는 이미 `FIELD` 기준이라 그대로다.
- 봇은 원 위치로 움직이니 따로 바꿀 것이 없다(확인만).

## 2. 황금 원 배율

- 기본 +20에 **일반 원과 같은 배율을 모두** 곱한다.
  - 피버 배율(피버 중) 또는 여운 배율
  - 점수 구역 배율 (잡은 자리)
  - 아이템(점수 2배·황금 손)
  - 유리 대포·표적 자처·대역전 (`scoreBoostOf`)
  - 역전 기회·마지막 불꽃·출발 신호 (`extraMult`)
  - 잭팟
- 콤보·피버 게이지는 지금처럼 바뀌지 않는다.

## 3. 조합 보너스

| 조합 | 필요한 증강 | 지금 | 바뀜 |
|---|---|---|---|
| 콤보 머신 | 콤보 장인·보험 | 콤보 보너스 +5 | **콤보 보너스 ×2** (레전드 효과로 더한 것까지) |
| 보스 헌터 | 해머·사냥꾼·파쇄 | 보스 피해 +1 | **피해 +1, 보스 타격 점수 ×1.5, 막타 점수 ×2** |
| 견제왕 | 강탈·반격 전문가·철면피 | 견제마다 +2 | **견제·반격 점수 ×3, 표적 시간 −1초** (폭죽·필드 클리어로 잡은 것은 제외 그대로) |
| 철옹성 | 방패·보험·리바운드 | 라운드마다 1번 끊김 막음 | **콤보가 끊기지 않고 20%만 줄어듦** (헛클릭·견제·반사·오오라 모두) |
| 미식가 | 편식가·노란 맛 | 편식가의 노란색 −1 대가 없음 | **노란 원 = 내 색**: 점수(편식가 보너스 포함)와 피버 게이지를 내 색 원처럼 |
| 피버 마스터 · 행운아 · 변두리 | | | 그대로 |

- 철옹성은 보험보다 먼저 적용한다(보험 %와 상관없이 20%만 줄어듦, 보험이 더 많이 남기면 보험 쪽).
- 철옹성 표시("철옹성! 콤보 유지")는 콤보가 줄어들 때 띄운다. 남은 횟수 표시는 없앤다.
- 문구(조합 설명, 도감, 설명 카드)는 수치 상수에서 만든다.

## 4. 레전드 조정

- **무지개 사냥 레전드:** "무지개 원을 잡으면 즉시 피버" → **"무지개 원의 피버 게이지 2배"** (+25 → +50). 즉시 피버는 무지개 원이 잦은 방(파티·카오스 10%, 무지개 비 테마)에서 피버가 끊이지 않아 너무 셌다. 편식가 레전드(내 색 게이지 2배)와 같은 결.
- 레전드 문구(`LEGEND_TEXT.rainbowHunt`)는 수치 상수에서 만든다.

## 5. 테스트

- **판:** `FIELD`가 1100×1100, 점수 구역 경계가 원(같은 거리면 어느 방향이든 같은 구역), 레이저 통과점이 판 안, 원이 판 밖으로 나가는 거리.
- **황금 원:** 피버·구역·아이템·잭팟 배율이 곱해짐, 콤보·게이지 그대로.
- **조합:** 다섯 개 각각의 새 효과(콤보 보너스 ×2, 보스 타격·막타 배율, 견제·반격 ×3과 표적 시간, 철옹성 20% 감소, 미식가 노란 원 점수·게이지).
- **무지개 사냥 레전드:** 무지개 원 게이지 +50, 즉시 피버 아님(게이지가 50 이상이면 그때 피버).
- **화면 확인:** 데스크톱·세로로 긴 창에서 정사각형 상자·테두리·여백, 피버 테두리, 점수 구역 원.
