# 대기실 규칙 표시와 게임 설정 창 가독성 개편 설계

2026-11-21 · 클라이언트 전용 (서버·프로토콜 변경 없음) · 이 문서만 읽고 구현할 수 있게 썼다

## 의도

- 대기실은 규칙 요약 한 줄 아래에 **같은 크기·같은 모양의 알약(칩) 12개**를 한 줄로 늘어놓는다(`rulesChips`). 시간·피버처럼 판의 성격을 정하는 값과 무지개 3% 같은 세부 값이 구분되지 않고, 꺼진 항목은 취소선뿐이라 읽기 어렵다.
- 게임 설정 창(`renderRules`)도 위쪽 큰 버튼(모드·인원 모드·프리셋)은 괜찮지만 **고급 설정이 선택 상자 12개와 체크 상자 9개를 한 줄씩 늘어놓은 평평한 목록**이다.
- 사용자가 정한 것: **버튼을 누르면 설정 창이 뜨는 구조는 유지**하고, 읽기 쉽게 **아이콘형 UI나 이미지**를 쓴다. Figma는 쓰지 않는다.
- 결과: 방장이든 친구든 대기실을 열자마자 "무슨 규칙의 판인가"를 1~2초에 읽고, 설정 창에서는 "무엇을 바꾸는가"를 아이콘으로 찾는다.

## 목표 / 하지 않는 것 / 실패 기준

**목표**
1. 대기실 규칙 표시를 **3단 위계**(모드 → 핵심 숫자 → 켜진 요소 아이콘)로 바꾼다.
2. 대기실의 아이콘 어휘와 설정 창의 아이콘 어휘를 **1:1로 같게** 한다. 대기실에서 본 아이콘이 설정 창에서 같은 모양의 토글이다.
3. 설정 창의 고급 설정을 **6개 묶음**으로 나누고, 선택지가 4개 이하이면 가로 버튼(세그먼트), 켜고 끄는 값은 아이콘 토글로 바꾼다.
4. 프리셋과 다른 값에는 **변경 표시**(노란 점)를 단다.
5. 설정 창 맨 위에 대기실과 같은 요약 패널을 **미리보기**로 둔다. 값을 바꾸면 바로 바뀐다.

**하지 않는 것**
- 서버, `RoomRules`, `PRESETS`, `RULE_CHOICES`, 소켓 이벤트(`lobby:rules`)는 바꾸지 않는다.
- 자리 4칸(`slots`), 슬롯 패널, 헤더 버튼, [게임 시작]/[준비], 협력전 규칙 목록(`coopRules`)과 스페셜 선택(`specialPicker`)의 동작은 바꾸지 않는다. 같은 디자인 토큰만 따라 간다.
- 비트맵 이미지 파일을 새로 만들거나 넣지 않는다 (아래 "이미지" 참고).
- 새 글꼴, 새 색은 추가하지 않는다.

**실패 기준** (기술적으로 돌아가도 실패)
- 켜짐/꺼짐이 색만으로 구분되는 것 (슬래시·텍스트로도 구분해야 한다).
- 12개 칩이 12개 타일로 이름만 바뀌고 위계가 없는 것.
- 설정 창에서 기존에 바꿀 수 있던 값을 바꿀 수 없게 되는 것.
- 모바일(너비 375px)에서 가로 스크롤이 생기는 것.

## 디자인

### 방향

이 게임의 정체성은 **짙은 남색 판 위의 선명한 도형(삼각형·사각형·마름모·십자)과 노란 강조**다. 새로운 장식을 얹지 않고, 기존 토큰과 도형 언어만으로 위계를 만든다. 크게 보이는 것은 **판의 성격을 정하는 숫자 3개**, 나머지는 조용한 아이콘 줄이다. 한 곳에만 힘을 준다.

### 대기실 규칙 패널 (3단 위계)

```
┌─ 규칙 패널 ─────────────────────────────────────────────────────────┐
│ [▣ 아이콘] 개인전 · 클래식         프리셋 [기본]       [게임 설정][점수표 보기] │  ← 1단: 모드
│                                                                       │
│  ┌────────────┐ ┌────────────────┐ ┌────────────────┐                  │
│  │ ⏱  60초     │ │ 🔥 피버 ×3      │ │ 〽 속도 ×1       │                  │  ← 2단: 핵심 숫자 3칸
│  │ 한 판       │ │ 7초 지속        │ │ 원 개수 ×1      │                  │     (큰 숫자 + 작은 설명)
│  └────────────┘ └────────────────┘ └────────────────┘                  │
│                                                                       │
│  판에 나오는 것     [👑][🎁][⚡][🚧][🌈][✦]                                 │  ← 3단: 켜진 요소 아이콘
│  감점 규칙         [🎯 표적 4초][⊘ 빈 곳]    꼴찌 보정 [↗]                   │     (꺼진 것은 슬래시+흐림)
└───────────────────────────────────────────────────────────────────────┘
```

- **1단 (모드)**: 큰 아이콘(`UI.classic/arcade/coop`) + 제목(`rulesSummary().title`) + 프리셋 이름 배지. 프리셋과 다르면 배지가 `커스텀`이 된다(지금 `matchPreset` 결과 그대로). 버튼 두 개는 오른쪽에 둔다.
- **2단 (핵심 숫자 3칸)**: 판 시간 · 피버 · 속도/원 개수. 숫자는 `--display` 24~28px, 아래에 `--muted` 12px 설명. 아케이드는 `5라운드 × 30초`, 클래식 서바이벌은 `20초마다 탈락`처럼 시간 칸의 내용이 바뀐다(`rulesChips`의 `time` 계산을 그대로 옮긴다). 프리셋 기본값과 다른 칸은 오른쪽 위에 **노란 점**을 단다.
- **3단 (켜진 요소)**: 아이콘 타일만 늘어놓는다(글자는 타일 아래 11px 또는 툴팁). 두 묶음으로 나눈다.
  - **판에 나오는 것**: 보스, 아이템, 특수 원, 레이저, 맵 패턴, 무지개. (특수 원은 지금 칩에 없다. 설정에는 있으니 추가한다.)
  - **감점 규칙**: 견제 페널티(표적 N초), 빈 곳 감점, 꼴찌 보정.
  - 켜짐: 아이콘 `--yellow`, 타일 테두리 `--line`. 꺼짐: 아이콘 `--muted` + **대각선 슬래시**(SVG) + 흐림 55%. 부가값(맵 패턴 35%, 무지개 3%, 레이저 보통)은 타일 오른쪽 아래 작은 숫자 배지.
  - 접근성: 각 타일은 `role="img"`와 `aria-label="보스 켜짐"` / `"레이저 꺼짐"`처럼 상태를 글로 말한다.
- **협력전**: 2·3단이 없다. 난이도 이름, 제한 시간, 체력만 2단 3칸 형식으로 보인다(지금과 같은 정보, 같은 모양).
- **모바일(≤640px)**: 2단은 3칸이 가로로 유지되되 글자를 줄이고, 3단은 줄바꿈된다. 버튼 두 개는 1단 아래 줄로 내려간다.

### 이미지 / 일러스트

- **새 이미지 파일은 만들지 않는다.** 이 게임의 그림은 전부 코드로 그린 SVG(`shapeSVG`, `guideArt.ts`의 `ball`·`cur`)다. 같은 방식을 따른다.
- 모드 아이콘은 lucide(`UI.classic/arcade/coop`)를 쓰되, 1단에서는 **대표 도형 한 개**(내 색 삼각형)를 아이콘 옆에 작게 놓아 "이 게임"임을 잇는다. 선택 사항이다.
- 프리셋은 이미 아이콘(`UI.chill/basic/party/hardcore/...`)이 있으니 그대로 쓴다.
- 더 풍부한 그림이 필요하면 `guideArt.ts`의 도형 도우미로 규칙별 48px 일러스트(예: 레이저 = 가로 번개선, 맵 패턴 = 벽 도형)를 만들어 타일 아이콘으로 쓸 수 있다. 이 문서의 범위에서는 lucide 아이콘으로 시작하고, 일러스트화는 후속 작업으로 남긴다. (내 판단)

### 게임 설정 창

버튼으로 여는 방식과 창 크기(`rules-card`, 최대 720px)는 유지한다. 위에서 아래 순서는 이렇게 바꾼다.

```
┌ 게임 설정 ───────────────────────────────────────────── [닫기] ┐
│ ┌ 미리보기 ───────────────────────────────────────────────────┐ │
│ │ (대기실 규칙 패널과 같은 요약, 값을 바꾸면 바로 바뀜)            │ │
│ └─────────────────────────────────────────────────────────────┘ │
│  게임 모드     [클래식] [아케이드] [협력전]        ← 지금 것 유지   │
│  인원 모드     [개인전] [팀전 2:2] [서바이벌]       ← 지금 것 유지   │
│  방 규칙       [기본][파티][하드코어][느긋하게][커스텀] ← 지금 것 유지 │
│  ▸ 세부 설정 (펼침/접힘 유지)                                      │
│    ⏱ 판 진행      한 판 시간 [30][45][60][90]   속도 [×1][×1.25]…   │
│    🔥 피버        배율 [×2][×3][×5]  시간 [4][7][10]초  충전 [느림][보통][빠름] │
│    🎯 견제·감점   [견제 페널티 ◉] 표적 시간 [2][4][6]  [빈 곳 ◉] [꼴찌 보정 ◉] │
│    🎁 나오는 요소 [보스][아이템][특수 원][웨이브] 토글 + 무지개 [없음][3%]… │
│    ⚡ 위험 요소   [레이저 ◉] 두께 [얇게][보통][굵게] 빈도 [..] [맵 패턴] [방해] │
│    🎲 아케이드    라운드 테마 [..]  랜덤 이벤트 [..]  (아케이드일 때만)  │
└──────────────────────────────────────────────────────────────────┘
```

- 위쪽 세 줄(모드·인원 모드·프리셋)의 버튼, 문구, 동작은 지금 그대로다.
- **세부 설정**은 지금처럼 `<details>`로 접고, 열린 상태를 다시 그릴 때 유지한다. 안은 6개 묶음이고 묶음마다 **아이콘 + 제목**(`--display` 16px)을 둔다. 묶음 사이는 간격과 얇은 구분선으로만 나눈다.
- **입력 형태**
  - `RULE_CHOICES[key]`가 4개 이하: **세그먼트 버튼**(가로, `aria-pressed`, 선택된 것은 노란 테두리). 값 표기는 기존 `fmt`를 쓴다.
  - 5개 이상(`mapPct`, `roundSec`가 해당하면): 기존 `<select>` 유지.
  - 켜고 끄는 값(`BOOL_FIELDS`): **아이콘 토글 타일** (대기실 3단 타일과 같은 모양, 클릭하면 켜짐/꺼짐, `aria-pressed`). 글자 라벨은 타일 안 아래쪽 또는 옆에 둔다.
  - 종속 값: 켜짐 토글 오른쪽에 붙인다. 예: 레이저 켜짐 → 두께·빈도가 보이고, 꺼짐 → 두 값을 숨긴다(지금은 항상 보여 헷갈린다). 견제 페널티 꺼짐 → 표적 시간 숨김.
- **변경 표시**: 현재 프리셋이 있으면 그 프리셋의 값과 다른 항목에 노란 점. 커스텀이면 `기본` 프리셋을 기준으로 삼는다. (내 판단: 기준 프리셋은 `matchPreset`이 `null`일 때 `DEFAULT_RULES`다.)
- **읽기 전용**: 방장이 아니면 지금처럼 `disabled`로 보이게 하고 제목 옆에 `(방장이 정해요)`를 둔다. 토글 타일도 눌러지지 않게 하고 모양은 그대로다.
- **협력전**: 지금처럼 모드·난이도만 보인다. 미리보기도 협력전 형식(난이도·시간·체력).
- 열림/닫힘: 닫기 버튼과 Esc(지금 동작 유지). 열 때 포커스를 창 안으로 옮기고 닫으면 `#rulesBtn`으로 돌려보낸다.

## 데이터 모델 (구현자 참고)

`lobbyUI.ts`에 화면과 분리된 순수 함수를 둔다 (`shared/test/lobbyui.test.ts`로 테스트).

```ts
export type RuleTileId = 'boss' | 'item' | 'special' | 'laser' | 'map' | 'rainbow' | 'mark' | 'miss' | 'comeback';
export interface RuleStat { icon: RuleChipIcon; big: string; small: string; changed?: boolean }
export interface RuleTile { id: RuleTileId; icon: RuleChipIcon; label: string; on: boolean; badge?: string; changed?: boolean }
export interface RulePanel {
  title: string;                 // rulesSummary().title
  preset: string;                // 프리셋 이름 또는 '커스텀'
  stats: RuleStat[];             // 핵심 숫자 3칸 (협력전은 난이도·시간·체력)
  groups: { label: string; tiles: RuleTile[] }[]; // [판에 나오는 것, 감점 규칙], 협력전은 빈 배열
}
export function rulePanel(r: RoomRules): RulePanel;
```

- `rulesChips`와 `RuleChip`은 새 함수로 대체한 뒤 지운다. 쓰는 곳은 `main.ts`의 `renderLobby`뿐이다. `shared/test/laserfreq.test.ts`가 `rulesChips`를 참조하므로 새 함수 기준으로 고친다.
- `changed` 계산: `matchPreset(r)`이 있으면 `PRESETS[id].rules`와, 없으면 `DEFAULT_RULES`와 해당 키를 비교한다.
- 설정 창 묶음은 `rulesUI.ts`의 데이터 표(`NUM_FIELDS`, `BOOL_FIELDS`)에 `group` 필드를 더해 만든다. `COOP_OFF`와 아케이드 전용 필드 조건은 그대로 유지한다.

## 구현 범위와 순서 (빌더용)

1. `lobbyUI.ts`: `rulePanel` 추가 + 테스트. (특수 원 타일 포함, 협력전 분기)
2. `index.html`/`style.css`/`main.ts`: 대기실 규칙 영역을 패널 구조로 교체, 아이콘 슬래시 SVG, 배지, 노란 점, 모바일 배치.
3. `rulesUI.ts`: 설정 창 미리보기, 세부 설정 6묶음, 세그먼트/토글 타일, 종속 값 숨김, 변경 표시, 포커스 처리.
4. `RULE_ICON` 매핑에 `special` 추가, `icons.ts`에 `Sparkles` 등 필요한 lucide 아이콘 추가.
5. 정리: `rulesChips`, `.rchip` CSS 삭제.

## 완료 기준

- 대기실에서 개인전 클래식 기본 규칙일 때 2단에 `60초 / 피버 ×3 7초 / 속도 ×1`이 큰 글씨로 보이고, 3단에 켜진 요소 아이콘이 노란색, 꺼진 것은 슬래시와 흐림으로 보인다.
- 프리셋을 바꾸면(`하드코어` 등) 값이 달라진 칸에 노란 점이 뜨고 이름이 맞게 바뀐다. 고급 설정으로 값을 바꾸면 `커스텀`이 된다.
- 설정 창에서 이전에 바꿀 수 있던 모든 값(숫자 12개, 아케이드 2개, 체크 9개, 모드·인원·프리셋·협력전 난이도)을 계속 바꿀 수 있고, 바꾼 값이 서버에 같은 `lobby:rules` 요청으로 가며, 미리보기가 즉시 갱신된다.
- 방장이 아닌 사람은 설정 창을 읽기 전용으로 열 수 있다.
- 협력전에서는 정보가 지금과 같고, 세부 설정은 숨는다.
- 너비 375px에서 가로 스크롤이 없고, 키보드(Tab·Enter·Space·Esc)로 모든 타일과 토글을 쓸 수 있다.
- `npm test`, `npm run typecheck`, `npm run build`가 통과한다.
- 효과 줄이기 설정을 켜면 패널의 전환 애니메이션이 없다. (애니메이션은 설정 창 열림 정도로만 쓴다.)

## 결정 필요 없이 내가 정한 것 (검수 때 확인)

- 새 이미지는 만들지 않고 lucide 아이콘 + 코드 SVG로 간다.
- 세그먼트 버튼은 선택지 4개 이하일 때 쓰고 5개 이상은 `<select>`를 유지한다.
- 종속 값(레이저 두께·빈도, 표적 시간)은 부모 토글이 꺼지면 숨긴다. 숨겨도 저장된 값은 그대로다.
- 특수 원 타일을 3단에 새로 넣는다. 지금 칩에는 없다.
- 변경 표시의 기준은 현재 프리셋, 없으면 기본 규칙이다.
- 점수표 창은 별도 문서로 미룬다.
