# 도감 · 게임 방법 · 점수표 화면 개편 설계

2026-11-21 · 클라이언트 전용 (서버·프로토콜 변경 없음) · 이 문서만 읽고 구현할 수 있게 썼다
짝 문서: [대기실 규칙 표시 개편](2026-11-21-lobby-readability-design.md) (같은 아이콘 어휘와 토큰을 쓴다)

## 의도

- 세 화면은 모두 "규칙을 읽는 곳"인데 읽기 방식이 제각각이고 글이 많다.
  - **도감**(`codex.ts`): 탭 8개(증강·유니크·조합·저주·특별·아이템·보스·규칙)가 한 줄로 늘어서 있고, 탭 안은 길게 이어지는 목록이다. 증강 하나가 이름 + 등급 4줄 + 레전드 문장이라 한 화면에 몇 개 안 들어온다. 탭마다 맨 위에 안내 문단이 길게 붙는다.
  - **점수표**(`rulesUI.ts`의 `scoreTable`): `<table>`에 문장형 칸이 섞여 있고, 특수 원 줄은 이모지(💣🧊🪨)를 쓴다. 나머지 화면은 모두 SVG·lucide 아이콘이라 어울리지 않는다. 같은 표를 대기실 점수표 창과 도감 '규칙' 탭이 함께 쓴다.
  - **게임 방법**(`guide.ts`): 큰 그림 + 한두 줄 슬라이드. 가장 잘 읽히는 화면이다. 슬라이드가 20장 안팎이라 "지금 어디쯤인지", "내가 찾는 규칙이 몇 번째인지" 알기 어렵다.
- 사용자가 정한 것: 가독성을 아이콘형 UI와 그림으로 높인다. **Figma는 쓰지 않는다.**
- 결과: 찾는 것을 훑어서 찾고, 숫자는 한눈에 읽고, 글은 필요한 곳에서만 읽는다.

## 목표 / 하지 않는 것 / 실패 기준

**목표**
1. 도감: 탭을 **3묶음**으로 정리하고, 탭 안 항목을 **카드 격자 + 색 구분 등급 칩**으로 바꿔 훑어 읽게 한다. 긴 안내 문단은 접는 "도움말"로 옮긴다.
2. 도감: 내가 고른 증강·조합 진행도 표시는 유지하고 더 눈에 띄게 한다(이미 `CodexCtx.picks`가 있다).
3. 점수표: 표를 **점수 카드 행**으로 바꾸고, 이모지를 도형 아이콘으로 바꾼다. 대기실 점수표 창과 도감 '규칙' 탭이 **같은 컴포넌트**를 쓴다.
4. 게임 방법: 슬라이드 형식은 유지하고, **목차(전체 보기)**와 진행 표시를 더해 원하는 장으로 바로 간다.
5. 세 화면이 같은 틀(머리·탭·본문·닫기)과 같은 토큰을 쓴다.

**하지 않는 것**
- 증강·규칙의 내용(수치, 문장 의미)은 바꾸지 않는다. 표시 방식만 바꾼다. 수치는 계속 `shared`의 상수와 `desc()` 함수에서 가져온다.
- 서버·프로토콜·규칙 로직 변경, 새 비트맵 이미지, 새 글꼴·색 추가는 하지 않는다.
- 게임 방법 슬라이드의 그림(`guideArt.ts`)을 다시 그리지 않는다.
- 원 안에 한글·영어 글자를 넣지 않는다(숫자와 `?`만 허용). 새로 그리는 도형 아이콘에도 같은 규칙을 지킨다.

**실패 기준**
- 정보가 줄어서 이전에 읽던 값(등급별 수치, 레전드 효과, 상한, 점수)을 못 읽게 되는 것.
- 카드로 바꿨는데 한 화면에 들어오는 항목 수가 지금보다 줄어드는 것.
- 색만으로 등급을 구분하는 것(등급 이름 글자나 칩 위치도 함께 둔다).
- 모바일(375px)에서 가로 스크롤이 생기거나 표가 잘리는 것.

## 디자인

### 공통 틀

세 화면은 같은 머리를 쓴다: 왼쪽 제목(`--display` 24px), 오른쪽 닫기 버튼. 그 아래 탭줄, 그 아래 본문. 지금의 `.cx-head`, `.seg`(탭 버튼) 모양을 공용으로 삼고 게임 방법도 같은 머리 모양으로 맞춘다. 새로 만드는 CSS는 `.info-*` 접두어로 모으고, 기존 `.cx-*`는 도감에서 쓰는 만큼 이름을 바꾸지 않는다.

닫기는 Esc, 오버레이 바깥 클릭, 닫기 버튼 모두 지금처럼 동작한다.

### 도감

**탭 3묶음**

```
┌ 도감 ──────────────────────────────────────────────── [닫기] ┐
│ 카드  [증강] [유니크] [조합] [저주] [특별]                      │
│ 세계  [아이템] [보스]                                         │
│ 규칙  [점수표]                                               │
├────────────────────────────────────────────────────────────┤
│ (본문)                                                       │
└────────────────────────────────────────────────────────────┘
```

- 묶음 이름은 작은 글씨(`--muted`)로 줄 맨 앞에 둔다. 탭 순서와 내용은 지금과 같다(이름만 '규칙' → '점수표').
- 모바일에서는 묶음마다 줄바꿈하고 가로 스크롤은 쓰지 않는다.

**증강 탭 (가장 큰 변화)**

```
 보조 ▾                                                 (분류 머리: 아이콘 + 이름 + 개수)
 ┌──────────────────────┐ ┌──────────────────────┐
 │ [◈] 주사위             │ │ [◈] 아이템 애호가       │
 │ [노말 ×1][레어 ×2]     │ │ [노말 40%][레어 60%]   │   ← 등급 칩 4개 (색 + 글자)
 │ [에픽 ×3][레전드 ×5]   │ │ [에픽 80%][레전드 100%] │
 │ 라운드 끝에 굴려…       │ │ 라운드 시작 3초 뒤…      │   ← 설명은 노말 기준 한 줄
 │ ▸ 레전드 효과 보기      │ │ ▸ 레전드 효과 보기      │   ← 접기
 └──────────────────────┘ └──────────────────────┘
```

- 분류 머리 아래 카드를 **2열 격자**(모바일 1열)로 놓는다.
- 카드 한 장: 아이콘, 이름, 배지(독주·상한), **등급 칩 4개**, 설명 한 줄, 레전드 효과 접기.
  - 등급 칩은 등급 이름과 수치를 함께 보인다(예: `노말 +1`). 칩 색은 `--t0/--t1/--t2/--prism`이다. 글자도 같이 있으니 색만으로 구분하지 않는다.
  - 설명은 `a.desc(values[0])`(노말 기준)를 보이고, 등급별 문장 전체는 카드를 눌러 펼칠 때 보인다(지금의 `ol.cx-tiers` 내용). 정보가 사라지지 않고 접힌다.
  - 레전드 효과 문장(`LEGEND_TEXT`)은 펼침 안에 둔다.
- 내가 가진 증강(`ctx.picks`)에는 노란 테두리와 `×N` 배지를 단다.
- **분류 머리는 접을 수 있다**(기본은 펼침). 긴 분류를 건너뛰어 읽는다.
- 탭 맨 위 긴 문단(독주·진화·성장 설명)은 `도움말 ▸` 접기로 옮긴다. 시너지 목록(`cx-syn`)도 이 안에 둔다.

**다른 탭**
- **유니크 / 저주 / 특별**: 같은 카드 격자. 저주 카드는 이득(`--gain` 색 줄)과 대가(`--curse` 색 줄)를 두 줄로 나눈다(지금과 같은 정보). 등급 칩은 없다.
- **조합**: 카드 격자. 카드에 필요한 증강 아이콘을 `[A] + [B]`(3장짜리는 `+ [C]`)로 나열하고, 내 보유 진행도는 완성/진행/없음으로 칩에 표시한다(지금 `comboTab(ctx)`가 계산하는 진행도 그대로).
- **아이템 / 보스**: 같은 격자. 아이템은 등급(`ITEM_TIERS`)을 칩 색으로, 보스는 지금 `BOSSES` 배열을 카드로 옮긴다.
- 검색은 이번 범위에서 하지 않는다. 카드가 한 화면에 훨씬 많이 들어오고 분류가 접히므로 필요하면 후속으로 둔다. (내 판단)

### 점수표 (대기실 점수표 창 + 도감 점수표 탭, 같은 컴포넌트)

표를 지우고 **점수 카드 행**으로 바꾼다. 행 하나는 "무엇을 잡았나 → 평상시 점수 → 피버 점수"다.

```
 이 방 규칙으로 계산한 점수예요                               (hint)

            평상시        피버 ×3 · 7초
 [▲] 내 색          +1          +3
 [●] 노란색         +2          +3 (내 색 취급)
 [◐] 무지개         +5          +15
 [▲] 남의 색(견제)   +1          +3          ↳ 내 콤보 끊김 · 표적 4초
 [▲] 표적의 색(반격) +3          +9
 [♛] 보스 원        때릴 때 +1 · 막타 +20 · 최다 +5 · 독식 +60       ×3
 ─ 특수 원 ──────────────────────────────────────
 [폭탄 아이콘] 폭탄 원   누르면 십자로 터져 …(BOMB_DESC)
 [얼음 아이콘] 얼음 원   …(ICE_DESC)
 [분열 아이콘] 분열 원   …(SPLIT_DESC)
 ─ 감점 ────────────────────────────────────
 [⊘] 빈 곳         콤보 끊김 · 피버 게이지 −N
```

- 왼쪽에 **도형 견본**(`shapeSVG`)과 이름. 점수 칸은 **큰 숫자**(`--display`)와 작은 부연 문장. 피버 칸은 평상시와 색을 달리해(`--fever`) 구분한다.
- 보스 줄은 점수 네 개를 작은 칩으로 나누어 한 줄에 둔다(지금은 목록 4줄).
- **이모지를 쓰지 않는다.** 특수 원(폭탄·얼음·분열)은 도형 견본이 필요하다. 렌더러에 이미 폭탄·얼음·분열 원을 그리는 코드가 있으니(`client/src/render.ts`의 특수 원 그리기) 같은 모양의 작은 SVG 견본 함수를 `shapeSVG` 옆에 추가한다. 견본에는 글자를 넣지 않는다.
- 규칙에 따라 줄이 빠지는 것은 지금과 같다(무지개 0%면 무지개 줄 없음, 아이템 꺼짐이면 아이템 줄 없음, 보스·특수 원 꺼짐 등). 협력전에서는 특수 원 줄을 숨긴다.
- 순수 함수로 행 데이터를 먼저 만든다: `scoreSheet(r: RoomRules): ScoreRow[]` (`rulesUI.ts` 또는 새 `scoreSheet.ts`). 화면은 이 데이터를 그리기만 한다. 테스트는 `shared/test`에 두되 `scoreTable`의 현재 값과 같은 숫자를 내는지 확인한다.
- 모바일: 숫자 두 칸을 유지하고, 부연 문장은 행 아래로 내려간다.

### 게임 방법

슬라이드 형식(그림 + 제목 + 두 줄)은 바꾸지 않는다. 더하는 것은 두 가지다.

1. **목차 보기**: 머리 오른쪽에 `목차` 버튼. 누르면 슬라이드 제목들이 아이콘이 아닌 **작은 썸네일 격자**(슬라이드 그림 축소)로 나열되고 눌러서 그 장으로 간다. 기본/심화 탭 안에서만 보인다. 꺼진 요소(`off`)는 흐리게.
2. **진행 표시**: 점(dots) 대신, 장이 많은 탭에서는 `7 / 12`처럼 숫자를 함께 보인다. 점은 유지한다.

그 밖의 동작(키보드 좌우, 연습하기 버튼, 처음 접속 때 자동 한 번)은 그대로다.

## 구현 범위와 순서 (빌더용)

1. 순수 함수 + 테스트: `scoreSheet(r)`. 특수 원 견본 SVG 함수 추가(`render.ts`, 글자 없음).
2. 점수표 컴포넌트와 CSS. `main.ts`의 점수표 창과 `codex.ts`의 점수표 탭을 같은 함수로 교체. `scoreTable` 삭제.
3. 도감 틀: 탭 3묶음, 카드 격자 공용 함수(`infoCard`), 등급 칩, 접기. 증강 → 유니크·저주·특별 → 조합 → 아이템·보스 순서로 탭을 옮긴다.
4. 게임 방법: 목차 보기와 진행 숫자.
5. 정리: 쓰지 않는 `.cx-list`·`.cx-tiers` 등 CSS 삭제, `scoretable` 표 CSS 삭제.

## 완료 기준

- 도감 증강 탭에서 한 화면(데스크톱 1280×720)에 지금보다 많은 증강이 보이고, 각 증강의 노말~레전드 수치와 레전드 효과를 여전히 읽을 수 있다(칩 + 펼침).
- 내가 가진 증강이 도감에서 구분되어 보인다. 조합 탭의 진행도가 지금과 같다.
- 점수표의 모든 숫자가 이전 표와 같다(기본 규칙과 프리셋 4종에서 비교). 이모지가 없다.
- 협력전 방에서는 점수표에 쓰지 않는 줄이 없다. 규칙으로 꺼진 요소의 줄이 없다.
- 게임 방법에서 목차로 임의의 장에 바로 갈 수 있고, 꺼진 요소는 흐리게 보인다.
- 세 화면 모두 키보드(Tab·Enter·Esc)로 열고 닫고 이동할 수 있고, 375px 너비에서 가로 스크롤이 없다.
- `npm test`, `npm run typecheck`, `npm run build`가 통과한다.

## 내가 정한 것 (검수 때 확인)

- 도감 탭을 3묶음(카드·세계·규칙)으로 나눈 이름과 순서.
- 증강 카드에서 등급 문장 전체를 "펼침"으로 접는 것(기본은 접힘, 칩에 수치는 보임).
- 도감 검색은 이번에 하지 않는다.
- 게임 방법의 목차를 썸네일 격자로 하고, 슬라이드 그림 축소를 재사용한다.
- 특수 원 견본은 렌더러의 그리기 모양을 따라 새로 만든 작은 SVG다.

## 열어 둔 것 (빌더가 판단)

- 카드 격자의 정확한 열 너비와 간격, 등급 칩의 글자 크기.
- 접기/펼치기에 `<details>`를 쓸지 버튼 + `aria-expanded`를 쓸지(접근성만 지키면 된다).
- 썸네일 크기와 목차의 한 줄 개수.
