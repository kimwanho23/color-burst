# 튜토리얼 설계 (2026-11-09)

## 목적

처음 하는 사람이 원 잡기 → 콤보 → 피버 → 견제를 직접 해 보며 익히는 연습 판. '게임 방법' 슬라이드(읽는 설명)에서 이어지는, 직접 해 보는 단계다. 로드맵 '다음 작업' 2번.

정한 것 (사용자 결정)
- 슬라이드 끝의 [직접 해 보기]에서 이어지고, 처음 화면에서도 시작할 수 있다.
- 단계는 목표를 해내면 넘어간다. 실패·시간 제한 없음.
- 판은 단계에 맞춰 꾸민다 (평소 판 그대로가 아님).
- 마치면 완료 화면에서 [혼자 하기 시작]·[처음으로] 중 고른다. 완료 여부는 저장하지 않는다.
- 서버에 튜토리얼 방을 두는 방식 (타임어택과 같은 구조). 화면만으로 흉내 내지 않는다.

## 1. 단계와 목표

| 단계 | 안내 | 판 구성 | 목표 |
|---|---|---|---|
| 1 `own` 원 잡기 | 내 색 원을 눌러 잡으세요 | 내 색 원만 천천히, 적게 | 내 원 3개 잡기 |
| 2 `combo` 콤보 | 놓치지 말고 연달아 잡으면 콤보가 올라요 | 내 원 넉넉히 | 5콤보 |
| 3 `fever` 피버 | 노란 원도 게이지를 채워요. 게이지가 차면 피버! | 내 원 + 노란 원, 피버 게이지 50으로 시작 | 피버 터뜨리기 |
| 4 `steal` 견제 | 다른 색 원을 잡으면 그 사람 콤보를 끊어요 (대신 잠깐 표적이 돼요) | 봇 1명(클릭 안 함, 시작 콤보 5) + 봇 색 원 | 봇 원 1개 잡기 |

- 헛클릭: 감점·피버 감소 없이 콤보만 끊긴다. 2단계에서 끊기면 "다시 이어 보세요" 안내.
- 목표를 이루면 "잘했어요!" 1초 → 판의 원을 비우고 다음 단계 판.
- 나오지 않는 것: 보스, 아이템, 증강, 저주, 이벤트, 레이저, 지도 패턴, 무지개 원, 황금 원.
- 판 시간 제한 없음. 목표를 다 이루거나 [건너뛰기]로만 끝난다.
- 점수는 화면에 보이지만 결과 화면·기록에는 남기지 않는다.

## 2. 서버

### 수치: `RULES.tutorial` (`shared/src/rules.ts`)
- 단계 순서 `['own', 'combo', 'fever', 'steal']`
- 목표 수치: own 3, combo 5, steal 1 (fever는 피버 시작 1회)
- 단계마다 원 생성 간격 · 한 번에 있는 최대 수 · 속도
- 피버 단계 시작 게이지 50, 단계 넘김 대기 1000ms

### 새 모듈 `server/src/tutorial.ts`
방 상태를 직접 바꾸지 않고, 방이 묻는 것에만 답한다.
- `spawnKinds(step, me, bot)`: 이번 단계에 나올 원 종류
- `progress(step, 사건, me)`: 원 획득·콤보 변화를 받아 진행 수와 목표 달성 여부를 돌려준다
- `enterStep(step, me)`: 단계 시작 준비 (피버 게이지 맞추기, 견제 단계면 봇이 필요하다고 알림)

### `server/src/room.ts` 연결 (생성자 `tutorial` 플래그, 타임어택과 같은 자리)
- 원 생성: 튜토리얼이면 평소 생성 대신 단계별 생성. 보스·아이템·이벤트·레이저·패턴 생성은 끈다.
- 원 획득 뒤: `progress` 확인 → 진행 수가 오르면 이벤트 전송, 목표 달성이면 1초 뒤 판 비우고 다음 단계.
- 헛클릭: 감점·피버 감소 없이 콤보만 끊는다.
- 판 시간: 끝나는 시각 없음.
- 봇: 견제 단계 진입 때 1명 넣는다. 이 봇은 `think`를 부르지 않는다(클릭 안 함).
- 마지막 단계 뒤: 결과 화면·순위 기록을 만들지 않고 `done` 전송.

### 주고받는 이벤트 (`shared/src/protocol.ts`)
- 시작: 기존 `room:solo`에 `tutorial: true` (타임어택의 `timeAttack: true`와 같은 방식).
- 서버 → 화면: `tutorial:step { step, index, total, count, goal, done }`. 단계가 바뀔 때, 진행 수가 오를 때, 마지막에 `done: true`.
- [건너뛰기]·[처음으로]는 기존 방 나가기를 그대로 쓴다.

## 3. 화면

### 들어가는 곳
- '게임 방법' 슬라이드 (`client/src/guide.ts`): 방 밖에서 연 경우에만(`inRoom` false) [직접 해 보기]. '기본' 마지막 장은 [심화로] 옆, 전체 마지막 장은 [다 봤어요] 옆. 대기실에서 연 경우엔 없음.
- 처음 화면 (`client/index.html`): [혼자 하기] 옆에 [연습하기].

### 단계 안내 띠 (새 파일 `client/src/tutorial.ts`)
- 게임 화면 위쪽: `2/4 콤보 · 안내 문구 · 3/5`. 문구는 이 파일에, 숫자는 서버 값 그대로.
- 목표 달성 때 "잘했어요!" 1초.
- 오른쪽에 [건너뛰기] 항상 → 방 나가기 후 처음 화면.
- 연습 중에는 일시정지·남은 시간·순위 표시를 숨긴다.

### 연습 완료 화면
- "연습 완료! 이제 실제 게임을 해 보세요" + [혼자 하기 시작]·[처음으로].
- [혼자 하기 시작]은 튜토리얼 방을 나간 뒤 기존 [혼자 하기]와 같은 흐름.

## 4. 테스트

`shared/test/tutorial.test.ts` (가짜 io, `room.test.ts`와 같은 방식)
- 단계마다 나오는 원 종류 (1단계 내 색만, 3단계 노란 원 포함, 4단계 봇 색 포함)
- 보스·아이템·무지개·황금 원이 나오지 않음
- 목표를 이루면 다음 단계로, 진행 수 이벤트 전송
- 헛클릭에 감점·피버 감소 없음, 콤보는 끊김
- 견제 단계에서만 봇이 들어오고, 그 봇은 원을 잡지 않음
- 피버 단계 시작 게이지 50
- 마지막 단계 뒤 `done: true`, 결과·기록 없음

화면은 빌드 후 로컬 미리보기에서 네 단계를 끝까지 해 보고, [건너뛰기]·완료 화면 두 버튼·슬라이드의 [직접 해 보기]를 눌러 확인한다.

## 하지 않는 것
- 완료 여부 저장, 처음 접속 때 튜토리얼 자동 시작 (슬라이드에서 이어지는 것으로 충분)
- 보스·아이템·증강 등 심화 요소 연습 (슬라이드 '심화'가 맡음)
