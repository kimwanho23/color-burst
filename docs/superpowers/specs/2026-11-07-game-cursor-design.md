# 3단계 설계: 게임 커서, 방해 아이템, 레이저, 카오스 모드

날짜: 2026-11-07 · 상태: 구현 완료 (1차·2차)

## 목적

플레이 피드백("다 눌러 버리면 재미없다", "판을 흔드는 요소가 더 필요하다")에 따라 **커서를 다루는 요소**를 넣는다: 감도 감소, 마우스 반대, 레이저 스턴, 이동형 보스 오오라, 끌어당기는 자석. 그리고 모든 요소를 최대로 켠 **카오스 모드**를 만든다.

이 기능들은 모두 "커서 위치"가 필요하므로, 먼저 공통 바탕인 **게임 커서**를 만든다.

## 사용자가 정한 것

- 커서 방식: **가짜 커서** (마우스 잠금 없이)
- 방해 아이템·레이저 기본값: **켜짐**, '느긋하게' 프리셋만 둘 다 꺼짐
- 카오스 모드: 새 프리셋, "진정한 난장판"
- 커서 자석: **끌어당긴다** (클릭 없이 잡힘)
- 진행: **두 번에 나눠서** (1차 바탕 → 플레이 → 2차)
- 앞서 정한 수치: 감도 감소·마우스 반대 5초(잡은 사람 뺀 모두), 레이저 스턴 1.5초, 1등 저격 3초 스턴 + 콤보 끊김, 오오라는 커서를 끌어당기고 접촉·클릭 시 감점

## 1차 묶음: 게임 커서, 스턴, 레이저, 끌어당기는 자석

### 게임 커서 (클라이언트)

- 캔버스 위에서는 진짜 마우스 커서를 숨기고(`cursor: none`), 게임이 내 커서를 그린다. 내 커서는 나만 본다
- 평소: 게임 커서 = 진짜 마우스 위치 (차이 없음)
- 효과 중(감도 감소·반대·오오라 끌림): 진짜 마우스의 이동량(`movementX/Y`)을 바꿔서 게임 커서를 움직인다. 필드 밖으로는 못 나감
- 효과가 끝나면 게임 커서가 진짜 마우스 위치로 0.15초 동안 미끄러지듯 돌아온다
- 클릭은 진짜 마우스 위치가 아니라 **게임 커서 위치**로 판정한다 (지금의 `toField(clientX, clientY)` 대신)
- 알려진 한계: 효과 중에 진짜 마우스가 캔버스 밖으로 나가면 그동안 조작이 멈춘다
- 터치(모바일): 손가락 위치 = 커서. 감도 감소·반대는 터치에서 "누른 위치가 그만큼 어긋나게" 처리 (2차에서 확인)

### 커서 위치 전송 (서버)

- 클라이언트는 게임 중 커서 위치를 초당 약 15번 보낸다: `cursor:move { x, y }` (필드 좌표, 움직였을 때만)
- 서버는 플레이어별 마지막 위치와 시각을 기억한다. 0.5초 넘게 소식이 없으면 "커서 없음"으로 보고 레이저·오오라·자석 판정에서 뺀다 (탭 전환 등)
- 다른 사람에게는 커서를 보내지 않는다
- 서버는 받은 위치를 믿는다 (친구끼리 하는 게임이라 조작된 클라이언트는 허용 범위로 본다). 클릭 판정은 지금처럼 서버가 한다
- 봇: 커서가 없으므로 레이저·오오라 대상이 아니다. 자석 능력은 봇이 고르지 않는다 (지금처럼)

### 스턴 (공통)

- `PlayerState.stunUntil`. 스턴 중에는 클릭이 무시되고 빈 곳 페널티도 없다
- 화면: 내 커서가 회색이 되고 별이 돈다. 점수판 칩에 스턴 아이콘
- 레이저 스턴 1.5초(콤보 유지), 1등 저격 3초(콤보 끊김, 2차)
- 일시정지가 풀리면 남은 시간은 그대로 (`shiftTimes`에 포함)

### 레이저 발사기

- 10~15초마다 (방 규칙 '레이저'가 켜져 있을 때) 화면을 가로지르는 레이저
- 무작위 각도로 필드를 통과하는 직선. 1초 전에 얇은 빨간 점선(경고선)이 보이고, 0.3초 동안 굵은 레이저
- 레이저가 켜진 0.3초 동안 커서가 레이저에서 18 안에 있으면 1.5초 스턴 (한 번 레이저에 한 번만)
- 원에는 영향 없음
- 서버가 `laser:warn { a, b, at }`(두 끝점, 발사 시각)를 보내고, 발사 시점에 서버가 커서 위치로 판정해 `stun { playerId, until, by: 'laser' }`를 보낸다
- 판 시작 3초 안, 라운드 마지막 1초, 시간 정지 중에는 쏘지 않는다

### 끌어당기는 자석 (자석 능력·자석 아이템)

- 지금의 "빗나간 클릭 보정" 자석을 대신한다
- 범위: 능력 60 / 90 / 120 / 160 (중첩 상한 200), 자석 아이템 +90 (능력과 더하고 상한 적용)
- 서버가 틱마다: 내 커서 둘레 범위 안에 원의 중심이 들어온 **내 원**(내 색·노란색·무지개)을 찾아, 가까운 것부터 "끌려가는 중"으로 묶는다
  - 플레이어마다 1초에 최대 2개 (끌기 시작 기준)
  - 발사 보호 구역(가운데 90) 안의 원은 안 된다
  - 묶인 원은 다른 사람이 클릭·범위·장판으로 잡을 수 없다
- `circle:pull { circleId, by, from: {x, y}, at, ms: 250 }`를 보내고, 모든 화면이 0.25초 동안 그 원이 끄는 사람 커서 쪽으로 빨려 드는 모습을 그린다 (끄는 사람 화면에서는 내 커서로, 다른 사람 화면에서는 시작 위치에서 줄어들며 사라짐)
- 0.25초 뒤 서버가 끄는 사람이 잡은 것으로 처리한다 (`claim(..., via: 'magnet')`)
- 커서 둘레에 자석 범위를 하늘색 점선 원으로 표시 (넓은 손 범위 원과 함께)

### 방 규칙

- `laser: boolean` (기본 켜짐, '느긋하게' 꺼짐) — 1차
- `sabotage: boolean` (기본 켜짐, '느긋하게' 꺼짐) — 2차

## 2차 묶음: 방해 아이템, 오오라, 카오스 모드

### 방해 아이템 (아이템 원에 섞음, 방 규칙 '방해 아이템')

| 등급 | 아이템 | 대상 | 효과 |
|---|---|---|---|
| 흔함 | 감도 감소 | 잡은 사람 뺀 모두 | 5초 동안 게임 커서가 실제 움직임의 30%만 움직임 |
| 흔함 | 마우스 반대 | 잡은 사람 뺀 모두 | 5초 동안 게임 커서 움직임이 반대 |
| 희귀 | 시야 방해 | 잡은 사람 뺀 모두 | 5초 동안 넷 중 하나: 잉크 얼룩 3~4개 / 반코트(화면 절반을 무작위 방향으로 가림) / 무작위 낙서 / 렌즈(볼록: 가운데 근처 원이 크고 바깥으로 밀려 보임, 오목: 작고 안쪽으로 몰려 보임) |

- 렌즈는 화면 픽셀이 아니라 **그리는 물체(원·보스·아이템 원)의 위치와 크기**에 렌즈 공식을 적용한다. 픽셀을 매 프레임 옮기는 방식은 Canvas 2D에서 무거워서 쓰지 않는다. 클릭 판정은 진짜 위치 그대로라, 보이는 곳과 실제 위치가 달라 헷갈리는 것이 방해 효과다. 배경·글자는 휘지 않는다
| 전설 | 1등 저격 | 1등 (잡은 사람이 1등이면 2등) | 3초 스턴 + 콤보 끊김, 점수는 안 뺌. 조준선 → "저격!" 연출 |

- 걸린 사람 화면에 무엇에 걸렸는지 아이콘과 남은 시간 (버프 바 옆, 붉은 테두리)
- 같은 방해를 또 맞으면 남은 시간에 더하되 5초의 2배까지 (버프와 같은 규칙)
- 보호막 아이템(견제 보호)은 방해를 막지 않는다

### 이동형 보스 오오라

- 이동형 보스 둘레 반지름 +80의 보랏빛 오오라
- 커서가 오오라 안에 있으면: 게임 커서가 보스 중심 쪽으로 약하게 끌려간다(초당 120 정도), 서버가 0.5초마다 −1점
- 오오라를 클릭하면(보스 몸통이 아닌 오오라 부분) −2점. 몸통 클릭은 지금처럼 타격
- 점수는 0 아래로 내려가지 않는다

### 카오스 모드 (새 프리셋 '카오스')

- 방 규칙 `chaos: boolean`을 새로 두고, 카오스 프리셋이 켠다 (다른 프리셋은 끔). 모든 요소 켜짐 + 아래 배율
- 아이템 원 확률 ×3 (2.5% → 7.5%), 방해 아이템 비율 상승
- 웨이브 간격 절반 (6~9초)
- 레이저 간격 절반 (5~8초)
- 보스 동시 등장 확률 [1마리 20, 2마리 40, 3마리 40]
- 아케이드 랜덤 이벤트 확률 10% → 30%
- 기본 규칙: 속도 ×1.25, 원 개수 많이, 피버 ×5, 무지개 10%, 꼴찌 보정 켬
- 수치는 `RULES.chaos`에 모은다

## 바뀌는 곳 (예상)

| 영역 | 파일 |

## 위험과 대응

- **입력 지연**: 클릭이 이제 게임 커서 위치로 판정됨 → 평소에는 진짜 마우스 위치와 같아야 함. 확인 방법: 평소 상태에서 게임 커서와 마우스 위치가 같은지 자동 테스트(변환 함수) + 직접 플레이
- **커서 전송량**: 4명 × 초당 15번, 메시지당 수십 바이트 → 무료 서버로 충분
- **렌즈 성능**: 픽셀이 아니라 물체 위치만 휘게 해서 원 개수만큼만 계산 (부담 거의 없음)
- **재접속**: 스턴·방해 남은 시간은 PlayerState에, 끌려가는 중인 원과 레이저 예고는 `game:sync`에 포함
