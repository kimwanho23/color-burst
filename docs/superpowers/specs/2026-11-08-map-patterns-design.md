# 맵 패턴 · 방해 조정 · 확률 고르기 · 프리셋 설계

상태: 구현 완료 (2026-11-08)

## 목적

판마다 상황이 달라지는 **변수**를 만든다. 라운드마다 확률로 한 번, 경고와 현수막 뒤에 커서를 방해하는 맵 패턴이 짧게 나타난다. 함께 방해·위험 규칙을 정리하고, 맵 패턴·테마·이벤트 확률을 방 규칙에서 고를 수 있게 하고, 프리셋 2개와 커스텀 프리셋을 더한다.

범위 밖 (따로 설계): 새 모드 3개(팀전, 협력전, 서바이벌).

## 1. 맵 패턴 공통

- **등장**: 라운드마다 확률로 **최대 1번**(클래식은 한 판이 한 라운드). 확률은 방 규칙 '맵 패턴'(아래 5절). 랜덤 이벤트·라운드 테마와 따로 굴린다.
- **시각**: 라운드 시작 5초 뒤 ~ 끝나기 12초 전 사이 무작위.
- **경고**: 나타나기 3초 전에 자리를 반투명으로 보여 주고 경고음(레이저와 다른 소리).
- **현수막**: 경고 시작과 함께 화면 위쪽(보스 처치 배너 높이)에 펼쳐진다. 큰 글씨 `⚠ 패턴 이름`, 그 아래 문구. 위험 패턴(가시 공·좁아지는 링)은 빨간 테두리, 나머지는 노란 테두리. 화면 효과 줄이기면 펼침 동작 없이 표시.
- **남은 시간 띠**: 유지되는 동안 위쪽에 작은 띠 "가시 공 6".
- **유지**: 패턴마다 8~10초 뒤 사라진다.
- **판정**: 스턴은 레이저처럼 서버가 커서 위치로 판정한다. 벽·막대·소용돌이·빙판은 내 게임 커서 움직임을 바꾸고(클라이언트), 서버는 벽·막대 안을 누른 클릭을 거절한다.
- **봇**: 커서가 없어서 레이저처럼 맵 패턴 영향을 받지 않는다.
- **일시정지**: 모든 패턴 시각은 일시정지한 만큼 밀린다.
- **피격 공통**(스턴 패턴·레이저): 방해 내성 증강과 철벽 특별 카드가 적용된다. 피버 중 맞으면 남은 피버 시간이 절반.

## 3. 방해·위험 규칙 변경

- 감도 감소·마우스 반대: 5초 → **3초**. 시야 방해 5초, 1등 저격(3초 스턴)은 그대로.
- **이동형 보스 오오라**: 점수 감점(0.5초마다 −1, 클릭 −2)을 없애고, 닿아 있는 동안 **1초마다 피버 게이지 −15, 콤보 30% 감소**. 피버 중이면 **들어갈 때 한 번** 남은 피버 시간 절반.
- **피버 중 피격**: 레이저·가시 공·링에 맞으면 남은 피버 시간 절반(여운도 같이 당김).
- **방해 내성** (레이저 내성 증강을 바꿈, 수치 25/40/60/100%, 상한 100):
  - 레이저·위험 패턴 스턴 시간과 방해 아이템(감도 감소·반대·시야 방해) 효과 시간을 그만큼 줄임. 100%면 안 걸림. 1등 저격은 제외.
  - 레전드 효과: 레이저·위험 패턴에 닿으면 피버 게이지 +20.
  - 레이저·방해 아이템·맵 패턴이 모두 꺼진 방에서는 선택지에 안 나옴.
- **철벽** 특별 카드: 위험 패턴 스턴도 막음.

## 4. 레이저 두께

방 규칙 '레이저 두께': 얇게(화면 높이 15%) / **보통(22%, 기본)** / 굵게(30%, 지금과 같음). 하드코어·카오스는 굵게.

## 5. 확률 고르기 (방 규칙 고급 설정)

| 규칙 | 선택지 | 기본 |
|---|---|---|
| 맵 패턴 | 끄기 0 / 가끔 20 / 보통 35 / 자주 50 / 많이 80 / 항상 100 (%) | 보통 |
| 라운드 테마 (아케이드) | 끄기 / 가끔 15 / 자주 30 (%) — 2라운드부터, 한 게임 최대 2번 | 가끔 |
| 랜덤 이벤트 (아케이드) | 끄기 / 가끔 10 / 자주 30 (%) — 한 게임 최대 2번 (지금 켜기/끄기를 바꿈) | 가끔 |
| 레이저 두께 | 얇게 / 보통 / 굵게 | 보통 |
| 원 크기 | 보통 / 작게(0.75배) | 보통 |

라운드 테마는 랜덤 이벤트에서 떼어 따로 굴린다(이벤트 목록에서 'theme' 제거).

**커스텀**: 프리셋 줄 끝의 버튼. 누르면 고급 설정이 펼쳐지고 방장이 마지막으로 만든 커스텀 규칙을 불러온다(처음이면 지금 규칙). 고급 설정 값을 하나라도 바꾸면 자동으로 커스텀이 켜진다(지금의 "사용자 설정 규칙" 글씨를 대신함). 커스텀 규칙은 방장 브라우저(localStorage)에만 저장한다. 서버에는 저장하지 않는다.

## 7. 테스트

- 서버·규칙 단위 테스트
  - 등장: 라운드마다 최대 1번, 확률 0이면 안 나옴, 100이면 반드시 나옴.
  - 등장 시각이 라운드 시작 5초 뒤 ~ 끝나기 12초 전 사이.
  - 가시 공·링 스턴, 무적 시간.
  - 벽·막대 안 클릭 거절.
  - 피버 절반, 오오라의 게이지·콤보 감소.
  - 방해 내성·철벽, 일시정지 밀림.
- GameCursor 테스트
  - 벽·막대에 막히고 밀려남.
  - 소용돌이 끌림, 빙판 관성.
  - 반대·감도 감소와 겹쳐도 화면 밖으로 안 빠짐.
- 브라우저 확인
  - 현수막·경고·남은 시간 띠.
  - 패턴 그림 7개.
  - 고급 설정 선택지, 커스텀 버튼.

## 정한 것 (참고)

- 맵 패턴은 랜덤 이벤트·테마와 독립, 방 규칙으로 확률을 고르고 끌 수 있음.
- 패턴은 짧게(8~10초), 라운드당 최대 1번.
- 위험 패턴은 스턴(레이저와 별개 시간), 가시 공은 닿으면 사라짐.
