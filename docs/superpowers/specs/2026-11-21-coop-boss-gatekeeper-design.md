# 협력전 보스 · 문지기 설계 (경계선을 지키는 보스, 공통 체력)

2026-11-21 · 서버·공유 규칙·클라이언트 · 이 문서만 읽고 구현할 수 있게 썼다
먼저 읽을 문서: [협력전 보스 종류 확장 틀](2026-11-21-coop-bosses-framework-design.md) (보스 선택, 실행 인터페이스 `CoopBossRun`, 체력 방식)
짝 문서: [폭파공 (설치형 보스)](2026-11-21-coop-boss-bomber-design.md)
이름 "문지기"는 가칭이다(사용자가 "경계선 보스"라고 불렀다).

## 의도

- 코어는 "탄막을 피하며 원을 잡는" 보스다. 문지기는 **"지킨다"**가 핵심 동사다: 보스가 쏘는 색 구체가 **후방 경계선**을 넘기 전에 **반사해서 되받아치는** 타워 디펜스형 대결이다. (사용자 비유: 식물 vs 좀비에서 좀비가 선을 넘으면 지는 구조.)
- 사용자 결정(대화에서):
  1. 보스가 **색 구체를 발사**하고 구체는 **벽에 튕긴다**.
  2. 구체가 후방 경계선을 넘으면 **공통 체력**에 피해를 입는다.
  3. 클릭하면 구체를 **반사**한다. 반사된 구체는 보스에게 피해를 주고 보스를 **그로기** 상태로 만든다.
  4. 일정 시간마다 **여럿이 함께 처리해야 하는 큰 구체**가 나온다. 이것도 클릭으로 반사한다.
  5. 문지기에는 **개인 체력이 없다.** 공통 체력만 있다.
- 결과: 한 사람이 못 막아도 다른 사람이 도울 수 있는 "서로의 구멍을 메우는" 협동이 중심이 된다. 개인 체력이 없으니 한 명이 쓰러져 빠지는 일이 없다.

## 목표 / 하지 않는 것 / 실패 기준

**목표**
1. 보스가 위쪽 가운데에 서서 색 구체를 쏘고, 구체가 벽에 튕기며 아래 경계선을 향해 온다.
2. 구체를 클릭하면 반사되어 보스에게 날아가 피해와 그로기를 준다. 경계선을 넘은 구체는 공통 체력을 깎는다.
3. 큰 구체는 여러 번(여러 사람이) 눌러야 반사된다.
4. 공통 체력 0이면 패배, 보스 체력 0이면 승리. 시간 제한 180초.
5. 난이도(이지~엑스퍼트)와 봇을 지원한다.

**하지 않는 것**
- 개인 체력, 피격, 기절, 무적. (문지기에는 개인이 맞는 위협이 없다.)
- 코어 전용 시스템: 수정 파훼, 탄막 무늬, 10초 고유 패턴, 분노(폭딜 반격), 스페셜 어택, 우클릭 보호막, 협력전 아이템. (1차에서 쓰지 않는다. "열어 둔 것")
- 판 위쪽으로 가는 새 위협(구체만 위협이다).

**실패 기준**
- 한 사람이 혼자서 모든 색을 막을 수 있어 협동이 필요 없는 것(색 소유 규칙과 클릭 제한으로 막는다).
- 반대로 혼자 하는 판(사람 1명 + 봇 3명)에서 봇 때문에 절대 이길 수 없는 것.
- 구체의 위치가 서버와 화면에서 어긋나 클릭이 빗나가는 것(시각 기준 위치 계산을 공유한다).
- 경계선을 넘는 순간이 화면에 분명하게 보이지 않는 것.

## 규칙 (초안 수치, 시뮬레이션으로 확정)

수치는 `shared/src/rules.ts`의 `RULES.coop.gatekeeper`에 둔다. 난이도 4단계(`easy/normal/hard/expert`) 표를 가진다.

### 판 구성

| 항목 | 값 | 설명 |
|---|---|---|
| 보스 | 위쪽 가운데 `(550, 150)`, 반지름 100 | 가만히 서 있는다(고정형). 구체를 쏘는 자리 |
| 후방 경계선 | `y = 1020` | 판 아래쪽의 빛나는 가로선. 구체 중심이 이 선을 넘으면 "침범" |
| 움직임 | 판 전체 | 플레이어는 어디로든 커서를 움직일 수 있다 |
| 제한 시간 | 180초 | 시간이 끝나면 패배 |

### 구체 (색 구체)

| 항목 | 값 (노말) | 난이도별 (이지/노말/하드/엑스퍼트) |
|---|---|---|
| 발사 간격 | 색 하나당 4.0초 | 5.0 / 4.0 / 3.2 / 2.6 초 (살아 있는 색마다 따로 센다) |
| 속도 | 200 px/초 | 160 / 200 / 240 / 280 |
| 반지름 | 38 | 같음 |
| 각도 | 보스에서 아래쪽 ±50° 안에서 무작위 | 같음 |
| 단계 배율 | 2단계 간격 ×0.85, 3단계 ×0.7 | 같음 |

- **색**: 구체의 색은 살아 있는 플레이어 색(사람과 봇)이다. 색이 돌아가며 나오도록 색마다 다음 발사 시각을 따로 둔다(코어의 `nextOrb`와 같은 방식). 사람이 4명이면 색 4개, 사람 1명 + 봇 3명이어도 색 4개다.
- **벽 튕김**: 구체는 좌우 벽(`x = r` 와 `x = 1100 − r`)에서 반사한다. 위쪽 벽은 없다(보스 쪽). 위치는 코어의 `moverAt`처럼 시각으로 계산한다(서버·화면이 같은 식을 쓴다).
- **침범**: 구체 중심 `y ≥ 1020`이 되는 순간 구체가 사라지고 공통 체력이 `breachDmg`만큼 깎인다. 화면은 선이 붉게 번쩍이고 공통 체력 막대가 줄어든다.

### 반사 (클릭)

- **누가 누를 수 있나**: 구체를 누를 수 있는 사람은 **그 색의 주인**이다. 사람은 **봇 색 구체도** 누를 수 있다(봇이 놓치면 사람이 구해 준다). **다른 사람의 색 구체는 누를 수 없다**(서버가 무시한다. 빈 곳 감점도 없다). 이 규칙이 한 사람이 모든 색을 막는 것을 막는다.
- **반사**: 누르는 순간 구체는 **무적**이 되어 보스 중심을 향해 직선으로 `reflectSpeed`(원래 속도 × 2.2, 최소 480 px/초)로 날아간다. 도착하는 순간 보스에게 피해를 준다. 반사 중에는 다시 누를 수 없다.
- **보스 피해**: 반사 적중 1회 = 피해 1(`reflectDmg`). 보스가 그로기이면 ×1.5.
- **그로기**: 반사가 적중하면 보스가 `groggyMs`(1.2초) 동안 그로기가 된다. 그로기 중에는 새 구체를 **쏘지 않고**(발사 타이머가 멈춤) 받는 피해가 ×1.5다. 그로기 중에 또 적중하면 남은 시간이 늘어난다(합계 최대 4초). 잘 막을수록 보스가 쉬게 되고 더 잘 맞게 되는 순환이다.
- 반사 구체는 다른 구체와 부딪히지 않는다.

### 큰 구체 (협력 구체)

| 항목 | 값 (노말) | 난이도별 |
|---|---|---|
| 등장 간격 | 20초마다 | 22 / 20 / 18 / 16 초 |
| 반지름 | 90, 색 없음(무지개 테두리) | 같음 |
| 속도 | 일반 구체의 60% | 같음 |
| 필요 타수 | 살아 있는 **사람 수 × 2** (사람 1명이면 4) | 이지 ×1.5(올림), 엑스퍼트 ×2.5(올림) |
| 침범 피해 | 5 | 이지 4 / 노말 5 / 하드 6 / 엑스퍼트 7 |
| 성공 | 모든 타수를 채우면 반사 → 보스 피해 8, 그로기 6초 | 같음 |

- **누구나 누를 수 있다**(색 없는 구체). 누를 때마다 타수가 1 줄고 구체가 **위로 70px 밀려난다**(내려오는 것을 늦춤). 한 사람은 **0.6초에 한 번**만 칠 수 있다(`bigCooldownMs`). 그래서 여러 사람이 함께 쳐야 제때 채운다.
- 남은 타수는 구체 가운데에 **숫자**로 보인다(숫자만 허용되는 규칙에 맞는다).
- 큰 구체가 경계선을 넘으면 침범 피해가 크다. 큰 구체가 한꺼번에 둘 이상 나오는 일은 없다.

### 공통 체력과 보스 체력

| 항목 | 값 (노말) | 난이도별 |
|---|---|---|
| 공통 체력 | 20 | 이지 30 / 노말 20 / 하드 14 / 엑스퍼트 10 |
| 보스 체력 | `hpBase × 색 수`(사람 + 봇) | `hpBase` 이지 26 / 노말 30 / 하드 34 / 엑스퍼트 38 |
| 단계 경계 | 67%, 33% | 같음 |

- 공통 체력은 **내구도처럼 회복되지 않는다**(1차). 침범 한 번이 1, 큰 구체가 5(노말)다.
- 목표: 노말 4색일 때 보스를 약 120~140초에 잡는다(구체가 초당 약 1개, 반사 성공률 약 85~90%, 그로기 배율 포함). 시뮬레이션으로 `hpBase`를 확정한다.
- 단계가 오르면(2·3단계) 발사 간격이 줄고(위 표) 한 번에 **연발**(2~3개 연속)이 가끔 나온다. 연발 확률은 2단계 20%, 3단계 35%(초안).

### 개인 체력이 없는 보스

- `PlayerState.hp`와 탈락(`outAt`)을 쓰지 않는다. 모두 판 끝까지 산다.
- **쓰지 않는 코어 시스템**: 수정·보호막·큰 피해 구간(`burst`)·분노·탄막·레이저·고유 패턴·스페셜 어택·우클릭 보호막·아이템. 단계는 난이도 곡선(발사 간격)에만 쓴다.

### 봇

- 봇은 자기 색 구체에 반응 시간(`botReactMs`: 이지 900 / 노말 650 / 하드 500 / 엑스퍼트 400 ms) 뒤 확률 `botSuccess`(이지 0.7 / 노말 0.8 / 하드 0.88 / 엑스퍼트 0.92)로 반사한다. 놓치는 구체는 사람이 구해 줄 수 있다. 봇은 큰 구체도 반응 시간 뒤 한 번씩 친다.

## 서버 구현 (`server/src/coop/gatekeeper.ts`, `CoopBossRun` 구현)

- `start(now)`: 보스 원을 만든다(`makeRaid`와 같은 종류의 `Circle`, `boss: 'raid'`로 두어 방의 기존 처리(방해 판정 등)가 다치지 않게 한다. 체력 `hpBase × 색 수`). 색마다 첫 발사 시각을 어긋나게 둔다. 공통 체력 초기화.
- `tick(now)`: ① 그로기 중이면 발사를 멈춘다 ② 발사 시각이 된 색마다 구체를 만든다(`host.addCircle`) ③ 큰 구체 시각이 되면 만든다 ④ 구체 위치를 시각 기준으로 계산해 경계선(`y ≥ 1020`)을 넘은 것을 침범 처리 ⑤ 반사 구체가 보스에 도착하면 피해·그로기 처리 ⑥ 봇의 반사 ⑦ 단계(67·33%) 갱신. 공통 체력이 0이 되면 `host.finish(false, 'shared')`, 보스 체력이 0이면 승리.
- `clickCircle(p, c, at, now)`: 구체 클릭 판정. 색 주인 확인(사람은 봇 색도 허용), 이미 반사 중이면 무시, 큰 구체면 쿨다운 확인 후 타수 처리. 반사면 구체를 반사 상태로 바꾸고 `gk:reflect`를 보낸다. 방이 `'handled'`를 받으면 기존 코어 경로로 가지 않는다.
- 구체의 이동은 `Circle`에 새 필드를 더해 표현한다: `ric?: { x: number; y: number; vx: number; vy: number; t0: number }`(출발 위치·속도·시각). `circlePos`(`rules.ts`)가 `ric`가 있으면 좌우 벽에서 접히는(fold) 위치를 돌려주도록 분기를 더한다(`moverAt`의 fold와 같은 방식). 반사 구체는 `ric` 대신 `reflect?: { from, to, t0, arriveAt, by }`를 가진다.
- `state()`: `CoopState`에 `boss: 'gatekeeper'`, `shared: { hp, max }`, `phase`, `groggyUntil`, `nextBigAt`을 싣는다. 일시정지 때 `shift(delta)`가 모든 시각을 민다. 재접속은 `state(true)`로 위치 계산에 필요한 정보를 받는다(구체는 `circle:spawn`으로 이미 받는다).
- `result(...)`: 사람마다 **반사 횟수, 큰 구체 타수, 침범 막은 수(내가 구한 봇 색 구체 수)**를 `CoopPlayerResult`의 확장 필드로 싣는다. `sharedLeft` 비율로 별을 계산한다.

### 프로토콜 (`shared/src/protocol.ts`)

| 방향 | 이벤트 | 내용 |
|---|---|---|
| 서버 → 클라 | `gk:reflect` | `{ id, by, from, to, t0, arriveAt }` (반사 시작, 클라이언트가 애니메이션) |
| 서버 → 클라 | `gk:hit` | `{ boss: hp, dmg, groggyUntil, by }` (보스 적중) |
| 서버 → 클라 | `gk:breach` | `{ id, dmg, shared }` (침범과 남은 공통 체력) |
| 서버 → 클라 | `gk:big` | `{ id, hits, left }` (큰 구체 타수 갱신) |
| 클라 → 서버 | 기존 `circle:click` | 반사·큰 구체 클릭. 서버가 보스 실행 객체에 넘겨 판정한다 |

## 화면 (클라이언트)

- **보스**: 위쪽 가운데의 큰 원. 그로기 중에는 눈이 감긴 모양(원 안에는 글자를 쓰지 않는다. 도형 무늬로만)과 별 효과, 발사 전에는 입구가 빛난다.
- **경계선**: 판 아래 가로선. 평소 은은하게 빛나고, 침범하면 붉게 번쩍인다. 선 아래는 "후방"으로 어둡게 칠한다.
- **구체**: 플레이어 색 도형 원. **내가 누를 수 있는 구체**(내 색 + 봇 색)는 선명하고 테두리 링이 있다. **누를 수 없는 구체**(다른 사람 색)는 흐리게(약 35%) 그리고 클릭 반응이 없다(체력전과 같은 규칙). 큰 구체는 무지개 테두리와 가운데 남은 타수 숫자.
- **반사 연출**: 구체가 보스를 향해 빠르게 날아가고, 적중하면 보스가 흔들리며 그로기 별이 뜬다. 효과 줄이기에서는 흔들림을 줄인다.
- **HUD**: 위쪽에 **공통 체력 막대**(큰 바), 보스 체력 막대, 남은 시간. 개인 체력 막대(`#myhp`)는 숨긴다.
- 원 안에는 글자를 쓰지 않는다(큰 구체의 타수 숫자만 예외).
- 결과 화면: 승패·별·시간, 사람별 **반사 횟수 / 큰 구체 타수 / 구해 준 봇 색 구체**.

## 구현 범위와 순서 (빌더용)

1. `shared`: `RULES.coop.gatekeeper` 수치(난이도 표), `Circle.ric`·`reflect`와 `circlePos` 분기, 순수 함수(`gatekeeperOrbAt(t)`, `breached(c, t)`, `bigHitsNeeded(humans, level)`, 반사 도착 시각 계산), 프로토콜 타입. 단위 테스트 `shared/test/gatekeeper.test.ts`: 벽 튕김 위치, 경계선 침범 시각, 색 소유 규칙(사람은 봇 색 허용·다른 사람 색 불가), 큰 구체 타수, 그로기 연장 상한, 보스 체력식.
2. `server/src/coop/gatekeeper.ts`: 실행 객체 + 봇 + 일시정지·재접속.
3. 클라이언트: 보스·경계선·구체·반사 연출, HUD, 결과 화면.
4. 시뮬레이션: 보스 평균 처치 시간, 공통 체력이 남는 비율, 봇 포함 판의 승률, 난이도별 곡선.

## 완료 기준

- 협력전 보스를 문지기로 시작하면 위쪽 보스가 색 구체를 쏘고 구체가 벽에 튕기며 내려온다. 개인 체력은 보이지 않고 공통 체력만 보인다.
- 내 색(또는 봇 색) 구체를 누르면 반사되어 보스에 맞고 보스가 그로기가 된다. 다른 사람 색 구체는 눌러도 아무 일이 없다.
- 구체가 경계선을 넘으면 공통 체력이 깎이고 선이 번쩍인다. 공통 체력이 0이 되면 패배한다.
- 큰 구체는 여러 사람이 쳐서 채워야 반사되고, 한 사람이 연타해도 0.6초에 한 번만 센다. 채우면 보스에게 큰 피해와 긴 그로기가 들어간다.
- 보스 체력이 0이 되면 승리한다. 사람 1명 + 봇 3명 판에서도 노말에서 이길 수 있다.
- 일시정지·재접속·결과가 정상이고, 코어·폭파공 판과 기존 테스트에 영향이 없다.
- 시뮬레이션에서 노말 4색 판의 평균 처치 시간이 약 120~140초(이지 100~120초, 엑스퍼트는 이기기 어렵게).
- `npm test`, `npm run typecheck`, `npm run build`가 통과한다.

## 내가 정한 것 (검수 때 확인)

- **색 소유 규칙**: 구체는 그 색의 주인만 누를 수 있고 사람은 봇 색도 누를 수 있다. (사용자가 "클릭 시 반사"라고만 말해서 누가 누르는지는 제 판단이다.)
- 보스는 위쪽 가운데에 고정, 경계선 `y = 1020`.
- **그로기**: 반사 적중마다 1.2초(최대 4초 합계), 그로기 중 발사 정지와 받는 피해 ×1.5.
- 공통 체력은 회복되지 않는다. 침범 1 / 큰 구체 5(노말).
- 큰 구체: 20초마다, 필요 타수 = 사람 수 × 2, 누구나 누를 수 있고 0.6초 쿨다운, 위로 70px 밀림.
- 1차에서 코어의 스페셜 어택·우클릭 보호막·아이템·분노는 쓰지 않는다.
- 연발(2~3개 연속)은 2·3단계에만 가끔 나온다. 고유 패턴(레이저 등)은 없다.
- 보스 체력 = `hpBase × 색 수`(사람 + 봇), 색은 둘을 같게 센다.

## 열어 둔 것 (빌더가 판단)

- 큰 구체가 밀려나는 거리와 쿨다운의 느낌, 반사 속도.
- 구체가 서로 겹칠 때 클릭 우선순위(가장 아래 = 경계선에 가까운 것 우선을 제안).
- 공통 체력 회복(예: 단계 경계에서 +3)을 넣을지.
- 이후 확장: 스페셜 어택·아이템을 문지기 규칙에 맞게 바꿔 허용.
