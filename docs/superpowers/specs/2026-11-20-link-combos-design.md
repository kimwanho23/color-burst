# 연결 효과 변경, 3장 조합 추가, 행운 축적·아이템 애호가 개편 설계

2026-11-20 · 아케이드 2차 묶음 (`feat/arcade-bundle2`)

## 의도

- 유니크 **연결**은 처음부터 지정 조합을 돕는 카드로 기획했는데, 분류 시너지(점수·피버·보스·유지·견제·보조)의 종류 수 +1로 잘못 구현되었다. 이를 바로잡는다.
- 연결이 의미를 가지려면 3장 조합이 충분히 많아야 한다. 지금 3장 조합은 4개(피버 마스터·보스 헌터·견제왕·철옹성)뿐이므로 6개를 더해 10개로 늘린다.
- **행운 축적**은 기본 잭팟 확률이 0%라서 혼자서는 칸이 전혀 쌓이지 않는다. **아이템 애호가**는 아이템 원이 원 생성의 2.5%에서만 나오고 다른 사람과 먼저 잡기 경쟁도 해야 해서, 보물 상자가 없으면 거의 발동하지 않는다. 두 카드가 스스로 발동 조건을 갖게 한다.

## 목표

1. 연결: **필요 증강이 3장인 조합을 2장만 모아도 완성**한다. 분류 시너지에는 아무 영향이 없다.
2. 새 3장 조합 6개: 타짜, 앙코르, 명사수, 토벌대, 만능 손, 역습.
3. 행운 축적: 잭팟·황금 원·무지개 원으로 칸이 쌓인다.
4. 아이템 애호가: 라운드 시작 때 아이템 1개가 발동한다.

## 하지 않는 것

- 2장 조합(콤보 머신·행운아·변두리·미식가·잡화점·보호막 강타·반격 태세)은 연결의 영향을 받지 않는다. 1장으로 완성되면 빠진 카드의 기능에 기대는 조합(변두리·보호막 강타·반격 태세)의 효과가 비기 때문이다.
- 분류 시너지 규칙과 수치는 바꾸지 않는다.
- 단골손님(독주), 보험·방패·리바운드는 이번 범위가 아니다.
- 약한 저주 리메이크, 리롤 이벤트, 주사위 증강은 따로 설계한다.

## 피해야 할 결과

- 연결로 2장만 모아 완성했을 때, 빠진 카드가 없어서 조합 효과가 비거나 이상하게 동작하는 경우. **새 조합은 3장 중 어느 2장으로 완성해도 효과가 동작하도록 설계한다.**
- 연결이 계속 분류 시너지를 켜는 경우. 이전 동작은 완전히 지운다.

## 방식 선택

| 항목 | 검토한 방법 | 고른 것과 이유 |
|---|---|---|
| 연결 | 모든 조합 −1 / 3장 조합만 −1 / 모든 조합 −1이되 빈 효과 조합 제외 | **3장 조합만 −1** (사용자 선택). 2장 조합이 1장으로 완성되는 문제를 피한다 |
| 행운 축적 | A. 기본 잭팟 확률 추가 / B. 쌓는 조건을 잭팟·황금·무지개로 넓힘 | **B** (사용자 선택). 성장 카드의 맛을 유지하면서 혼자서도 칸이 쌓인다 |
| 아이템 애호가 | A. 아이템 원 등장 증가 / B. 콤보마다 아이템 / C. 라운드 시작 아이템 | **C** (사용자 선택). A는 다른 사람도 이득을 보고, B는 보물 상자와 똑같다 |

## 1. 연결

- 새 설명: "필요한 증강이 3장인 조합을 2장만 모아도 완성"
- 완성 판정 (`combosOf`): 연결을 가지고 있고 조합의 `needs`가 3장이면, 그중 2장 이상을 가졌을 때 완성으로 본다. 그 밖에는 지금처럼 전부 가져야 완성이다.
- 조합 진행도 (`comboProgress`): 연결을 가졌으면 3장 조합의 `need`를 2로 보여 준다. 1장 이상 가진 조합만 보여 주는 지금 규칙은 유지한다.
- 새로 완성되는 조합 미리보기 (`combosCompletedBy`): `combosOf`를 쓰므로 자동으로 따라온다. 연결 카드를 고를 때 완성되는 3장 조합도 미리 보여야 한다.
- 분류 시너지 (`synergyProgress`): `linkBonus`를 지운다.
- 독주: 연결을 가지면 독주가 꺼지는 지금 규칙은 그대로 둔다.
- 봇 빌드 가중치 (`buildWeight`): 지금은 `combosOf`를 쓰지 않고 "필요 증강을 전부 가졌는지"를 직접 본다. 이를 `combosOf` 기준으로 바꿔서, 연결로 완성된 3장 조합의 남은 1장에는 조합 가중치(×3)가 붙지 않게 한다. 연결을 가지고 3장 조합 중 1장만 가졌을 때는 미완성이므로 남은 2장에 지금처럼 가중치가 붙는다. (구현자 판단으로 정함)
- 조합 효과로 더하는 피버 게이지는 잡화점처럼 고정값으로 더한다(과충전 배율 무시, `addFever(..., raw = true)`).
- 같은 카드가 두 조합에 들어 있어도(사냥꾼: 보스 헌터·토벌대) 각 조합을 따로 판정한다.

## 2. 새 3장 조합

효과 문장과 수치는 초안이다. 수치는 밸런스 시뮬레이션 후 조정한다. 모든 효과는 3장 중 어느 2장으로 완성해도 동작해야 한다.

| id (제안) | 이름 | 필요 증강 | 효과 (초안) | 2장일 때 확인 |
|---|---|---|---|---|
| `gambit` | 타짜 | 잭팟 + 행운 축적 + 속사 | 잭팟이 터지면 피버 게이지 +10, 다음 원 1개는 속사 허용 시간이 0.4초 → 1초 | 속사 없음: 피버 게이지만 / 잭팟 없음: 행운 축적 칸으로 잭팟이 터짐 |
| `encore` | 앙코르 | 과충전 + 여운 + 점화 | 피버가 끝날 때 피버 게이지 +30 | 세 카드 모두 피버 순환과 관련이 있어 어느 2장이어도 동작 |
| `marksman` | 명사수 | 정밀 사격 + 중앙의 왕 + 출발 신호 | 직접 클릭으로 잡은 원 점수 +15%. 정밀 사격 판정이면 콤보 +1 추가 | 정밀 사격 없음: 콤보 추가만 빠짐 |
| `raidParty` | 토벌대 | 선봉 + 왕의 증표 + 사냥꾼 | 보스가 나오면 피버 게이지 +25. 왕의 증표 기여도 계산에서 내 보스 피해 ×1.5 | 왕의 증표 없음: 피버 게이지만 |
| `allHandsCombo` | 만능 손 | 넓은 손 + 헛손질 보정 + 자기장 | 자기장으로 끌어온 원도 콤보와 피버 게이지를 채움 (잭팟 없음). 넓은 손·헛손질 보정으로 잡은 원 +1점 | 자기장 없음: +1점만 |
| `riposteCombo` | 역습 | 방해 내성 + 견제 반사 + 도발 | 견제당할 때마다 피버 게이지 +15 (반사 여부 무관) | 어느 2장이어도 동작 |

판정 범위 (사용자 결정, 2026-11-20):
- **타짜**: 속사 허용 시간 연장은 잭팟이 터진 획득 바로 다음 원 1개에만 적용한다. 잭팟이 터지면 시간이 지나도 연속으로 치는 방식은 속사 레전드(5연속이면 잭팟 확정)와 끝없이 이어질 수 있어 쓰지 않는다.
- **만능 손**: 콤보·피버 게이지를 채우는 것은 자기장(`autoMagnet`)으로 끌어온 원뿐이다. 자석 증강과 자석 아이템으로 끌어온 원은 지금처럼 점수만 준다. 자기장 설명의 "콤보·피버 충전 없음"은 이 조합이 있을 때 덮어쓴다. 콤보가 쌓여 생기는 콤보 보너스와 단련 칸은 그대로 따라온다.
- **역습**: 일반 견제와 피버 중 견제(무페널티 견제 포함)만 센다. 반격, 폭죽·필드 클리어, 보호막·보호막 발생기·철벽에 막힌 견제는 세지 않는다. 도발 → 표적 → 반격으로 게이지가 계속 차는 순환을 막기 위해서다.

- 이름은 기존 증강·조합·저주·특별·유니크·아이템·이벤트·모드 이름과 겹치지 않는다. 기존 특별 증강 '만능 손'은 '탐욕'으로 바꿨다(`c6c1a9b`).
- 명사수와 만능 손은 봇이 고르지 않는 증강(`ASSIST_ABILITIES`)을 포함하므로 사람 전용 빌드가 된다. 의도한 결과다.
- 아이템이 꺼진 방에서는 넓은 손·자석 아이템 버프가 없다. 그래도 만능 손은 자기장·넓은 손·헛손질 보정만으로 동작한다.

## 3. 행운 축적

- 새 설명: "잭팟이 터지거나 황금 원·무지개 원을 잡을 때마다 잭팟 확률 +1%가 쌓임 (최대 N칸)"
- 칸이 쌓이는 경우: 잭팟이 터질 때(지금과 같음), 황금 원을 잡을 때, 무지개 원을 잡을 때. 하나의 획득에서 무지개를 잡고 잭팟도 터지면 1칸만 쌓는다.
- 견제 반사로 원 주인이 대신 잡은 것으로 처리된 경우에도 주인에게 쌓인다(주인이 잡은 것으로 계산하므로).
- 칸당 수치, 최대 칸(3 / 5 / 7 / 10, 상한 15), 레전드 효과(×3 이상 확률 2배)는 그대로 둔다. 시뮬레이션에서 너무 빨리 차면 최대 칸이나 쌓는 조건을 조정한다.

## 4. 아이템 애호가

- 새 설명: "라운드 시작 후 3초에 무작위 아이템 1개 발동. 아이템이 발동하면 v% 확률로 새 아이템이 한 번 더"
- 라운드 시작 아이템은 일반 아이템 원과 같은 등급 확률(`RULES.items.tierOdds`)로 뽑고, 커서 위치에서 발동한다. 커서 위치를 모르면 화면 가운데에서 발동한다.
- 3초를 기다리는 이유: 라운드가 막 시작했을 때는 화면에 원이 거의 없어서 폭죽·필드 클리어 같은 즉시 효과가 헛돈다.
- 이 발동도 일반 발동과 같은 흐름(`activateItem`)을 타므로, 한 번 더 확률, 단골손님, 잡화점 피버 게이지가 그대로 붙는다.
- 아이템이 꺼진 방에서는 지금처럼 선택지에 나오지 않는다.
- 여러 번 골라도 라운드 시작 아이템은 라운드당 1개다. 한 번 더 확률만 지금처럼 중첩된다.

## 수치 위치

`CLAUDE.md`에 따라 새 규칙 수치(조합 효과 수치, 아이템 애호가 지연 시간)는 `shared/src/rules.ts`의 `RULES`에 둔다. 기존 `COMBO` 상수는 옮기지 않는다.

- `shared/src/arcade.ts`: `COMBOS`와 `ComboId`, `combosOf`, `comboProgress`, `synergyProgress`, 연결·행운 축적·아이템 애호가 설명
- `shared/src/rules.ts`: `RULES` 새 수치, 조합 효과 판정, 행운 축적 쌓기
