# 게임 중 나가기 · 게임 방법 설계

상태: 구현 완료 (2026-11-09)

## 목적

1. 게임 중에도 나갈 수 있게 한다. 남은 사람의 게임은 4인 균형을 유지한 채 계속된다.
2. 처음 하는 사람이 기본 규칙(점수·콤보·피버·견제·반격·페널티·보스 등)을 한눈에 알 수 있는 "게임 방법" 화면을 만든다.

## 1. 게임 중 나가기

### 지금
- 서버는 게임 중 '방 나가기'(`room:leave`)를 받으면 그 사람을 연결 끊김으로 표시한다(점수판에 남음, 다시 못 들어옴).
- 화면에는 게임 중 나가기 버튼이 없다. 대기실에만 '방 나가기'가 있다.

### 버튼과 확인
- 게임 중 위쪽 바의 도감 버튼 옆에 **나가기** 아이콘 버튼을 둔다. 일시정지 화면에도 "게임 나가기" 버튼을 둔다.
- 누르면 확인 창이 뜬다.
  - 문구: "게임에서 나갈까요?" / "봇이 이어서 플레이하고, 다시 들어올 수 없어요." (혼자 하기는 "게임이 끝나요.")
  - 버튼: [나가기] [계속하기]. Esc나 바깥을 누르면 닫힌다(계속하기).
- 나가면 처음 화면으로 돌아간다(대기실 '방 나가기'와 같은 처리).

### 봇이 이어받기 (여럿이 하는 방)
- 나간 사람의 자리는 **그대로 봇이 된다**. 점수·증강·콤보·피버 상태를 이어받는다.
- 이름은 "원래 이름 (봇)", 봇 수준은 방의 봇 수준이다.
- 점수판·결과 화면에 그 자리가 봇으로 계속 나온다. 게임이 끝나면 다른 봇처럼 대기실에서 빠진다.
- 다른 사람 화면에는 알림 한 줄: "○○님이 나갔어요. 봇이 이어받아요."
- 연결이 끊긴 경우(새로고침·네트워크)는 지금처럼 자리를 지키고 다시 들어올 수 있다. 봇으로 바뀌는 건 **직접 나가기를 눌렀을 때만**이다.

### 같이 처리할 것
- **증강 고르는 중에 나가면:** 그 사람의 남은 선택을 바로 무작위로 고른다(30초를 기다리지 않음). 모두 골랐으면 바로 다음 라운드.
- **일시정지를 건 사람이 나가면:** 바로 다시 시작 카운트다운(3초)을 시작한다.
- **방장이 나가면:** 지금처럼 남은 사람에게 방장이 넘어간다.
- **사람이 모두 나가면:** 지금처럼 방이 끝난다(봇끼리 계속하지 않음).
- **혼자 하기:** 나가면 방을 바로 끝낸다.

## 2. 게임 방법

### 버튼
- 처음 화면: 도감 버튼 옆에 **게임 방법** 버튼.
- 대기실: 도감 버튼 옆에 같은 버튼.
- **처음 접속한 사람에게 한 번 자동으로** 띄운다(브라우저에 '봤음'을 저장, 저장이 안 되는 환경이면 띄우지 않음).

### 화면
- 도감과 같은 창 모양(✕ 닫기, Esc 닫기)에 탭 2개: **기본**, **심화**.
- 항목마다 그림(원 모양·아이콘)과 짧은 문장. 숫자는 지금 방 규칙에서 가져온다(방 밖이면 기본 규칙).
- **기본 탭**
  - 목표: 중앙에서 터져 나오는 원을 4명이 동시에 노린다. 점수가 가장 높은 사람이 이긴다.
  - 원 점수: 내 색 +3, 노란 원 +2(누구나), 무지개 +5.
  - 콤보: 쉬지 않고 잡으면 콤보가 오르고, 10콤보마다 콤보 보너스 +5.
  - 피버: 원을 잡으면 게이지가 차고, 가득 차면 피버(7초, 점수 ×3). 피버 중엔 노란 원도 내 색, 견제 페널티 없음.
  - 견제: 남의 색 원을 잡으면 +1, 상대 콤보를 끊지만 내 콤보도 끊기고 피버 게이지가 줄고 4초간 표적이 된다.
  - 반격: 표적이 된 사람의 색 원은 +6.
  - 페널티: 빈 곳을 누르면 콤보가 끊기고 피버 게이지가 준다(방 규칙에서 끌 수 있음).
  - 점수 구역: 중앙 ×1 / 사이 ×2 / 가장자리 ×3.
- **심화 탭**
  - 보스: 때리면 깎은 만큼 점수, 막타 +20, 최다 타격 +5, 체력 절반 이상을 혼자 깎고 처치하면 독식 +60. 방어형(보호막), 공격형(붉을 때 때리면 감점), 이동형(오오라).
  - 황금 원·아이템 원.
  - 방해 요소: 레이저(닿으면 스턴), 맵 패턴, 방해 아이템.
  - 아케이드: 5라운드, 라운드마다 증강 선택, 등급(노말·레어·에픽·레전드), 조합, 저주, 역전 기회.
- 방 규칙에서 꺼진 요소(보스·레이저·아이템 등)는 "이 방에선 꺼져 있어요"로 흐리게 표시한다.

## 3. 테스트

- **나가기(서버):** 게임 중 나가면 그 자리가 봇이 되고 점수·증강 유지, 다시 들어올 수 없음, 증강 고르는 중이면 바로 무작위 선택, 일시정지 건 사람이 나가면 다시 시작 카운트다운, 혼자 하기는 방 종료, 사람이 다 나가면 방 종료, 연결 끊김은 봇이 되지 않음.
- **게임 방법:** 내용의 숫자가 방 규칙을 따름(피버 배율·시간, 표적 시간), 꺼진 요소 표시.
- **화면 확인:** 게임 중 나가기 버튼·확인 창·처음 화면 복귀, 남은 사람 알림, 게임 방법 첫 접속 자동 표시와 탭.
