# 폭탄 원 설계

2026-11-19. ROADMAP 💡 '특수 원 추가' 중 폭탄 원만 먼저 만든다. 원래 초안의 "잡으면 감점"은 버리고, 터뜨리면 십자로 폭발해 걸린 원을 점수로 가져가는 원으로 바꾼다.

## 목표 · 넣지 않는 것 · 실패 기준

목표
- 판에 "언제 터뜨릴지 노리는" 원을 하나 더한다. 처음부터 폭탄으로 보이므로 좋은 타이밍을 두고 쟁탈이 생긴다.
- 보스가 십자 줄 근처에 있을 때 폭탄을 차지하려는 싸움이 생긴다.
- '특수 원' 방 규칙과 생성 구조를 만들어, 뒤에 얼음 원·분열 원을 얹을 수 있게 한다.

넣지 않는 것
- 얼음 원, 분열 원 (구조만 열어 둔다)
- 협력전, 튜토리얼
- 감점 폭탄

실패 기준
- 연쇄 폭발이 같은 원을 두 번 잡거나 같은 폭탄을 두 번 터뜨린다.
- 발사 보호 구역 안의 원이 십자에 잡힌다.
- 일시정지·시간 정지 중에 예약된 연쇄가 터진다.

## 규칙

| 항목 | 규칙 |
|---|---|
| 모드 | 클래식·아케이드. 협력전·튜토리얼에는 나오지 않는다 |
| 방 규칙 | 새 옵션 '특수 원' (`specialCircles`, 협력전 `specials`와 구분). 기본 켜짐, 하드코어 프리셋은 꺼짐 |
| 등장 | 일반 원이 생길 때 아이템 원 판정 다음에 2.5% 확률로 폭탄 원(`kind: 'bomb'`). 웨이브 원·라운드 테마의 확률 덮어쓰기에는 섞이지 않는다 |
| 움직임 | 일반 원과 같은 발사·이동. 판 밖으로 나가면 터지지 않고 사라진다 |
| 폭탄 자체 | 점수·콤보 없음. 견제 대상이 아니다 |
| 폭발 범위 | 폭탄 중심을 지나는 가로줄·세로줄, 판 끝까지. 원 중심과 줄 사이 거리가 `원 반지름 + 줄 반폭` 이하면 걸린다. 줄 반폭은 `RULES.specialCircles.bomb.halfWidth` (초안 30) |
| 걸리는 것 | 모든 색의 일반 원·노란 원·무지개 원, 보스, 다른 폭탄 원. 황금 원·아이템 원은 걸리지 않는다(폭죽과 같음). 발사 보호 구역 안은 제외 |
| 걸린 원 | 남의 색도 견제 페널티·표적 없이 잡는다. 원마다 평소처럼 점수·콤보·피버 게이지·증강 효과·잭팟을 받는다 |
| 보스 | 십자에 걸리면 직접 클릭 1회와 같은 타격. 독식 기여도에 들어가고 막타로 인정한다. 보호막·붉은(공격형) 상태의 보스는 십자가 지나간다(피해·감점 없음) |
| 터지는 경우 | 직접 클릭, 넓은 손 범위, 폭죽, 장판, 다른 폭탄의 십자. 자석으로는 터지지 않는다 |
| 연쇄 | 십자에 걸린 폭탄은 `chainDelayMs`(초안 150ms) 뒤 그때 위치에서 터진다. 연쇄 점수는 모두 처음 터뜨린 사람이 받는다 |
| 봇 | 일반 원처럼 일정 확률로 노린다. 타이밍은 재지 않는다 |

### 폭죽 잭팟 (함께 바꿈)

폭죽·필드 클리어로 잡은 원도 잭팟을 굴린다. 지금 `resolveClaim`은 `via === 'blast'`면 잭팟을 끈다. 이 예외를 없앤다. 기존 규칙 변경이므로 `balance` 커밋으로 나눈다. 아이템 빌드 점수가 오를 수 있어 플레이 기록으로 확인한다.

### 십자 획득 경로 (`via: 'cross'`)

십자에 걸린 원은 새 획득 경로 `'cross'`로 잡는다. 폭죽(`'blast'`)과 같은 점과 다른 점은 아래와 같다.

| 항목 | 폭죽 `'blast'` | 십자 `'cross'` |
|---|---|---|
| 견제 페널티·견제 통계·강탈 증강(`stealKing`, 견제 시너지) | 없음 | 없음 |
| 아이템 배율 중 '직접 획득에만' 붙는 부분 | 없음 | 없음 |
| 콤보·피버 게이지 | 쌓임 | 쌓임 |
| 잭팟 | 굴림 (이번에 켬) | 굴림 |
| 보물 상자 충전 | 없음 | **충전함** |
| 점화(피버 시작 시 자동 획득) | 없음 | **발동함** |

아케이드의 고점 빌드를 막지 않는다(사용자 결정, 2026-11-19). 폭탄은 처음부터 보여서 남과 다투어야 하고, 터뜨리는 타이밍을 노려야 하므로 그만한 보상을 준다. 고리는 판의 원 수로 끝난다. 점화는 내 색 원만 자동 획득하므로 폭탄을 다시 터뜨리지 않는다. 보물 상자가 폭죽을 내면 그 폭죽은 다른 폭탄을 터뜨릴 수 있다.

폭탄을 **직접 클릭**한 것 자체는 점수·콤보가 없으므로 보물 상자를 충전하지 않는다. 충전은 십자에 걸린 원이 올린 콤보만큼 한다.

## 처리 흐름 (서버)

1. 클릭·넓은 손·장판·폭죽 판정에서 `kind === 'bomb'`이고 보호 구역 밖이면 `detonate(p, bomb, now)`를 부른다. 자석 후보에서는 제외한다.
2. `detonate`는 폭탄을 지우고 `bomb:blast { circleId, by, x, y }`를 보낸다(화면이 십자 연출을 먼저 그리게).
3. 그 순간 위치로 판의 원을 훑는다. 일반 원은 `claim(..., 'cross')`, 보스는 `strikeBoss` 1회, 다른 폭탄은 `pendingBlasts`에 `{ by, circleId, at: now + chainDelayMs }`로 넣는다(이미 들어 있으면 넣지 않는다).
4. 틱마다 `at`이 지난 예약을 꺼내 그 폭탄이 아직 있으면 `detonate`한다. 일시정지·시간 정지는 `at`을 그만큼 민다. 라운드·판이 끝나면 비운다.
5. 같은 틱에 이미 잡힌 원은 `claim`의 기존 중복 검사가 막는다.

## 점수 출처 통계

`SrcKey`에 `bomb`를 더해 십자에 걸린 원으로 얻은 점수를 따로 모은다(원 점수·콤보 보너스). 십자의 보스 타격 점수는 독식·막타 계산과 함께 '보스' 출처에 남는다. 결과 화면 점수 출처 카드에 '폭탄' 줄이 생긴다. 출처 합 + 기타 − 잃은 점수 = 총점 규칙은 그대로 지킨다.

## 화면

- 겉모양: 색 없는 검은 원, 흰 십자 무늬, 위쪽 심지가 깜빡인다. 한눈에 일반 원과 구분된다.
- 폭발: 중심에서 네 방향으로 빛줄기가 판 끝까지 뻗는다(약 200ms). 걸린 원은 중심에서 가까운 순서로 30ms 간격으로 터진다(폭죽과 같은 방식).
- 연쇄: 다음 폭탄은 예약 시간에 맞춰 같은 연출을 반복한다.
- 효과 줄이기: 번쩍임·흔들림 없이 빛줄기만 그린다.
- 효과음: 새 폭발음 1개. 연쇄는 같은 소리를 짧은 간격으로.
- 도감·게임 방법: 특수 원 항목에 폭탄 원 설명 1줄. 대기실 규칙 카드에 '특수 원' 표시.

## 수치 (`RULES.specialCircles`)

```ts
specialCircles: {
  bomb: { chance: 0.025, halfWidth: 30, chainDelayMs: 150, r: 36 },
}
```

화면 문구 속 숫자는 이 상수에서 만든다.

## 바뀌는 파일 (예상)

- `shared/src/rules.ts`: `RULES.specialCircles`, `CircleKind`에 `'bomb'`, `ClaimVia`에 `'cross'`, 방 규칙 `specialCircles`, `makeCircle` 생성, `SrcKey`에 `bomb`, 블라스트 잭팟 예외 제거
- `server/src/room.ts`: `detonate`, 연쇄 예약·일시정지 보정, 클릭·넓은 손·장판·폭죽 경로 연결, 자석 제외
- 서버 봇 로직: 폭탄 원을 노릴 대상에 포함
- `client/src/render.ts`: 폭탄 원·십자 폭발 연출, `client/src/main.ts`: `bomb:blast` 수신, 대기실·도감 문구

## 테스트 (모든 기능 구현 뒤 한꺼번에)

1. 십자 판정: 줄 위·줄 밖·판 끝 근처 원, 보호 구역 안 원 제외
2. 연쇄: 폭탄 A의 십자에 B가 걸리면 150ms 뒤 B 위치에서 터지고 점수는 A를 터뜨린 사람에게. 서로 걸린 A·B가 두 번 터지지 않음
3. 일시정지·시간 정지 중 예약이 밀림, 판 종료 시 예약 비움
4. 보스: 십자 타격이 독식 기여도와 막타에 반영
5. 걸린 원마다 콤보·피버 게이지·잭팟이 적용되고 견제 페널티가 없음. 보물 상자가 충전되고 점화가 발동함
6. 자석으로 폭탄이 터지지 않음, 넓은 손·장판·폭죽으로는 터짐
7. 방 규칙 꺼짐·협력전·튜토리얼에서 폭탄 원이 생기지 않음
8. 폭죽 잭팟이 굴러감
9. 점수 출처: `bomb` 포함 합계 규칙 유지
