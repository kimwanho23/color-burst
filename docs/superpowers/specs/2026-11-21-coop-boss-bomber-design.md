# 협력전 보스 · 폭파공 설계 (시한 폭탄을 되받아치는 설치형 보스)

먼저 읽을 문서: [협력전 보스 종류 확장 틀](2026-11-21-coop-bosses-framework-design.md) (보스 선택, 실행 인터페이스 `CoopBossRun`, 체력 방식)
짝 문서: [문지기 (경계선 보스)](2026-11-21-coop-boss-gatekeeper-design.md)
이름 "폭파공"은 가칭이다(사용자가 "설치형 보스"라고 불렀다).

## 의도

- 코어는 "탄막을 피하며 원을 잡는" 보스다. 폭파공은 **"되받아친다"**가 핵심 동사다: 보스가 설치하는 **색 시한 폭탄**을 눌러서 **보스 쪽으로 컬링 스톤처럼 보내** 폭발시킨다. 누르지 않은 폭탄은 제자리에서 십자로 터져 우리를 다치게 한다.
- 이미 있는 폭탄 원(십자 폭발·연쇄, `shared/src/bomb.ts`)의 규칙과 코드를 그대로 가져오므로 구현이 가볍고, 플레이어에게도 낯설지 않다.
- 사용자 결정(대화에서):
  1. 플레이어가 움직일 수 있는 영역은 **하단 중간까지**로 제한한다(판 아래 절반).
  2. 보스는 **색 시한 폭탄**을 지속적으로 설치한다. **그 색을 가진 사람만 해제**(클릭)할 수 있다.
  3. 폭탄은 **클릭하거나 제한 시간이 지나면** 터진다. 클릭하면 폭탄이 **반사되어 보스의 y(높이)로 빠르게 날아가** 터진다(**x는 클릭 위치에 따라 달라진다**, 컬링처럼 조준).
  4. 반사하지 않으면 **그 자리에서** 터진다.
  5. 폭발은 **십자로 판 끝까지** 간다. 다른 폭탄이 폭발에 휘말리면 **연쇄**로 터진다.
  6. 클릭하지 않아도 **보스가 피해를 입을 수 있고, 우리도 피해를 입을 수 있다.**
  7. **보스는 작게** 해서 세로 폭발로 맞는 일을 줄인다. 보통은 **가로 폭발로 피해**를 준다. 연쇄로 적중하면 피해가 더 크다.
  8. 보스가 **우리 쪽으로 내려와 폭탄을 설치하는 연출**(강습)을 넣는다.
- 결과: "어느 폭탄을 누르고, 어디로 보내고, 어느 줄을 비울까"를 같이 읽는 판이 된다. 코어와 달리 탄막이 없다.

## 목표 / 하지 않는 것 / 실패 기준

**목표**
1. 하단 영역에서만 움직이는 판. 보스가 폭탄을 계속 설치하고, 내 색 폭탄을 눌러 되받아치면 보스가 폭발에 맞는다.
2. 누르지 않은 폭탄은 제자리 십자 폭발로 커서가 맞은 사람에게 피해를 준다. 폭탄끼리 연쇄한다.
3. 보스의 주기적 강습(내려오기)과 단계(67%·33%)별 난이도 상승.
4. 개인 체력 보스(코어와 같은 `hp`), 난이도·봇 지원, 우클릭 보호막으로 폭발 막기.

**하지 않는 것**
- 탄막, 레이저, 수정 파훼, 큰 피해 구간, 분노(폭딜 반격), 스페셜 어택, 협력전 아이템. (1차에서 쓰지 않는다. "열어 둔 것")
- 폭탄의 폭발 모양 변경(십자 고정).
- 판 위쪽을 사용하는 새 위협(플레이어는 하단에만 있다).

**실패 기준**
- 가로 폭발이 항상 보스를 맞혀서 "누르기만 하면 되는" 구조가 되어 조준·연쇄의 이점이 없는 것(연쇄 보너스·정렬 규칙으로 보완).
- 폭탄이 너무 많아 피할 줄이 없는 것(동시 폭탄 수 상한과 경고선으로 방지).
- 반사 폭탄의 도착 지점이 서버와 화면에서 다른 것(같은 식·같은 시각 기준).
- 코어·문지기 판과 기존 테스트에 영향이 생기는 것.

## 규칙 (초안 수치, 시뮬레이션으로 확정)

수치는 `shared/src/rules.ts`의 `RULES.coop.bomber`에 둔다. 난이도 4단계(`easy/normal/hard/expert`) 표를 가진다. 폭발의 모양(십자 줄 반폭 30, 연쇄 지연 150ms)은 폭탄 원의 값(`RULES.specialCircles.bomb`의 `halfWidth`, `chainDelayMs`)을 그대로 쓴다.

### 판 구성

| 항목 | 값 | 설명 |
|---|---|---|
| 플레이어 영역 | `y ≥ 560` (판 아래 절반) | 커서는 이 안에서만 움직인다. 서버는 영역 밖 클릭을 무시한다 |
| 보스 | 반지름 48, 기본 줄 `y = 150`, 좌우로 천천히 이동(왕복 9초, `x` 150~950) | **작은 보스.** 세로 폭발에 맞는 일이 줄어든다 |
| 강습 줄 | `y = 470` | 영역 위쪽 경계(560)보다 위. 가로 폭발이 플레이어를 건드리지 않는 높이 |
| 제한 시간 | 180초 | 시간이 끝나면 패배 |

### 폭탄 (색 시한 폭탄)

| 항목 | 값 (노말) | 난이도별 (이지/노말/하드/엑스퍼트) |
|---|---|---|
| 설치 간격 | 색 하나당 6초 | 8 / 6 / 5 / 4 초 (살아 있는 색마다 따로 센다) |
| 도화선 | 7.5초 | 9 / 7.5 / 6.5 / 5.5 초 |
| 반지름 | 40 | 같음 |
| 동시 폭탄 상한 | 6 | 5 / 6 / 7 / 8 |
| 단계 배율 | 2단계 설치 간격 ×0.85·도화선 ×0.9, 3단계 ×0.7·×0.8 | 같음 |

- **색**: 폭탄의 색은 살아 있는 플레이어 색(사람·봇)이다. 색이 돌아가며 나오도록 색마다 설치 시각을 따로 센다(코어의 `nextOrb`와 같은 방식).
- **자리**: 플레이어 영역 안(`y ∈ [600, 1000]`, `x ∈ [90, 1010]`)에서 무작위로 고른다. 다른 폭탄과 중심 거리 130 이상. 단, **정렬 확률 25%**로 이미 있는 폭탄과 `x`를 맞춘다(±20). 정렬해 두면 한 번의 반사로 세로 팔이 여럿을 연쇄시킬 기회가 생긴다.
- **도화선**: 폭탄 둘레에 줄어드는 호로 남은 시간을 보인다. 마지막 `warnMs`(1.2초) 동안은 **폭발 줄(십자 팔)을 흐린 선으로 미리 보여 준다**(피할 수 있게).
- **연쇄 예고**: 폭발 줄 안에 다른 폭탄이 있으면 그 폭탄에 점선 표시(연쇄될 것임).

### 해제 = 반사 (클릭)

- **누가 누를 수 있나**: 폭탄을 누를 수 있는 사람은 **그 색의 주인**이다. 사람은 **봇 색 폭탄도** 누를 수 있다. **다른 사람의 색 폭탄은 누를 수 없다**(서버가 무시, 빈 곳 감점 없음). (문지기와 같은 규칙)
- **반사**: 누르는 순간 폭탄은 무적이 되어 보스의 **그 순간 높이(`bossY`)**로 직선 비행한다(`reflectSpeed` 1,400 px/초). 도착 지점의 `x`는 **클릭 위치로 정한다**:

```
landX = clamp(bomb.x + (bomb.x − click.x) × aimGain, 60, 1040)     // aimGain = 5
landY = boss.y   (클릭 순간의 보스 높이)
```

  - 폭탄 가운데를 누르면 곧바로 위로 가고, **왼쪽을 누르면 오른쪽으로, 오른쪽을 누르면 왼쪽으로** 튀어 날아간다(컬링 스톤을 옆에서 치는 느낌). 반지름 40이면 최대 약 ±200px 이동.
  - 도착 시각은 `거리 / 1,400`(약 0.3~0.7초). 비행 중에는 다시 누를 수 없고, 다른 폭발에 휘말리지 않는다.
  - 화면은 폭탄 위에 마우스를 올리면 **예상 도착 지점**(보스 줄 위의 작은 표시)을 미리 보인다.
- **도착 폭발**: 도착한 자리에서 십자로 터진다. 가로 팔은 보스 줄 전체를 쓸어서 **보스를 맞힌다**. 세로 팔은 도착 `x`에서 아래로 내려가며 그 줄의 폭탄을 **연쇄**시킨다.

### 폭발과 연쇄

- **폭발 모양**: 폭탄 원과 같다. 중심을 지나는 가로·세로 줄(줄 반폭 30)이 판 끝까지 간다. `inCross`(`shared/src/bomb.ts`)를 그대로 쓴다.
- **연쇄**: 폭발 줄에 걸린 다른 폭탄은 **150ms 뒤** 그 자리에서 터진다(제자리 폭발). 이 폭발도 십자라서 또 다른 폭탄을 연쇄시킨다. 폭탄 원의 연쇄 코드(`chainDelayMs`)를 쓴다. 일시정지·시간 정지 동안에는 예약이 밀린다.
- **보스 피해**: 폭발의 십자 팔이 보스 원과 겹치면 그 폭발마다 보스에게 `blastDmg` = 1(보스 체력 단위)을 준다. 한 번의 연쇄(반사 폭탄 + 휘말린 폭탄들)에서 **연쇄로 터진 폭탄 하나당 총 피해가 +25%**씩 늘어난다(`chainMult` = 1 + 0.25 × (연쇄 수)). 보스는 작아서 세로 팔은 가끔 맞고, 반사 폭탄의 가로 팔은 항상 맞는다. (사용자: "보통은 가로 폭발로 피해, 연쇄 적중이면 더 많은 피해")
- **플레이어 피해**: **제자리 폭발**(도화선이 다 되었거나 연쇄로 터진 것)의 십자 팔 안에 **폭발 순간 커서가 있던** 사람이 피해를 입는다. 피해는 기존 난이도 표 `RULES.coop.levels[난이도].hurt`에 **새 항목 `blast`**를 더해 쓴다(이지 10 / 노말 15 / 하드 20 / 엑스퍼트 25, 같은 표의 빔 20~35·탄막 5~20과 같은 방향). `CoopHitBy`에 `'blast'`를 더한다. 맞은 뒤 무적 1.5초·기절 0.5초(`hurtFx.blast`). 반사 폭탄의 도착 폭발은 보스 줄이 영역 밖(`y ≤ 470 + 30 < 560`)이라 **플레이어에게 닿지 않는다**(가로 팔) — 세로 팔은 `x` 줄을 따라 영역까지 내려오므로 **도착 `x` 줄 위에 서 있던 사람은 맞는다**(조준할 때 아군 위치도 봐야 한다).
- **우클릭 보호막**: 코어와 같다. 보호막 중에는 폭발 피해를 막는다(`C.barrier`). 압살 같은 관통 판정은 없다.
- **봇**은 피해를 입지 않는다(코어와 같음).

### 강습 (보스가 내려오는 연출)

- `diveEveryMs`(이지 35s / 노말 28s / 하드 22s / 엑스퍼트 18s)마다 보스가 **강습 줄(y = 470)로 내려와 5초 머문다**. 내려오는 동안(1초) 도착 높이를 경고선으로 미리 보인다.
- **머무는 동안**: ① 폭탄 설치 간격이 절반(몰아서 설치) ② 반사 폭탄의 비행 거리가 짧아져 되받아치기가 빠르고 쉽다 ③ 보스가 플레이어 쪽에 가까워 보인다. 5초 뒤 위로 돌아간다.
- 반사 목표 높이는 **보스의 지금 y**다. 내려와 있는 동안 반사하면 강습 줄에서, 올라가 있으면 기본 줄에서 폭발한다. 가로 팔이 플레이어 영역(≥ 560)에 닿지 않도록 강습 줄은 470이다.

### 체력과 단계

| 항목 | 값 (노말) | 난이도별 |
|---|---|---|
| 개인 체력 | 100 | 코어와 같다(`RULES.coop.hpMax`) |
| 보스 체력 | `hpBase × 색 수` | `hpBase` 이지 12 / 노말 14 / 하드 16 / 엑스퍼트 18 |
| 단계 경계 | 67%, 33% | 같음 |

- 목표: 노말 4색일 때 보스를 약 120~140초에 잡는다(폭탄이 초당 약 0.67개, 반사 성공률 약 75%, 평균 연쇄 보너스 ×1.2). 시뮬레이션으로 `hpBase`를 확정한다.
- 2·3단계에서 설치 간격·도화선이 줄고 강습이 잦아진다(위 표의 단계 배율, 3단계 강습 간격 ×0.8).
- 모든 사람이 쓰러지면(개인 체력 0) 패배한다(코어와 같은 규칙). 별은 `coopStars`를 그대로 쓴다.
- 보스 피해가 아닌 폭발로 폭탄이 계속 쌓이는 일을 막기 위해 동시 폭탄 상한을 둔다. 상한에 닿으면 새 설치를 미룬다.

### 봇

- 봇은 자기 색 폭탄에 반응 시간(`botReactMs`: 이지 900 / 노말 650 / 하드 500 / 엑스퍼트 400 ms) 뒤 확률 `botSuccess`(이지 0.65 / 노말 0.75 / 하드 0.85 / 엑스퍼트 0.9)로 반사한다. 조준 오차는 `x ± 60` 무작위. 놓친 폭탄은 사람이 구해 줄 수 있다(사람은 봇 색도 누른다).

## 서버 구현 (`server/src/coop/bomber.ts`, `CoopBossRun` 구현)

- `start(now)`: 보스 원 생성(반지름 48, 기본 줄, `boss: 'raid'` 종류로 두어 방의 기존 처리가 다치지 않게). 색마다 첫 설치 시각을 어긋나게 둔다. 영역 `bounds()` = `{ x0: 0, y0: 560, x1: 1100, y1: 1100 }`.
- `tick(now)`: ① 보스 위치 갱신(좌우 이동, 강습 일정) ② 설치 시각이 된 색마다 폭탄을 만든다(자리 선택 규칙) ③ 도화선이 끝난 폭탄을 **제자리 폭발**로 터뜨린다 ④ 연쇄 큐 처리(150ms 지연) ⑤ 반사 폭탄이 도착하면 도착 폭발 ⑥ 폭발마다 플레이어 판정(커서 위치, 무적·보호막 확인)과 보스 판정 ⑦ 단계 갱신 ⑧ 봇 반사.
- `clickCircle(p, c, at, now)`: 폭탄 클릭. 영역 밖이면 무시, 색 주인 확인, 이미 반사 중이면 무시. 반사 도착 시각·좌표를 계산해 `bm:reflect`를 보낸다. `'handled'` 반환.
- 폭발 판정 도우미(공유 순수 함수): `blastArms(center)`(폭탄 원과 같은 십자), `inBlast(pt, center, halfWidth)`, `chainTargets(center, bombs)`. 폭탄 원의 `inCross`를 재사용하고, 폭탄 원 쪽 `chainDelayMs`와 같은 값을 쓴다.
- 폭탄은 `Circle`의 새 종류 `'cbomb'`로 표현한다(`owner: color`, `fuseAt`, 자리 고정). 폭탄 원(`'bomb'` 특수 원)과 이름·처리가 섞이지 않게 분리한다.
- 일시정지는 도화선·연쇄 예약·강습 시각을 모두 `shift(delta)`로 민다. 재접속은 `state(true)`와 `circle:spawn`으로 복구한다.
- `result(...)`: 사람마다 **반사 횟수, 연쇄 수, 내 폭발에 맞은 아군 수(피해 준 수), 받은 피해**를 `CoopPlayerResult` 확장 필드로 싣는다.

### 프로토콜 (`shared/src/protocol.ts`)

| 방향 | 이벤트 | 내용 |
|---|---|---|
| 서버 → 클라 | `bm:reflect` | `{ id, by, from, to, t0, arriveAt }` (반사 시작) |
| 서버 → 클라 | `bm:blast` | `{ id, x, y, chain: boolean, hitBoss: boolean, hurt: string[] }` (폭발 하나. 연쇄는 여러 번) |
| 서버 → 클라 | `bm:boss` | `{ x, y, diveFrom, diveUntil }` (보스 위치와 강습 일정은 `coop:state`에도 실림) |
| 클라 → 서버 | 기존 `circle:click` | 폭탄 클릭. 서버가 보스 실행 객체에 넘긴다 |

## 화면 (클라이언트)

- **영역**: 아래 절반에 커서가 갇힌다(`cursor.ts`가 `bounds()`로 가둔다). 위쪽 절반은 어둡게 하고 "보스 구역"으로 보이게 한다.
- **보스**: 작은 원. 강습 때는 아래로 내려오는 모습과 도착 높이 경고선.
- **폭탄**: 플레이어 색 도형 원(원 안 글자 없음), 둘레에 줄어드는 도화선 호. 내가 누를 수 있는 폭탄(내 색 + 봇 색)은 선명하고, 누를 수 없는 폭탄(다른 사람 색)은 흐리게(약 35%) 보인다. 마지막 1.2초에는 폭발 십자 줄이 미리 그려지고, 연쇄될 폭탄에 점선.
- **조준**: 내 폭탄 위에 커서를 올리면 보스 줄 위에 **예상 도착 표시**가 따라 움직인다.
- **폭발 연출**: 십자 선이 판 끝까지 번쩍이고 연쇄는 150ms 간격으로 이어진다. 보스가 맞으면 흔들림. 효과 줄이기에서는 줄이 번쩍이지 않고 짧게 표시.
- **HUD**: 코어와 같은 개인 체력 막대·보스 체력·남은 시간. 우클릭 보호막 표시도 코어와 같다.
- 결과 화면: 승패·별·시간, 사람별 반사·연쇄·아군 피해(준/받은).

## 구현 범위와 순서 (빌더용)

1. `shared`: `RULES.coop.bomber` 수치, `'cbomb'` 종류, 순수 함수(`reflectLanding(bomb, click)`, `flightMs(from, to)`, 폭탄 자리 고르기(`pickBombSpot`), 십자 판정/연쇄 대상(`bomb.ts` 재사용), 강습 일정/보스 위치 계산 `bomberBossAt(t)`), 프로토콜 타입. 단위 테스트 `shared/test/bomber.test.ts`: 착지 x 공식(가운데=직진, 좌우 반대 방향, 경계 clamp), 연쇄 큐(순서·지연), 색 소유 규칙, 영역 밖 클릭 무시, 십자 안/밖 판정, 강습 중 반사 목표 높이, 정렬 확률 시 x 일치.
2. `server/src/coop/bomber.ts`: 실행 객체 + 봇 + 일시정지·재접속, `room.ts`의 `bounds()` 처리(영역 밖 클릭 무시).
3. 클라이언트: 영역 제한과 어둡게, 폭탄·도화선·경고 줄·예상 도착 표시, 폭발·연쇄 연출, 보스 강습.
4. 시뮬레이션: 처치 시간, 연쇄 평균, 플레이어가 맞는 횟수(한 판에 평균 몇 번), 봇 포함 판 승률, 난이도 곡선.

## 완료 기준

- 협력전 보스를 폭파공으로 시작하면 커서가 아래 절반에만 머물고, 보스가 폭탄을 계속 설치한다. 내 색(또는 봇 색) 폭탄만 눌러지고 다른 사람 색은 눌러도 반응이 없다.
- 폭탄을 누르면 클릭 위치에 따라 왼쪽/오른쪽/가운데로 튀어 보스 줄에서 폭발하고 보스가 피해를 입는다. 연쇄가 일어나면 피해가 더 커진다.
- 누르지 않은 폭탄은 도화선이 끝나면 제자리에서 십자로 터져 판 끝까지 가고 그 줄 위 커서에 피해를 준다. 폭발 줄 안의 다른 폭탄이 연쇄로 터진다.
- 보스가 주기적으로 내려와 폭탄을 몰아 설치하고, 내려와 있는 동안은 반사가 더 빠르다. 강습 줄의 가로 폭발은 플레이어 영역에 닿지 않는다.
- 사람 1명 + 봇 3명 판에서 노말을 이길 수 있고, 일시정지·재접속·결과가 정상이다. 코어·문지기 판과 기존 테스트에 영향이 없다.
- 시뮬레이션에서 노말 4색 판의 평균 처치 시간이 약 120~140초.
- `npm test`, `npm run typecheck`, `npm run build`가 통과한다.

## 내가 정한 것 (검수 때 확인)

- **색 소유 규칙**(주인만 누르고 사람은 봇 색도 허용). 문지기와 같다. 사용자가 "그 색 보유자만 해제"라고 했으나 봇 색 허용은 제 판단이다.
- **착지 x 공식** `bomb.x + (bomb.x − click.x) × 5`와 비행 속도 1,400 px/초.
- **정렬 확률 25%**로 폭탄을 같은 `x`에 놓아 연쇄 기회를 만든다.
- **연쇄 배수**: 연쇄로 터진 폭탄 하나당 총 피해 +25%. (사용자는 "연쇄 적중이면 더 많은 피해"라고 했고 배수는 제 초안이다.)
- **강습**: 28초마다 내려와 5초 머문다. 강습 줄 `y = 470`(영역 경계 560보다 위)이라 가로 폭발이 플레이어를 건드리지 않는다.
- 플레이어 영역 `y ≥ 560`, 보스 반지름 48, 보스 좌우 이동 9초 왕복.
- 플레이어 피해는 **제자리 폭발**만이고 반사 폭탄의 가로 팔은 영역 밖이라 안전하다. 반사 폭탄의 세로 팔은 도착 `x` 줄의 플레이어를 맞힌다.
- 1차에서 스페셜 어택·아이템·분노·탄막은 쓰지 않고 우클릭 보호막은 허용한다.
- 보스 체력 = `hpBase × 색 수`(사람 + 봇을 같게 센다).
