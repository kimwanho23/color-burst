# 얼음 원 · 분열 원 설계

2026-11-19. [폭탄 원](2026-11-19-bomb-circle-design.md)이 만든 방 규칙 '특수 원'(`specialCircles`)과 생성 구조 위에 특수 원 두 개를 더한다. ROADMAP 💡 '특수 원: 얼음·분열'을 구체화한다. 처음 초안(얼음 = 상대 원 가속, 분열 = 작은 원으로 갈라짐)에서 바뀌었다.

## 의도

특수 원 셋이 서로 다른 역할을 맡는다.

| 원 | 역할 | 노리는 순간 |
|---|---|---|
| 폭탄 | 타이밍 쟁탈 | 보스·원이 십자 줄에 모였을 때 |
| 얼음 | 모두를 방해 | 남이 누르기 전에 먼저 차지 |
| 분열 | 내 원 뿌리기 + 상대 견제 | 상대 커서 쪽으로 파편을 날려 보낼 때 |

## 목표 · 넣지 않는 것 · 실패 기준

목표
- 얼음 원: 터뜨린 사람만 빼고 모두가 1초 동안 커서가 아주 느려진 뒤 얼어붙는다. 처음부터 얼음으로 보여서 먼저 누르려는 쟁탈이 생긴다.
- 분열 원: 터뜨린 사람 색의 작은 원(파편)이 사방으로 흩어진다. 터뜨린 사람은 파편을 잡아 점수를 얻고, 남은 파편에 커서가 닿으면 기절하니 피해야 한다.

넣지 않는 것
- 협력전·튜토리얼 (폭탄과 같음)
- 이미 날아가는 원의 속도 바꾸기 (`circlePos`가 발사 정보 + 시각으로 계산하는 구조라 중간 변경 장치가 없다)
- 원 안의 한글·영어 글자 (아래 제약)

실패 기준
- 같은 얼음 원·분열 원이 두 번 터진다 (클릭과 넓은 손, 십자와 클릭이 같은 틱에 겹칠 때).
- 터뜨린 사람이나 그 팀원이 얼거나 파편에 기절한다.
- 일시정지·시간 정지 중에 얼음의 '느려짐 → 얼어붙음' 전환이 진행되거나, 파편 피격이 일어난다.
- 파편 피격으로 같은 사람이 연달아 기절한다 (위험 스턴 무적 시간 `hazardUntil`이 무시됨).

## 제약

- **원 안에 한글·영어 글자를 넣지 않는다.** 겉모양은 색·무늬·도형으로만 구분한다. 숫자(체력)와 아이템 원의 `?`만 예외다(사용자 결정, 2026-11-19).
- 규칙 수치는 `shared/src/rules.ts`의 `RULES.specialCircles`에만 둔다. 화면 문구 속 숫자도 이 상수에서 만든다.

## 공통 규칙 (얼음·분열)

| 항목 | 규칙 |
|---|---|
| 방 규칙 | 기존 '특수 원'(`specialCircles`) 하나로 폭탄·얼음·분열을 함께 켜고 끈다. 새 옵션은 없다 |
| 모드 | 클래식·아케이드. 협력전·튜토리얼에는 나오지 않는다 |
| 등장 | 특수 원 전체 확률 2.5%(`RULES.specialCircles.chance`)를 한 번 굴리고, 나오면 폭탄·얼음·분열 중 하나를 같은 비율(`weights`)로 고른다. 라운드 테마 확률 덮어쓰기·내 색 비에는 섞이지 않는다 — **내 결정**: 판이 특수 원으로 넘치지 않게. 폭탄은 지금의 1/3로 줄어든다 |
| 웨이브 원 | 특수 원 셋 모두 섞이지 않는다. 폭탄 원 설계가 정한 규칙인데 지금 코드(`shared/src/waves.ts`의 `makeWave`)는 `itemChance`만 0으로 하고 폭탄 확률은 넘겨서 웨이브에도 폭탄이 나온다. 이번에 함께 고친다 — **내 결정**: 승인된 폭탄 설계를 따름 |
| 움직임 | 일반 원과 같은 발사·이동. 판 밖으로 나가면 아무 일 없이 사라진다 |
| 원 자체 | 점수·콤보 없음. 견제 대상이 아니다 |
| 터지는 경우 | 폭탄과 같다: 직접 클릭, 넓은 손 범위, 장판, 폭죽, 폭탄 십자. 자석으로는 터지지 않는다. 발사 보호 구역 안에서는 터지지 않는다(직접 클릭이면 폭탄처럼 거절을 보내 다시 누를 수 있게) |
| 폭탄 십자에 걸림 | 십자를 터뜨린 사람이 터뜨린 것으로 친다. 연쇄 지연 없이 십자 판정 그 자리에서 바로 터진다 — **내 결정** |
| 필드 클리어 | 폭탄과 같게 다룬다 (현재 필드 클리어가 폭탄을 어떻게 다루는지 따른다) |
| 봇 | 일반 원처럼 일정 확률로 노린다. 타이밍·위치는 재지 않는다 (`server/src/bot.ts`의 폭탄 가중치와 같은 방식) |
| 서바이벌 탈락자 | 탈락자는 얼음·파편 대상이 아니다 |

## 얼음 원

| 항목 | 규칙 |
|---|---|
| 대상 | 터뜨린 사람만 빼고 모두. 봇 포함. 팀전이면 상대 팀만 |
| 1단계: 얼어 가는 1초 | 커서가 진짜 마우스를 아주 늦게 따라온다. 기존 방해 '감도 감소'(`slow` 디버프, 평소 지연 `RULES.sabotage.slowLagMs` 350ms)와 같은 방식이고 지연만 크게 한다(`RULES.specialCircles.ice.slowLagMs`, 초안 1,200ms). 클릭은 된다 |
| 2단계: 얼어붙음 | 1단계가 끝나는 순간 1초 기절(`ice.stunMs`). 클릭이 무시되고 커서가 그 자리에 멈춘다 |
| 콤보·피버 | 얼음·분열 기절은 콤보를 끊지 않고 피버도 줄이지 않는다(사용자 결정, 2026-11-19). 기존 `hazardStun`은 아케이드에서 콤보를 끊고 피버를 절반으로 줄이므로, 면역·무적 시간 처리는 같게 하되 이 둘을 빼는 변형(옵션 인자 등)을 쓴다. 레이저·가시 공의 기존 동작은 그대로 |
| 면역 | 2단계 기절은 기존 `hazardStun`의 면역 규칙을 따른다: 철벽(`fortress`)이면 안 걸리고, 위험 스턴 무적 시간(`hazardUntil`, 기절 뒤 `RULES.laser.immuneMs`) 중이면 안 걸리고, 레이저 내성 증강만큼 줄어든다. 1단계 느려짐은 터진 순간 기절을 막는 조건(철벽·무적 시간)이면 함께 건너뛴다 |
| 겹침 | 1단계 중에 또 얼음이 터지면 새로 시작하지 않고 그대로 진행한다 |
| 봇 | 커서가 없으므로 1단계 동안 클릭 속도가 느려지고(초안: 봇 클릭 간격 ×2), 2단계는 사람과 같이 기절한다. 지금 봇 루프(`server/src/room.ts`)에는 기절 검사가 없어 기절해도 계속 클릭하므로, 봇 루프에 `isStunned` 검사를 넣는다. 모든 기절에 적용한다(사용자 결정, 2026-11-19): 지금은 봇에게 효과가 없던 1등 저격 스턴도 봇에게 먹히게 된다 |
| 일시정지·시간 정지 | 1단계 종료 시각(= 얼어붙는 시각)을 그만큼 민다. 재접속하면 상태에 실려 이어진다 |
| 판·라운드 종료 | 예약된 얼어붙음을 비운다 |

## 분열 원

| 항목 | 규칙 |
|---|---|
| 파편 | 터뜨린 순간 그 위치에서 파편 4개(`split.count`)를 같은 간격(시작 각도 무작위)으로 쏜다. 반지름 22(`split.pieceR`), 속력은 분열 원 속력의 1.5배(`split.speedMult`). 판 밖으로 나가면 사라진다 |
| 파편 색 | 터뜨린 사람의 색. `kind`는 그 색이고 `splitBy`에 터뜨린 사람 id를 적는다 |
| 터뜨린 사람·팀원 | 파편은 평소 '내 원'이다. 클릭·넓은 손·자석·장판으로 평소처럼 잡고, 점수 구역·피버·잭팟·증강도 평소대로. 커서에 닿아도 아무 일 없다 |
| 다른 사람 | 커서에 파편이 닿으면 1초 기절(`split.stunMs`, 얼음과 같은 변형: 면역 규칙은 `hazardStun`과 같고 콤보·피버는 그대로). 닿은 파편은 사라진다(기절이 막혀도). 파편을 직접 클릭해도 견제가 아니라 닿은 것과 같게 처리한다(기절, 파편 사라짐) — **내 결정**: 클릭하려면 커서가 먼저 닿으므로 견제는 처리 순서에 따라 들쭉날쭉해진다. 넓은 손·자석·장판은 원래 내 원만 잡으므로 남의 파편을 잡지 않는다 |
| 피격 판정 | 서버 틱마다 다른 사람의 최근 커서(`freshCursor`)와 파편 위치를 비교한다. 맵 패턴 가시 공 판정(`server/src/room.ts`의 `spikeHit` 처리)과 같은 방식. 봇은 커서가 없어 맞지 않는다 |
| 보호 구역 | 보호 구역 안에 있는 파편은 잡을 수도, 피격을 일으킬 수도 없다 |
| 십자·폭죽 | 파편은 일반 원처럼 십자·폭죽·필드 클리어에 잡힌다 (잡은 사람 기준 평소 규칙) |
| 터뜨린 사람이 나감 | 파편은 그대로 남고 이어받은 봇의 색 원이 된다 (기존 자리 이어받기 규칙) |

## 점수 출처 통계

`SrcKey`에 `split`을 더해, 파편 주인(터뜨린 사람)과 팀원이 파편을 잡아 얻은 점수(원 점수·콤보 보너스)를 따로 모은다. 잡은 방법(클릭·넓은 손·자석·장판·십자·폭죽)과 상관없이 `split`이 기존 출처(`bomb`·`magnet`)보다 먼저다. 다른 사람이 십자·폭죽·필드 클리어로 파편을 잡으면 그 방법의 기존 출처를 따른다. 결과 화면 점수 출처 카드에 '분열' 줄이 생긴다. 얼음 원은 점수가 없어 출처가 없다. 출처 합 + 기타 − 잃은 점수 = 총점 규칙은 그대로 지킨다. — **내 결정**

## 화면

글자 없이 색·무늬로만 구분한다.

| 대상 | 겉모양 |
|---|---|
| 얼음 원 | 하늘색 반투명 원, 흰 눈송이(여섯 갈래 선) 무늬, 가장자리 서리 반짝임 |
| 분열 원 | 회색 원, 가운데서 갈라지는 금(검은 선) 무늬, 천천히 맥동 |
| 파편 | 주인 색 원 + 톱니(뾰족한) 테두리 + 짧은 잔상 꼬리. 일반 원과 한눈에 구분되고 '닿으면 아프다'는 느낌 |

연출
- 얼음 폭발: 터진 자리에서 하늘색 서리 고리가 퍼진다. 대상의 1단계 동안 내 커서 둘레에 서리가 차오르고, 2단계에 커서가 얼음 결정 모양으로 바뀐다. 남이 얼면 점수판 칩에 작은 얼음 표시.
- 분열: 금이 쩍 갈라지는 짧은 번쩍임 뒤 파편이 튀어 나간다. 파편에 맞으면 맞은 자리에서 작은 팡과 기존 스턴 연출.
- 효과 줄이기: 번쩍임·흔들림 없이 고리와 파편만.
- 효과음: 얼음 깨지는 소리, 갈라지는 소리 각 1개.
- 도감·게임 방법: 특수 원 항목에 얼음·분열 설명 각 1줄. 대기실 '특수 원' 규칙 설명을 셋 모두로 고친다.

## 수치 (`RULES.specialCircles`)

```ts
specialCircles: {
  chance: 0.025,                       // 특수 원 전체 확률
  weights: { bomb: 1, ice: 1, split: 1 },
  bomb: { halfWidth: 30, chainDelayMs: 150, r: 36 },  // chance는 위로 옮김
  ice: { r: 36, slowMs: 1_000, slowLagMs: 1_200, stunMs: 1_000, botGapMult: 2 },
  split: { r: 36, count: 4, pieceR: 22, speedMult: 1.5, stunMs: 1_000 },
}
```

## 만드는 방식 (Approaches)

| 방식 | 내용 | 결과 |
|---|---|---|
| A. 파편 = 일반 원 + 주인 표시 | 터뜨린 사람 색의 `Circle`을 `from`(분열 위치)에서 쏘고 `splitBy`를 붙인다. 잡기 규칙은 그대로, 서버 틱에 커서 피격 검사만 더한다 | **선택** (사용자, 2026-11-19). 단, 일반 원과 겉모양으로 구분할 것 |
| B. 파편 = 가시 공 같은 위험물 + 잡기 따로 | 피격 판정은 그대로 쓰지만 점수·콤보·넓은 손 처리를 새로 이어야 한다 | 일이 두 배이고 어긋나기 쉬워 버림 |

얼음은 기존 `slow` 디버프 + `hazardStun` 외에 맞는 방법이 없다. 별도 스턴을 만들면 방해 내성·철옹성 규칙과 따로 논다.

'얼음 = 상대 원 가속'(처음 초안)은 날아가는 원의 속도를 바꿀 장치가 없고, 사용자가 스턴 방식으로 바꿨다.

## 바뀌는 파일 (예상)

- `shared/src/rules.ts`: `RULES.specialCircles` 개편, `CircleKind`에 `'ice'`·`'split'`, `Circle.splitBy`, `SpawnOpts`의 특수 원 확률, `makeCircle` 종류 고르기, `SrcKey`에 `split`, 얼음 상태(느려짐 → 얼어붙음 예약) 필드와 일시정지 보정
- `server/src/room.ts`: 얼음·분열 터뜨리기(폭탄 `detonate` 옆), 클릭·넓은 손·장판·폭죽·십자 경로 연결, 자석 제외, 얼음 예약 틱·파편 피격 틱, 일시정지·시간 정지·판 종료 처리
- `server/src/bot.ts`: 얼음·분열 노리기, 얼어 가는 동안 클릭 간격
- `client/src/render.ts`: 세 겉모양과 연출, `client/src/main.ts`: 새 이벤트 수신·커서 느려짐/얼어붙음·효과음, 도감·게임 방법·대기실 문구

## 테스트 (모든 기능 구현 뒤 한꺼번에)

1. 등장: 특수 원 확률과 종류 비율, 방 규칙 꺼짐·협력전·튜토리얼·웨이브 원에서 안 나옴
2. 얼음: 터뜨린 사람·팀원 제외, 1초 느려짐 뒤 1초 기절, 철벽·위험 스턴 무적 시간 중이면 안 걸림, 일시정지·시간 정지 중 예약 밀림, 판 종료 시 비움, 두 번 안 터짐
3. 기절 공통: 얼음·분열 기절은 콤보·피버를 건드리지 않음, 레이저·가시 공 기절은 예전처럼 콤보를 끊음, 기절한 봇은 클릭하지 않음(1등 저격 포함)
4. 분열: 파편 4개가 터뜨린 사람 색으로 생김, 주인·팀원은 닿아도 무사, 다른 사람은 닿거나 클릭하면 기절하고 파편 사라짐, 무적 시간으로 연달아 기절 안 함, 보호 구역 안 파편은 피격 없음
5. 터지는 경우: 클릭·넓은 손·장판·폭죽·십자로 터지고 자석으론 안 터짐, 십자로 터지면 십자 주인 기준
6. 점수 출처: `split` 포함 합계 규칙 유지
