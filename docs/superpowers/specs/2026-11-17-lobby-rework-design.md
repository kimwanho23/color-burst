# 대기실 개편 설계 (2026-11-17)

## 왜

지금 대기실은 좁은 카드 하나에 방 코드·색·참가자·봇 옵션·방 규칙 전체·점수표·시작 버튼·나가기를 위에서 아래로 쌓았다. 간격이 좁고 길어서 시작 버튼이나 점수표를 보려면 한참 내려가야 하고, 팀전 화면은 특히 어색하다. 사용자가 원하는 모습은 오버워치 같은 대기실이다. 맨 위에 자리 4칸이 있어 사람이 들어오면 칸이 차고, 빈 칸은 (+)로 봇을 넣는다.

## 정한 것 (사용자 결정)

1. 배치는 **A안**이다. 맨 위 헤더 아래에 자리 4칸을 가로로 두고, 그 아래에 규칙 요약과 [게임 시작]을 둔다.
2. 고급 설정을 포함한 규칙 바꾸기는 **별도 설정 창**에서 한다. 대기실에는 규칙 요약만 보인다.
3. **[방 나가기]는 상단 헤더**에 둔다.
4. 버튼 아래·옆의 부가 설명 문구는 없앤다.
5. '빈 자리는 봇으로 채우기'와 방 전체 봇 난이도는 없앤다.
6. 빈 칸의 (+)를 누르면 봇이 **그 즉시** 자리를 차지한다. 난이도는 봇 칸에서 바로 바꾸므로 봇마다 다를 수 있다.
7. 헤더에 '방 K7QZ'와 **[링크 복사]**를 둔다.
8. 인원 모드
   - 팀전은 2:2라 시작할 때 빈 칸을 봇으로 채워 4명을 맞춘다.
   - 서바이벌·협력전은 채우지 않고 있는 인원 그대로 한다. 인원에 따른 규칙은 지금 코드가 이미 따라간다: 서바이벌 판 길이·탈락 수, 협력전 보스 체력. 따로 바꾸지 않는다.

## 화면

```
┌ [← 방 나가기]  방 K7QZ  [링크 복사]                    [도감] [게임 방법] ┐
│ ┌──────┐ ┌──────┐ ┌──────────┐ ┌──────┐                                  │
│ │ ● 민수 │ │ ● 지은 │ │ ● 봇 A  ×  │ │  (+)   │   ← 자리 4칸                      │
│ │ 방장   │ │ 준비   │ │쉬움 보통 어려움│ │ 봇 추가 │                                    │
│ └──────┘ └──────┘ └──────────┘ └──────┘                                  │
│ ┌ 개인전 · 클래식 · 기본  60초 · 피버 ×3 7초 · 보스 · 아이템 ┐ ┌──────────┐ │
│ │ [규칙 바꾸기]  [이 방 점수표]                                │ │ 게임 시작 │ │
│ └──────────────────────────────────────────┘ └──────────┘ │
└──────────────────────────────────────────────────────────┘
```

- 대기실 카드를 지금보다 넓히고 칸 사이 간격을 키운다. 좁은 화면에서는 4칸이 2×2로 접힌다.
- **헤더**
  - 왼쪽: [방 나가기], '방 코드', [링크 복사]
  - 오른쪽: [도감], [게임 방법]
  - 혼자 하기는 '혼자 하기'라 쓰고 링크 복사가 없다.
  - 아래쪽에 있던 버튼 줄(게임 방법·도감·방 나가기)은 없앤다.
- **사람 칸**: 색 원, 이름(나면 "(나)"), 방장·준비 표시.
  - 내 칸을 누르면 지금의 색 고르기를 연다. '내 색상' 줄은 없앤다.
  - 방장이 남의 칸을 누르면 지금처럼 [방장 넘기기]·[내보내기].
- **봇 칸**: 색 원, '봇 A', 난이도 세 버튼(쉬움·보통·어려움, 지금 것 강조), ×(빼기).
  - 난이도 버튼과 ×는 방장만 누를 수 있다. 다른 사람에게는 지금 난이도만 보인다.
- **빈 칸**: (+)와 '봇 추가'. 방장만 누를 수 있고, 다른 사람에게는 빈 테두리만 보인다.
  - 봇은 '보통'으로 들어오고 남은 색 중 하나를 받는다.
- **팀전**: 4칸을 팀 A 2칸 | 팀 B 2칸으로 나누고 팀마다 이름과 n/2를 둔다.
  - 빈 칸에는 [이 팀으로](내가 다른 팀일 때)와 [+ 봇 추가](방장)를 함께 둔다.
  - 봇 칸도 팀에 속한다.
- **규칙 요약**: 인원 모드·클래식/아케이드·프리셋 이름 한 줄. 그 아래에 판 시간·피버 배율과 시간·켜진 요소(보스·아이템·레이저 등) 한 줄.
  - [규칙 바꾸기]는 방장에게만 보인다. 다른 사람은 [규칙 보기]로 같은 창을 읽기 전용으로 연다.
  - [이 방 점수표]는 지금처럼 그 방 숫자로 펼친다.
- **규칙 설정 창**: 지금 `renderRules`가 그리는 인원 모드·모드·프리셋·고급 설정을 그대로 옮긴다.
  - 화면 가운데 큰 창으로 띄우고, 바꾸면 바로 적용한다. 지금처럼 `lobby:rules`를 쓴다.
  - 닫기·Esc로 닫는다.
- **[게임 시작]/[준비]**: 지금처럼 방장은 시작, 다른 사람은 준비다. 아래 안내 문구는 없앤다.
  - 시작할 수 없을 때는 기존 오류 문구를 그대로 쓴다. 예: 준비 안 한 사람, 혼자서는 시작 불가.
- **타임어택 대기실**: 자리 칸이 없다. 지금 화면을 새 헤더·간격만 맞춰 둔다.

## 서버

- **봇은 대기실에서부터 플레이어다.** 방장이 `lobby:addBot`(팀전이면 `{ team }`)을 보내면 그 자리에 봇이 들어간다.
  - 봇은 `newPlayer(id, '봇 X', 빈 색, true)`로 만들고, `PlayerState`에 `botLevel`을 둔다(봇만, 기본 1 = 보통).
  - 4명이 다 찼거나 빈 색이 없으면 무시한다.
- `lobby:removeBot(id)`: 그 봇을 뺀다. `lobby:botLevel({ id, level })`: 그 봇의 난이도를 바꾼다. 둘 다 방장, 대기실에서만.
- **사람이 들어올 때**: 봇까지 합쳐 4칸이 다 차 있으면 "방이 가득 찼어요"로 막는다. 방장이 봇을 빼야 들어올 수 있다(사용자 결정: 방장이 넣은 봇이 말없이 사라지지 않게). 관전석은 이번에 하지 않고 나중에 따로 만든다.
- **시작할 때**
  - 대기실 봇은 그대로 둔다. 판의 `Bot` 객체는 각 봇의 `botLevel`로 만든다.
  - 팀전만 빈 칸을 '보통' 봇으로 채운다. 이 봇은 판이 끝나면 빠진다.
  - 서바이벌·협력전·개인전은 있는 인원 그대로다. 2명 미만이면 지금 오류("혼자서는 시작할 수 없어요")를 그대로 쓴다. 문구에서 '봇 채우기를 켜 주세요'는 '봇을 추가해 주세요'로 바꾼다.
  - 협력전은 지금처럼 1명도 시작할 수 있다.
- **판이 끝나 대기실로 돌아올 때**: 대기실에서 넣은 봇은 남긴다. 팀전 채우기 봇과 게임 중 나간 사람을 이어받은 봇은 뺀다.
- **혼자 하기 방**: 처음 만들 때 '보통' 봇 3명을 넣는다. 방장(나)이 빼고 넣고 난이도를 바꿀 수 있다.
- 없앨 것: `fillBots`, 방 전체 `botLevel`, `lobby:options`, '빈 자리 봇' 관련 화면.
  - 이 둘을 쓰는 기존 테스트(`lobby`·`room`·`survival`·`team`·`coop`·`gamelog`·`boss-fixes`)는 '봇을 대기실에서 추가'하는 방식으로 고친다.

## 링크

- [링크 복사]는 `location.origin + location.pathname + '#' + 방코드`를 클립보드에 넣고 "복사했어요"를 잠깐 띄운다.
- 그 링크로 열 때
  - 저장된 이름이 있으면 바로 그 방에 들어간다(`room:join`).
  - 없으면 지금처럼 처음 화면의 방 코드 칸을 채우고 이름을 기다린다.
  - 방이 없거나 가득 차 있으면 처음 화면에 기존 오류를 띄운다.

## 하지 않는 것

- 인원 수에 따른 서바이벌·협력전 규칙 변경(지금 코드가 이미 따라감)
- 팀전 3:1·1:1 같은 다른 인원 팀
- 대기실 채팅, 방 목록
- 관전석(칸이 다 찼을 때 관전자로 들어오기, 자리 바꾸기) — 다음에 따로
- 게임 화면(판·점수판) 디자인 변경

## 이러면 실패

- 방장이 아닌 사람이 봇을 넣거나 빼거나 난이도를 바꿀 수 있음
- 칸이 비어 있는데 "가득 찼어요", 또는 봇까지 4칸이 찼는데 사람이 더 들어옴
- 다음 판으로 넘어갈 때 대기실 봇이나 봇 난이도가 사라짐
- 규칙 설정 창이 대기실 위에서 잘리거나 다시 길게 내려가야 함

## 만드는 방법

다른 방법은 하나다. 서버를 그대로 두고 화면만 바꿔, 시작할 때 봇을 만드는 지금 방식에 '봇 칸 설정'만 따로 보내는 것이다. 이러면 봇이 칸을 차지하는 모습이 화면 흉내가 되고, 들어오는 사람과 봇 칸이 엇갈린다. 그래서 봇을 대기실 플레이어로 만드는 위 방식 하나로 간다.

## 짓는 사람에게 맡기는 것

- 색·간격·글자 크기는 지금 `style.css` 토큰 안에서 정한다.
- 봇 이름 붙이는 순서(봇 A, B, C, 빠진 이름 다시 쓰기)
- 규칙 설정 창 안의 배치(지금 `renderRules` 그대로 넣어도 됨)
