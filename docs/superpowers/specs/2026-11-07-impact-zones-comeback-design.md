# 타격감·점수 구역·역전 구조 설계

날짜: 2026-11-07 · 상태: 1·2차·3-1·3-2 구현 완료, 3-3 예정

세 번에 나눠 만든다. 1차는 이 문서로 계획을 쓰고, 2차·3차는 방향과 결정 사항만 적어 두고 각 차례 시작 전에 세부를 확정한다.

## 사용자가 정한 것

- 꼴찌 배려: 점수 차가 크게 벌어졌을 때만 한 방 역전 기회를 준다. 평소에는 1등이 피지컬보다 **증강 빌드로 굳히는** 구조
- 역전 기준: 고정 500점이 아니라 **라운드마다 상대 기준** (1등 점수 대비)
- 인원 배율: **방 인원**에 따라 다름, 꼴찌를 벗어나면 사라짐
- 레전드 상향: 수치는 적당히 올리고 **레전드에서만 특수 효과** 추가 (승패를 가를 만큼)
- 점수 구역: 일반 원에만 적용. 황금 원은 고정 점수
- 황금 원: 작고 아주 빠르며 이동형 보스처럼 벽에서 튕김
- 싸움이 중앙에 몰리니 가장자리까지 점수 영역을 넓히는 게 목적
- 순서: 1차 타격감·가시성 + 레이저 + 도감 → 2차 점수 구역·황금 원 → 3차 역전 구조·레전드 상향·조합

## 1차: 타격감·가시성, 레이저, 도감

### 보스 처치 타격감
- 처치 순간 0.08초 정지(히트스톱), 강한 화면 흔들림(0.35초), 큰 파편 + 충격파
- 화면 가운데보다 살짝 위쪽에 처치한 사람 색으로 "○○ 보스 처치! +N" 배너 1.2초
- 효과 줄이기 설정이면 정지·흔들림 없이 배너만

### 아이템 획득 가시성
- 남이 잡아도 화면 위쪽에 "○○: 폭죽" 알림(아이콘 + 잡은 사람 색), 1.2초. 여러 개면 쌓임(최대 3줄)
- 잡은 사람 점수판 칩 위로 아이템 아이콘이 0.8초 튀어오름

### 피버 연출 강화
- 피버 중 화면 테두리 불꽃 일렁임, 배경 맥박(0.5초 주기), 원 터질 때 파편 1.5배
- 효과 줄이기면 테두리 색만

### 레이저
- 굵기: 빔 폭을 화면 높이의 약 30%로. 맞는 거리 `RULES.laser.width` 18 → 135 (빔 폭 270, 지금의 7.5배). 경고 1초 → 1.2초
- 여러 방향 동시 발사 패턴 추가: 한 번에 2~3줄 (평행·X자·방사), 사이에 피할 틈이 반드시 남게
- 카오스: 2초마다 최소 1발, 겹쳐 나올 수 있음
- 스턴이 끝나면 1초 무적 (연속 스턴 방지)
- 확인 필요: 270 폭 + 여러 줄이면 피할 곳이 좁을 수 있음 → 플레이 후 조정

### 도감
- 처음 화면·대기실에서 여는 도감: 증강(등급별 수치), 저주, 아이템(등급·효과), 보스 종류
- "같은 증강을 또 고르면 수치가 더해진다(중첩)"와 상한을 설명
- 점수판 증강 칩에서 같은 증강은 하나로 합쳐 ×N 표시 (지금은 고른 만큼 아이콘이 나열됨)

## 2차: 점수 구역·황금 원

### 점수 구역
- 화면이 16:9라 타원으로 나눈다: 가운데에서의 거리 e = √(((x−800)/800)² + ((y−450)/450)²). e < 0.35 중앙 ×1, 0.35 ≤ e < 0.7 사이 ×2, e ≥ 0.7 가장자리 ×3
- 잡는 순간 원이 있던 자리로 판정. 일반 원(내 색·노란·남의 색·무지개)에만, 잡는 방법(클릭·넓은 손·장판·자석·폭죽·필드 클리어)과 상관없이
- 배율은 피버·여운·점수 2배·잭팟과 곱한다 (콤보 보너스 포함한 그 원 점수 전체에). 강탈 점수에는 안 붙음
- 바닥에 두 경계를 은은한 점선 타원으로, 잡을 때 사이·가장자리면 점수 글자 옆에 ×2 / ×3
- 평균 점수가 1.5~2배쯤 오른다. 3차 역전 기준은 1등 대비 비율이라 영향 없음

### 황금 원
- 반지름 22 (일반 원 약 40), 초당 520 (이동형 보스 380), 중앙에서 나와 벽에서 튕기고 5초 뒤 사라짐
- 고정 +20점. 구역 배율·피버·잭팟·점수 2배·콤보·피버 게이지·견제·표적 모두 없음. 누구나 직접 클릭으로만 잡는다 (넓은 손·자석·장판·폭죽·필드 클리어로는 안 잡힘)
- 한 판에 1 / 2 / 3번 확률 25 / 50 / 25 (평균 2번), 판 시작 3초 뒤 ~ 끝나기 6초 전 사이 무작위 시점
- 잡으면 금빛 파편과 "+20" 금색 글자, 남이 잡으면 위쪽 알림

### 증강 '찰나의 순간'
- 분류 점수. 가장자리 배율 +0.5 / +1 / +1.5 / +2.5 (등급별), 중첩 상한 +4

## 3차: 역전 구조·레전드 상향·증강 확장

양이 많아 세 번에 나눠 만든다: **3-1** 선택 구조·역전·특별 카드·넓은 손 순위 보정 → **3-2** 레전드 상향·새 증강 10개(침착 교체) → **3-3** 조합·빌드 가중치·대평등. 각각 계획·구현·리뷰·배포.

### 3-1. 증강 선택 구조와 역전

아케이드는 5라운드, 증강 선택은 1~4라운드가 끝날 때마다 4번 (선택 n = n라운드 끝, n+1라운드 준비).

| 선택 | 모두 | 꼴찌 (등급 보장) | 역전 기회인 꼴찌 |
|---|---|---|---|
| 1번째 (1R 끝) | 지금과 같음 | 3장 중 1장 이상 레어 이상 | 없음 |
| 2번째 (2R 끝) | 노말 제외 (레어 이상만) | 1장 이상 에픽 이상 | 여기서 처음 판정 → 3R부터 방 인원 배율 |
| 3번째 (3R 끝) | 노말 제외, **2개 선택** | 1장 이상 레전드 | 3장 중 1장이 **특별 카드** |
| 4번째 (4R 끝) | 노말 제외, **2개 선택** | 1장 이상 레전드 | 3장 **전부 레전드** |

- 꼴찌 = 그 시점 누적 점수가 가장 낮은 사람(동점이면 모두). 1~2라운드에는 역전 기회 없음
- **역전 기회**: 2·3·4라운드가 끝날 때 판정. 꼴찌 점수 < 1등 점수 × 0.6이면 켜짐 (1등이 0점 이하면 꺼짐)
- **방 인원 배율**: 역전 기회인 동안 꼴찌가 얻는 원·보스·황금 원 점수에 2인 ×1.1 / 3인 ×1.2 / 4인 ×1.3 (봇 포함 인원). 라운드 중이라도 꼴찌를 벗어나면 바로 꺼지고, 다음 라운드 끝 판정까지 다시 켜지지 않음. 강탈·이벤트·라운드 효과 점수에는 안 붙음
- **2개 선택**: 카드 3장 중 2장을 차례로 고른다 (다시 뽑기는 그 선택에 1번, 2장째 고르기 전에도 쓸 수 있음). 선택 시간 30초 그대로, 시간이 다 되면 남은 수만큼 무작위
- **특별 카드 (12장)**: 새 등급 '특별'(검붉은 바탕 + 금빛 테두리). 효과는 **4·5라운드 내내**. 남의 점수를 깎지 않는다

| 카드 | 효과 |
|---|---|
| 대역전 | 내 모든 점수 ×1.5 |
| 판 뒤집기 | 라운드가 끝날 때 1등과의 점수 차의 20%를 내 점수에 더함 (1등 점수는 그대로) |
| 집중 포화 | 라운드를 피버로 시작, 피버 배율 +2 |
| 하이에나 | 1등이 원을 잡을 때마다 20% 확률로 내 점수 +3 |
| 추격자 | 모든 원이 한 단계 바깥 구역 배율 (중앙 ×2, 사이 ×3, 가장자리 ×4) |
| 기세 | 콤보가 끊기지 않고, 콤보 보너스가 5콤보마다 |
| 만능 손 | 남의 색 원도 내 색처럼 +3, 견제 페널티·표적 없음 |
| 철벽 | 견제(콤보 끊김·강탈)·레이저·방해 아이템에 걸리지 않음 |
| 연쇄 폭발 | 원을 잡으면 15% 확률로 반지름 120 안의 내 원도 함께 |
| 막타 독식 | 보스에게 주는 피해 2배, 막타 점수 2배 |
| 마지막 불꽃 | 라운드 마지막 15초 동안 점수 ×2 |
| 아이템 사냥꾼 | 아이템 원을 잡으면 한 등급 위 아이템, 효과 시간 2배 |

- **넓은 손 순위 보정** (방 규칙 '꼴찌 보정'이 켜진 방, 모든 모드): 실시간 순위로 꼴찌 넓은 손 +20, 3·4인 방의 3등 +10. 순위가 바뀔 때마다 다시 계산, 증강·아이템 넓은 손과 더하고 상한 80

### 3-2. 레전드 상향과 새 증강

- **레전드 수치 = 에픽 × 2** (예: 해머 +3 → +6, 사냥꾼 +30 → +60). 상한은 그대로라 이미 상한인 것(예열 100, 보험 100, 철면피 99, 파쇄 4)은 수치 대신 아래 전용 효과로만 오른다. 자석 상한 200 → 240
- **레전드 전용 효과**: 그 증강을 레전드로 한 번이라도 고르면 붙는다 (여러 번 골라도 한 번)

| 증강 | 레전드 효과 |
|---|---|
| 편식가 | 내 색 원을 잡으면 피버 게이지 2배로 참 |
| 노란 맛 | 노란 원이 콤보·피버 게이지에서 내 색 원과 같게 |
| 무지개 사냥 | 무지개 원을 잡으면 즉시 피버 |
| 콤보 장인 | 콤보 보너스 +5 → +15 |
| 출발 신호 | 라운드 처음 10초 점수 ×1.5 |
| 잭팟 | 잭팟 배율 ×2~×5 (확률 70/25/5 그대로) |
| 찰나의 순간 | 가장자리 원을 잡으면 콤보 +2 |
| 예열 | 라운드 첫 피버 배율 +2 |
| 연장전 | 피버 중 원을 잡을 때마다 피버 시간 +0.1초 |
| 과충전 | 피버가 끝나도 게이지 50% 남음 |
| 폭주 | 피버 중 콤보 보너스 2배 |
| 여운 | 여운 배율 ×1.5 → ×2 |
| 해머 | 보스를 때리면 15% 확률로 3타 |
| 사냥꾼 | 보스 막타 때 화면의 내 원 전부 잡음 |
| 파쇄 | 방어형 보스 보호막 무시 |
| 보험 | 콤보가 끊겨도 피버 게이지 안 깎임 |
| 방패 | 견제당하면 견제한 사람 점수 3점을 빼앗음 |
| 철면피 | 견제해도 피버 게이지 안 깎임 |
| 강탈 | 1등을 견제하면 빼앗는 점수 2배 |
| 반격 전문가 | 반격하면 상대 콤보도 끊김 |
| 견제 반사 | 횟수 제한 없음 |
| 방해 전파 | 내 피버가 터지면 상대 커서 2초 감도 감소 |
| 넓은 손 | 범위로 같이 잡은 원 점수 ×1.5 |
| 자석 | 1초에 4개까지 |

- **침착 삭제**, 새 증강 10개 (수치는 노말/레어/에픽/레전드, 레전드는 아래 수치 + 전용 효과)

| 증강 (id) | 분류 | 효과 | 레전드 효과 |
|---|---|---|---|
| 헛손질 보정 (missSave) | 보조 | 빈 곳 클릭 시 반경 40/60/80/120 안의 가장 가까운 내 원을 대신 잡음 (페널티 없음). 봇은 안 고름 | 대신 잡은 원 점수 ×1.5 |
| 리바운드 (rebound) | 유지 | 콤보가 끊긴 뒤 3초 동안 점수 +30/50/70/120% | 끊긴 콤보의 절반을 그 3초 안에 되찾음 |
| 속사 (rapid) | 점수 | 0.4초 안에 연달아 잡으면 두 번째부터 +1/2/3/6 | 연속 5개면 다음 원 잭팟 확정 |
| 레이저 내성 (laserProof) | 유지 | 레이저 스턴 시간 −25/40/60/100% | 레이저에 닿으면 피버 게이지 +20 |
| 수집가 (collector) | 보조 | 아이템 효과 시간 +20/40/60/100% | 아이템 원을 잡으면 50% 확률로 한 등급 위 |
| 연쇄 콤보 (chainCombo) | 점수 | 10콤보마다 반경 150 안의 내 원 1/1/2/3개 자동 획득 | 5콤보마다 |
| 중앙의 왕 (centerKing) | 점수 | 중앙 구역 원 점수 +30/50/70/120% | 중앙에서 잡으면 콤보 +2 |
| 점화 (ignite) | 피버 | 피버가 터질 때 화면의 내 원 1/2/3/5개 자동 획득 | 화면의 내 원 전부 |
| 선봉 (vanguard) | 보스 | 보스에게 첫 타를 넣으면 +5/10/15/25 | 보스 등장 후 3초 동안 피해 2배 |
| 도발 (taunt) | 견제 | 견제하면 상대 피버 게이지 −5/10/15/25% | 피버 중인 상대를 견제하면 그 피버 1초 단축 |

- 증강 34개 (25 − 침착 + 10). 50개는 로드맵 4단계(스택형·자동 시전형)에서 채운다

### 3-3. 조합·빌드 가중치·대평등

- **조합 보너스**: 정해진 증강을 모두 가지면(등급 무관) 추가 효과. 선택 화면에 진행도(예: 피버 마스터 2/3), 완성 때 배너

| 조합 | 필요 | 보너스 |
|---|---|---|
| 피버 마스터 | 예열 + 연장전 + 폭주 | 피버 배율 +1 |
| 콤보 머신 | 콤보 장인 + 보험 | 콤보 보너스 +5 |
| 보스 헌터 | 해머 + 사냥꾼 + 파쇄 | 보스에게 주는 피해 +1 |
| 견제왕 | 강탈 + 반격 전문가 + 철면피 | 견제할 때마다 +2 |
| 행운아 | 잭팟 + 무지개 사냥 | 잭팟 확률 +10% |
| 변두리 | 찰나의 순간 + 자석 | 가장자리에서 자석 범위 +50% |
| 미식가 | 편식가 + 노란 맛 | 편식가의 노란색 −1 대가 없어짐 |
| 철옹성 | 방패 + 보험 + 리바운드 | 라운드마다 한 번 콤보 끊김을 막음 |

- **빌드 가중치**: 선택지를 뽑을 때 이미 가진 증강과 같은 분류는 ×2, 가진 조합의 나머지 증강은 ×3 (곱함). 저주·특별 카드에는 적용 안 함
- **대평등** (랜덤 이벤트 추가): 모두의 점수가 평균 쪽으로 절반만 움직임 (s → s + (평균 − s) / 2, 반올림). 3라운드가 끝난 뒤부터, 한 게임 최대 1번
