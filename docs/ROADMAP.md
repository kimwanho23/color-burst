## 아케이드 모드 (1.0.0-beta.3) ✅

5라운드 동안 라운드가 끝날 때마다 특수 능력(증강)을 골라 나만의 빌드를 만드는 모드.

### 진행
- 5라운드, 점수는 5라운드 누적 합산
- 라운드 시간: 기본 30초, 방 규칙에서 30 / 45 / 60 / 90초
- 1~4라운드 뒤마다 능력 3개 중 1개 선택 (각 선택지마다 등급이 따로 굴려짐)
- 고를 때마다 다시 뽑기 1번
- 꼴찌 배려: 꼴찌는 다음 차례의 등급 확률을 쓴다 (마지막 차례는 노말 15 / 레어 35 / 에픽 35 / 레전드 15) (30초, 시간 초과 시 무작위)
- 다른 사람의 증강은 점수판 아이콘으로 공개
- 봇도 증강을 골라 혼자 하기에서도 플레이 가능

### 증강 등급

| 등급 | 색 | 느낌 |
|---|---|---|
| 노말 | 흰색 | 소소한 보너스 |
| 레어 | 파랑 | 확실히 체감되는 강화 |
| 에픽 | 보라 | 플레이 방식을 바꾸는 강화 |
| 레전드 | 프리즘색 (무지개 그라데이션이 흐르는 테두리, 전용 효과음·반짝임) | 진짜 운 좋을 때만 |

등장 확률 초안 (라운드가 갈수록 상위 등급 증가):

| 라운드 후 | 노말 | 레어 | 에픽 | 레전드 |
|---|---|---|---|---|
| 1 | 70% | 25% | 5% | 0% |
| 2 | 55% | 32% | 12% | 1% |
| 3 | 40% | 37% | 20% | 3% |
| 4 | 25% | 40% | 30% | 5% |

### 능력과 등급

능력은 등급과 따로 정해져 있고, 같은 능력이 어느 등급으로 뜨느냐에 따라 수치만 달라진다.
기본 배율은 노말 ×1, 레어 ×2, 에픽 ×3, 레전드 ×5. 수치로 올릴 수 없는 능력은 횟수·시간·확률로 맞춘다.

같은 능력을 다시 고르면 수치가 합쳐진다(중첩). 보험 등은 상한, 철면피는 표적 시간 0초가 하한.

### 랜덤 이벤트

라운드 사이에 **깜짝** 룰렛이 돌아 판을 뒤흔든다. 운 요소를 더하는 게 목적. 처음에는 진행자 캐릭터가 일으키는 이벤트로 기획했지만, 캐릭터 없이 랜덤 이벤트로 정리했다.

- **시점**: 라운드 사이에만. 라운드 결과 → (가끔) 랜덤 이벤트 룰렛 → 이벤트 발동 → 능력 선택
- **깜짝**: 언제 나올지 미리 알려 주지 않는다. 라운드 사이마다 10% 확률로 등장 (라운드 사이 4번 → 한 게임에 한 번 이상 나올 확률 약 34%), 한 게임 최대 2번 💬
- **편**: 좋은 이벤트와 나쁜 이벤트를 섞는다. 1등 견제 이벤트가 너무 많으면 1등이 억울하므로 비율은 플레이 후 조정 💬
- 봇도 이벤트 대상이 된다 (혼자 하기에서도 동작)
- 이벤트가 일어나면 능력 선택 시간 +4초 (룰렛 약 1.3초 + 결과 2.2초, 결과는 눌러서 바로 닫을 수 있음). 방 규칙 '랜덤 이벤트'로 끌 수 있다 (기본 켜짐, 아케이드에서만 보임)
- 일어난 이벤트는 능력 선택 화면 위쪽에 "랜덤 이벤트 · 이름 + 결과 문장"으로 선택이 끝날 때까지 계속 보인다 (재접속해도 보임)
- 일으킬 수 없는 이벤트는 빠진다: 모두 동점이면 로빈 후드·순위 역전·선물, 저주 아닌 능력이 있는 사람이 2명 미만이면 능력 교환 등

| 분류 | 이벤트 | 내용 (초안) |
|---|---|---|
| 점수 | 로빈 후드 | 1등 점수의 10%를 꼴찌에게 |
| 점수 | 세금 | 모두에게서 5%씩 걷어, 다음 라운드에 가장 많이 번 사람(라운드 점수 증가량 기준)에게 라운드 끝에 지급 |
| 점수 | 복권 | 무작위 한 명 +30점 |
| 점수 | 순위 역전 룰렛 | 1등과 꼴찌의 점수를 맞바꿈. 아주 드물게 (다른 이벤트 가중치 1, 이것만 0.2) |
| 능력 | 능력 교환 | 무작위 두 명이 능력 하나씩 맞바꿈 |
| 능력 | 강등 | 1등의 능력 하나 등급 한 단계 하락 |
| 능력 | 선물 | 꼴찌는 다음 능력 선택에서 선택지 +1 (다시 뽑아도 유지) |
| 능력 | 저주 배달 | 저주 상한이 아닌 무작위 한 명의 다음 선택지에 저주 카드가 반드시 포함 (다시 뽑아도 유지) |
| 다음 라운드 | 라운드 테마 | 골드 러시(노란 원 확률 60%), 보스 러시(라운드 25%·55%·85% 지점), 역발사(원이 가장자리에서 중앙으로), 무지개 비(15%), 아이템 폭주(아이템 원 4배), 전원 같은 색(모든 원 노란색, 견제 없는 속도 대결). 보스·아이템이 꺼진 방에서는 해당 테마 제외 |

## 도우미·변화 요소

게임을 쉽게 해 주는 요소(넓은 손, 자석)와, 클래식이 단조로워지지 않게 하는 요소. 아케이드 능력은 "영구 보정", 아이템 원은 "잠깐 보정"으로 같은 효과 코드를 쓴다.

| 상태 | 적용 | 기능 | 내용 |
|---|---|---|---|
| ✅ | 아케이드 | 보조 능력: 넓은 손 | 범위 클릭. 클릭 지점 둘레 반지름 안에 걸친 내 원을 한 번에 여러 개 잡음. 반지름 15 / 25 / 35 / 55 (상한 80) |
| ✅ | 아케이드 | 보조 능력: 자석 | 빈 곳을 눌러 아무것도 못 잡았을 때, 거리 안에서 가장 가까운 내 원 하나를 잡음. 거리 30 / 50 / 70 / 110 (상한 150) |
| ✅ | 공통 | 아이템 원 | 가끔 나오는 `?` 원. 잡으면 무작위 아이템이 즉시 발동. 방 규칙에서 켜고 끄기, 꼴찌 보정이 켜져 있으면 꼴찌는 효과 시간 증가. 목록은 [아래](#아이템-목록) |
| ✅ | 공통 | 발사 패턴 | 12~18초마다 웨이브가 섞여 나옴: 부채꼴(5개, ±30°), 동시 다발(8개, 사방 같은 간격), 나선(8개, 0.1초 간격으로 45°씩). 직전 0.4초 중앙 원 번쩍임·효과음으로 예고. 색은 원마다 평소처럼(테마·내 색 비는 따름), 아이템 원은 안 섞임, 역발사 테마면 웨이브도 역발사, 시간 정지 중에는 안 나옴. 방 규칙 '발사 패턴'(기본 켜짐). 점수 규칙은 그대로 |
| 💡 | 공통 | 콤보 단계 보상 (후보) | 콤보 15·30 달성 시 짧은 버프(예: 넓은 손 3초). 아이템 원 효과 코드 재사용 |

### 규칙 메모
- **"내 원"** = 내 색, 노란색, 무지개. 넓은 손·자석은 내 원에만 적용된다. 남의 색과 보스는 범위·자석에 들어가도 잡히지 않고, 직접 정확히 눌렀을 때만 지금처럼 견제·보스 타격이 된다
- 판정 순서: ① 보통 판정으로 직접 맞은 원 (작은 원이 없으면 보스) ② 넓은 손 범위 안의 내 원 전부 ③ (아무것도 못 잡았으면) 자석 범위 안의 가장 가까운 내 원. 보스를 직접 눌렀으면 자석은 작동하지 않는다 (보스를 노린 클릭이 근처 작은 원으로 빨려 가지 않게)
- **발사 보호 구역**: 원 중심이 필드 가운데에서 90 안에 있는 동안은 직접 클릭·넓은 손·자석·장판·폭죽·필드 클리어·봇 모두 잡을 수 없다 (보스 포함). 모든 원이 가운데에서 태어나서, 가운데만 연타하면 태어나는 원을 96% 가져가던 결함을 막는다. 보호 구역은 점선 원으로, 그 안의 원은 반투명으로 그린다
- 원을 노리고 눌렀는데 남이 먼저 가져갔으면 빈 곳 페널티 없음. 화면의 빗나감 표시도 서버와 같은 지연 보정(250ms)으로 예측한다
- 범위 클릭으로 잡은 원은 하나하나 따로 점수·콤보·피버 게이지에 들어간다. 그래서 다른 능력보다 수치를 낮게 잡았다 (플레이 후 조정)
- 판정은 서버가 한다. 화면은 지금처럼 클릭 위치만 보내고, 범위 안의 다른 원은 서버가 찾아 각각 `circle:claimed`로 알린다 (메시지 형식 변경 없음, 지연 보정 250ms 포함)
- 원을 실제로 끌어당기지 않는다. 원 위치는 `발사 정보 + 시각`으로 모든 화면이 똑같이 계산하는 구조라서, 자석은 클릭이 원을 빨아들이는 방식 + 끌림 선 연출로 표현한다
- 시간 정지는 원 데이터에 정지 구간(`holds`)을 붙이고 `circlePos`가 그만큼 덜 움직이게 계산한다. 정지 중에는 새 원·보스가 나오지 않는다
- 봇은 넓은 손·자석 능력을 고르지 않는다 (봇은 정확히 눌러서 효과가 없음)

### 아이템 목록

**발동 방식: 잡는 즉시 발동.** 보관했다 쓰는 타이밍 싸움이 아니라 운 요소를 넣는 게 목적이다.
- 아이템 원은 `?`로 보여서, 잡기 전에는 무엇이 나올지 모른다
- 등급은 흔함 / 희귀 / 전설 (테두리 색으로 구분은 하되 내용은 비공개). 등급별 등장 확률로 강한 아이템을 드물게 만든다
- 효과 시간·수치는 초안, 플레이 후 조정
- 등장: 일반 원이 생길 때마다 2.5% 확률로 대신 아이템 원 (60초 한 판에 3~4개). 등급 확률 흔함 70 / 희귀 25 / 전설 5
- 아이템 원 자체는 점수·콤보 없음 (효과만). 넓은 손·자석·장판으로는 안 잡히고 직접 눌러야 한다
- 방 규칙 '아이템 원' (기본 켜짐, 하드코어 프리셋은 꺼짐). 꼴찌 보정이 켜진 방에서 꼴찌가 잡으면 효과 시간 ×1.5

| 등급 | 분류 | 아이템 | 효과 (초안) |
|---|---|---|---|
| 흔함 | 쉽게 | 넓은 손 | 5초간 범위 클릭 (반지름 35, 능력과 더하고 능력 상한 80) |
| 흔함 | 쉽게 | 자석 | 5초간 빗나간 클릭이 가까운 내 원을 잡음 (거리 70, 능력과 더하고 능력 상한 150) |
| 흔함 | 쉽게 | 헛클릭 무효 | 8초간 빈 곳 클릭 페널티 없음 (빈 곳 페널티가 꺼진 방에서는 안 나옴) |
| 흔함 | 쉽게 | 콤보 고정 | 5초간 콤보가 끊기지 않음 |
| 흔함 | 쉽게 | 보호막 | 5초간 견제당해도 콤보 안 끊기고 강탈 없음 (상대 흡혈귀 저주의 대가는 그대로) |
| 흔함 | 쉽게 | 표적 해제 | 내 표적 상태가 즉시 풀림 |
| 흔함 | 점수 | 피버 충전 | 피버 게이지 즉시 +50% |
| 희귀 | 점수 | 즉시 피버 | 게이지와 상관없이 바로 피버 발동 (이미 피버 중이면 +3초) |
| 희귀 | 점수 | 황금 손 | 다음에 잡는 원 5개 점수 2배 |
| 희귀 | 점수 | 점수 2배 | 5초간 점수 2배 |
| 희귀 | 점수 | 물들이기 | 5초간 노란 원을 내 색 점수로 계산 |
| 희귀 | 쉽게 | 내 색 비 | 3초간 내 색 원만 쏟아짐 |
| 희귀 | 쉽게 | 장판 | 잡은 자리에 4초간 반지름 90 장판 설치. 장판 위를 지나는 내 원은 자동으로 잡힘 (남의 색은 안 잡힘) |
| 희귀 | 한 방 | 폭죽 | 잡은 자리에서 터져 반지름 180 안의 원을 남의 색까지 전부 잡음, 견제 페널티·표적 없음. 보스 제외 |
| 전설 | 한 방 | 시간 정지 | 모든 원이 1.5초 멈춤 |
| 전설 | 한 방 | 필드 클리어 | 화면의 원을 남의 색까지 전부 잡음, 반격·표적 판정 없음. 보스 제외 |
| 💬 | 방해 | 안개 | 상대 화면 3초 흐림 ('방해 전파' 연출 재사용). 견제 규칙 후기 후 결정 |
| 💬 | 방해 | 얼음 | 상대 색 원 잠깐 가속. 2차 '얼음 원'과 통합 검토 |

- 2차의 "폭탄 원(감점)"과 이름이 겹치지 않게, 아이템 쪽은 **폭죽**으로 부른다
- 폭죽·필드 클리어로 잡은 원은 점수 배율을 따로 조정하지 않는다. 원마다 평소 규칙대로 점수가 들어간다 (내 색 +3, 노란색 +2, 남의 색 +1 …, 피버 중이면 피버 배율)
- 장판은 내 원만 잡는다 (넓은 손·자석과 같은 "내 원" 규칙). 원 위치가 시각으로 정해지므로 서버가 매 틱 장판과 원의 겹침을 판정한다
- 슬로우는 넣지 않는다

### 효과 겹침 규칙

능력·아이템·저주·랜덤 이벤트가 섞일 때의 규칙.

**같은 효과**

| 상황 | 규칙 |
|---|---|
| 넓은 손·자석의 능력 + 아이템 | 더한다. 능력 상한(넓은 손 80, 자석 150)은 그대로 적용 |
| 같은 아이템을 또 잡음 | 남은 시간에 더한다. 단 원래 효과 시간의 2배까지 |
| 즉시 피버 + 피버 중 | 피버 시간 연장 |
| 보호막 아이템 + 방패 능력 | 아이템이 먼저 막는다. 방패 횟수는 줄지 않음 |
| 서로 다른 아이템 | 동시에 여러 개 걸릴 수 있음 |
| 아이템 효과 종료 | 라운드가 끝나면 전부 사라진다 (아케이드) |

**점수 배율 순서**: 기본 점수(+능력 가산) → 피버 배율 → 점수 2배·황금 손 → 잭팟
- 점수 2배와 황금 손은 서로 겹치지 않는다 (둘 다 있으면 ×2 한 번만). 겹치면 피버 ×3 × 2 × 2 × 잭팟 ×3 = 36배까지 올라감
- 잭팟은 맨 마지막에 곱한다

**잭팟 + 여러 개를 잡는 효과**
- 넓은 손·자석·장판: 원마다 따로 굴린다 (평소 클릭과 같음)
- 폭죽·필드 클리어: 잭팟 없음 (이미 한 방이 커서)

**저주 vs 아이템**: 저주의 대가는 아이템이 못 뚫는다. 대가가 확실해야 저주 카드가 의미 있음
- 외길(노란색 0점) + 물들이기 → 노란색은 그대로 0점
- 유리 대포(빈 곳 −5점) + 헛클릭 무효 → 콤보·피버 페널티는 막지만 −5점은 그대로
- 표적 자처 + 표적 해제 → 표적이 풀리지 않음

**여러 사람이 같은 원**: 노란색·무지개는 모두에게 "내 원"이라 두 사람의 장판·넓은 손이 같은 원을 동시에 잡을 수 있다. 서버가 먼저 처리한 사람이 가져간다 (지금과 같음)

### 이펙트

지금 있는 효과(링, 스파크, 떠오르는 글자, 화면 흔들림, '화면 효과 줄이기')를 바탕으로 만든다.

**원칙**
- 색이 곧 의미: 금색 = 점수(잭팟, 황금 손), 하늘색 = 보조(넓은 손, 자석, 장판), 아이템 등급 = 아케이드 등급 색 (흔함 흰색, 희귀 파랑, 전설 프리즘)
- 내 것은 크게, 남의 것은 작게. 남의 버프는 점수판 칩의 작은 아이콘으로만
- '화면 효과 줄이기'가 켜져 있으면 흔들림·번쩍임·파편은 빼고 링과 숫자만
- 파티클 개수 상한. 필드 클리어처럼 원 수십 개가 한꺼번에 터져도 버벅이지 않게

| 기능 | 이펙트 |
|---|---|
| `?` 아이템 원 | 천천히 도는 `?` + 등급 색 테두리 (전설은 프리즘이 흐름). 색이 아니라 `?` 모양으로 구분해 색약도 알아봄 |
| 아이템 획득 | 잡은 자리에서 아이콘이 룰렛처럼 빠르게 바뀌다 멈춤 (0.4초). 운 요소를 살리는 핵심 연출 |
| 넓은 손 | 클릭하면 범위만큼 하늘색 링이 퍼짐. 효과 중에는 커서 둘레에 얇은 원 |
| 자석 | 클릭 지점 → 원으로 짧은 곡선 끌림 선, 원이 클릭 쪽으로 살짝 빨려 들며 터짐 (연출만, 판정 위치는 그대로) |
| 장판 | 바닥에 내 색 원형 무늬, 테두리가 줄어들며 남은 시간 표시. 원이 지나가면 작게 팡 |
| 폭죽 | 원형 충격파, 범위 안 원이 안쪽부터 바깥으로 차례로 터짐 (30ms 간격) |
| 필드 클리어 | 짧은 흰 번쩍임 → 화면 전체 충격파, 원들이 거리 순서로 연쇄 폭발 |
| 시간 정지 | 화면 채도 낮춤, 멈춘 원에 시계 무늬 |
| 즉시 피버 | 지금 피버 연출 + 시작할 때 링을 한 번 더 크게 |
| 잭팟 | ×1.5 금색 숫자 + 스파크 / ×2 확대 / ×3 번쩍임 + 동전 파편. 보스에서 터지면 한 단계 더 크게 |
| 랜덤 이벤트 | 주사위 아이콘과 "랜덤 이벤트!" 카드가 가운데에서 커지며 나타나고, 이벤트 아이콘 9칸을 불빛이 돌다 결과에서 멈춤 (칸마다 틱 소리, 결과음). 결과는 2.2초 동안 보이고 누르면 닫힘. 이후에도 선택 화면에 결과 줄이 남음 |

**버프 표시**
- 내 버프: 화면 아래 가운데에 아이콘 + 원형 타이머가 줄어듦, 끝나기 1초 전 깜빡임
- 남의 버프: 점수판 칩에 작은 아이콘만

## 플레이 피드백 반영 (2026-11-07)

플레이 테스트 피드백. 핵심 불만은 "다 눌러 버리면 게임을 즐길 수 없다" → 견제는 흐름을 끊는 용도로 두고 주 점수원이 되지 않게, 대신 반격·보스·방해로 판을 흔든다.

### 1단계: 빠른 조정

| 상태 | 기능 | 내용 |
|---|---|---|
| ✅ | 반격 점수 상향 | 반격 +4 → **+6** (견제 +1은 유지) |
| ✅ | 강탈 능력 너프 | 강탈 1/2/3/5 → 1/1/2/3 (견제가 주 점수원이 되지 않게) |
| ✅ | 증강 선택 시간 | 15초 → **30초**. 모두 고르면 바로 다음 라운드 (지금처럼) |
| ✅ | 라운드 종료 표시 | 라운드가 끝나면 "라운드 종료!"를 1.5초 보여 준 뒤 능력 선택 화면을 연다. 그동안 들어온 클릭은 무시 (라운드 끝에 원을 누르던 클릭이 막 깔린 카드를 골라 버리는 문제) |
| ✅ | 보스 격파 직후 헛클릭 무시 | 보스가 터진 뒤 1초 동안 빈 곳 클릭 페널티 없음 (보스를 연타하던 클릭이 헛클릭이 되는 문제) |
| ✅ | 사출 속도 증가 | 원의 기본 발사 속도 +15% |

### 2단계: 보스 확장

| 상태 | 기능 | 내용 |
|---|---|---|
| ✅ | 동시 등장 | 보스가 나올 때마다 1마리 60% / 2마리 30% / 3마리 10% (보스 러시 테마는 2~3마리), 화면에는 최대 3마리. 서로 다른 방향으로, 종류·체력은 마리마다 따로 |
| ✅ | 보스 종류 확률 | 일반 40% / 방어형 20% / 공격형 20% / 이동형 20% |
| ✅ | 방어형 보스 | 푸른 몸통·방패 무늬. 3초마다 마지막 1초 동안 보호막(하늘색 육각 테두리). 보호막 중에 때리면 "막힘!": 피해·점수 0, 헛클릭도 아님 |
| ✅ | 공격형 보스 | 주황 몸통·성난 눈썹. 4초마다 마지막 1.5초 동안 붉어진다. 붉을 때 때리면 피해 없이 −2, −4, −6 … (그 라운드에 붉을 때 때린 횟수만큼 커짐, 라운드마다 초기화) |

- 이동형의 튕김은 원 위치를 시각만으로 계산하는 지금 구조(`circlePos`)에 반사 계산을 더해서 처리한다 (서버·화면이 같은 결과)

### 3단계: 게임 커서와 방해 아이템

감도 감소·마우스 반대·레이저 스턴·오오라는 모두 **커서**를 다룬다. 그래서 먼저 "게임 커서"를 만든다.
- 캔버스 위에서는 진짜 마우스 커서를 숨기고 게임 안에 내 커서를 그린다 (내 커서는 나만 보임). 클릭은 그 커서 위치로 판정
- 커서 위치를 서버에 초당 약 15번 보낸다 (레이저·오오라 접촉 판정용). 혼자 하기·멀티 모두
- 평소에는 진짜 커서와 똑같이 움직여서 차이가 없고, 효과가 걸렸을 때만 달라진다

| 상태 | 기능 | 내용 |
|---|---|---|
| ✅ | 감도 감소 (방해) | 잡은 사람을 뺀 모두의 커서가 5초 동안 진짜 마우스를 늦게 따라옴 (처음엔 움직임 30%였으나 커서가 화면 밖으로 빠져서 위치 기준으로 바꿈) |
| ✅ | 마우스 반대 (방해) | 잡은 사람을 뺀 모두의 커서가 5초 동안 화면 가운데 기준 거울 위치 (처음엔 움직임 반대였으나 커서가 화면 밖으로 빠져서 바꿈) |
| ✅ | 시야 방해 (방해) | 잡은 사람을 뺀 모두의 화면에: 잉크 얼룩 / 반코트(화면 절반을 가림) / 무작위 그림 / 볼록·오목 렌즈. 렌즈는 화면 전체가 아니라 원·보스·아이템의 위치와 크기만 휜다 (클릭 판정은 그대로) |
| ✅ | 1등 저격 (방해) | 1등을 노리는 아이템. 맞은 1등은 3초 스턴 (클릭 불가) + 콤보 끊김, 점수는 빼지 않음. 1등이 잡으면 2등을 노린다 |
| ✅ | 레이저 발사기 | 화면 밖에서 일정 시간마다 레이저 발사 (초안: 10~15초마다, 1초 전 경고선). 레이저에 커서가 닿은 플레이어는 1.5초 스턴 (클릭 불가, 커서가 회색) |
| ✅ | 이동형 보스 오오라 | 이동형 보스 둘레 80 고리. 안에 들어간 커서는 초당 120만큼 보스 쪽으로 끌리고 0.5초마다 −1, 고리를 클릭하면 −2 (빈 곳 페널티 대신). 봇은 커서가 없어 제외 |
| ✅ | 카오스 모드 (프리셋) | '모든 게 켜진 진정한 난장판'. 아이템 등장 3배, 발사 패턴·레이저 간격 절반, 보스가 한 번에 1/2/3마리 확률 20/40/40, 랜덤 이벤트 확률 30%. 속도 ×1.25, 원 개수 ×1.3, 피버 배율 5, 무지개 10%, 꼴찌 보정 켜짐 |
| ✅ | 커서 자석 | 자석 능력·자석 아이템을 커서 기준으로 바꾼다: 커서 둘레 반경 안에 들어온 내 원을 클릭 없이 잡는다 (능력 반경 30 / 45 / 60 / 90, 1초에 최대 2개). 커서 둘레에 자석 범위 표시. 지금의 '빗나간 클릭 보정' 자석을 대신함 |

- 스턴: 그동안 클릭은 무시하고 빈 곳 페널티도 없다. 서버가 판정. 레이저 스턴은 콤보를 끊지 않고, 1등 저격 스턴만 콤보를 끊는다
- 방해 아이템은 기존 아이템 원에 섞는다 (감도 감소·마우스 반대 흔함, 시야 방해 희귀, 1등 저격 전설). 방 규칙 '방해 아이템'으로 따로 끌 수 있다 (기본 켜짐, 느긋하게 프리셋은 꺼짐)
- 같은 방해가 겹치면 남은 시간이 늘어나되 최대 10초. 효과가 끝나면 커서가 0.15초 동안 진짜 마우스 위치로 미끄러져 돌아온다
