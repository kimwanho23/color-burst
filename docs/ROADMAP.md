# 로드맵

진행 상태: ✅ 완료 · 🚧 진행 중 · ⏳ 예정 · 💬 플레이 후기 받은 뒤 결정

## 1차 (1.0.0-beta.2 목표)

| 상태 | 기능 | 내용 |
|---|---|---|
| 🚧 | 방 규칙 설정 | 방장이 대기실에서 설정, 모두 동일 적용. 게임 속도, 원 개수, 한 판 시간, 피버 배율·시간·충전 속도, 무지개 확률, 견제 페널티, 표적 시간, 꼴찌 보정, 보스 원 켜기 |
| 🚧 | 규칙 프리셋 | 기본 / 파티 / 하드코어 / 느긋하게 + 고급 설정 |
| 🚧 | 보스 원 | 크고 느린 체력 원. 타격 +1, 막타 +20, 최다 타격(MVP) +5. 보스는 피버 배율 최대 ×2. 한 판에 2~3번(마지막 10초 포함) |
| 🚧 | 혼자 하기 | 방 코드 없이 봇 3명과 바로 플레이하는 비공개 방 |
| 🚧 | 일시정지 | 혼자 하기: 자유(`Esc`/`P`, 다른 탭으로 가면 자동). 멀티: 방장만 |
| 🚧 | 바로 한 판 더 | 결과 화면에서 대기실을 거치지 않고 재시작(방장) |
| 🚧 | 설정 패널 | 음악·효과음 음량 따로, `M` 음소거, 화면 효과 줄이기, 전체 화면, 핑 표시 |
| 🚧 | 결과 화면 칭호 | 견제왕, 막타 장인, 피버 머신, 콤보 마스터, 평화주의자, 정밀 사격 |
| 🚧 | 점수 그래프 | 시간에 따른 점수 변화로 역전 장면 확인 |
| 🚧 | 방 누적 전적 | 같은 방에서 여러 판 할 때 승수 표시 |
| 🚧 | 클릭 속도 제한 | 매크로 방지, 1인 초당 15회 |

## 2차

| 상태 | 기능 | 내용 |
|---|---|---|
| ⏳ | 이벤트 타임 | 판 중간 몇 초간 특별 규칙: 골드 러시(노란 원 폭포), 역발사(가장자리→중앙), 미니(원 작아짐) |
| ⏳ | 특수 원 추가 | 폭탄 원(감점), 얼음 원(상대 원 가속), 분열 원(작은 원으로 갈라짐). 방 규칙에서 켜고 끄기 |
| ⏳ | 대기실 편의 | 준비 버튼, 방장 넘기기, 강퇴 |
| ⏳ | 이모지 반응 | 결과 화면에서 간단한 반응 |
| ⏳ | 튜토리얼 | 처음 하는 사람용 30초 연습 |

|---|---|---|

## 💬 플레이 후기 후 조정

| 항목 | 메모 |
|---|---|
| 견제 시스템 | 평상시 페널티 강도, 표적 시간, 반격 점수. 연속 견제 경고(같은 사람만 노리면 표적 시간 증가) 도입 여부 |
